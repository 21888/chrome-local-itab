# Local iTab

[简体中文](README.md) · [English](README.en.md) · [Español](README.es-ES.md)

一个以本地数据为中心的 Chrome 新标签页。把搜索、常用网站和自己的小看板放在一处，让每次打开新标签页都简洁、顺手。

**离线优先 · 分类快捷方式 · 自定义布局 · 可选同步与备份**

无需构建，也无需注册 Local iTab 账号。时钟、快捷方式管理、本地图片和手动填写的卡片可离线使用；网络搜索、打开网站和可选云端功能需要网络。

[界面预览](#preview) · [安装](#install) · [功能](#features) · [隐私与备份](#privacy) · [开发](#development)

**本地 AI 工作流：** 管理提示词和正文版本，审阅变量预览，保存并回看精确关联的结果。可选连接自己的模型服务，审阅接口与完整提示词后手动发送，再决定是否保存回复。[使用流程](#local-ai)

## 安装与开始使用

1. 下载并解压仓库源码，或克隆本仓库。源码可以直接加载，不需要运行构建命令。
2. 在 Chrome 地址栏打开 `chrome://extensions/`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择**直接包含 `manifest.json` 的文件夹**，通常是 `chrome-local-itab/` 或下载后解压得到的仓库目录。不要选择 ZIP 文件或它的上级目录。
4. 打开新标签页，添加常用网站，再进入设置调整外观、搜索和模块。

运行环境为支持 Manifest V3 的 Chrome。快捷方式与布局的并发写入保护还使用 `navigator.locks`；相关浏览器 API 不可用时，这些写入会失败并显示错误。

**备份提醒：** 配置 JSON 和 Drive 快照不包含待办、专注计时器、便签或倒计时。已保存的个人模块可通过[完整本地备份](docs/complete-backup.zh-CN.md)迁移，独立导出仍可使用；未保存草稿和专注会话不可迁移。世界时钟偏好属于配置。卸载或清理数据前，请按[迁移清单](docs/migration.zh-CN.md)保存所需副本。

### 已有解压安装如何升级

1. 先保存所有打开页面中的编辑，并下载[完整本地备份](docs/complete-backup.zh-CN.md)，选择需要的已保存模块。普通设置 JSON 和 Drive 快照不包含个人模块。尚无完整备份的旧版请使用原有独立导出，并手动记录专注偏好；未保存草稿和计时会话不可迁移。便笺请从包含要保留文本的原标签页导出，尤其是未保存或冲突草稿。
2. 从 GitHub Release 下载运行文件 ZIP，解压后将文件替换到**最初加载的固定文件夹内**，保持 `manifest.json` 位于该目录根部。不要移除扩展，也不要把新解压目录作为另一扩展加载；更换目录可能改变扩展身份，导致原数据无法访问。
3. 在 `chrome://extensions/` 找到 Local iTab 并点击「重新加载」，再刷新已打开的新标签页和设置页，确认安装版本及原有数据。

详见[版本检查、独立备份入口与更新步骤](docs/version-updates.md)。更新检查不会自动下载、替换文件或重新加载。

<a id="local-ai"></a>

### 本地 AI 资料库：从提示词到已保存结果

提示词库与 AI 收藏是当前设备上的两份资料库，由所有工作空间共用。默认不调用模型或上传内容。可选的[模型运行流程](docs/ai-model-workflow.md)允许选择兼容 OpenAI 的 HTTPS 接口，单独授予该地址权限、审阅完整内容后手动发送；服务商可能收费。密钥仅暂存于对话框且不会进入存储或备份，回复需手动保存。

1. **保存模板，审阅预览。** 在提示词库中新建标题和正文，按需加分类、标签和 `{{变量}}`，需要保留时再明确保存。新建未保存草稿也可主动预览、填写变量并复制，无需先保存。修改任意草稿字段、切换提示词、关闭或开始保存会清除临时变量；保存仍保留模板占位符。正文修改保存后保留版本历史。[提示词库指南](docs/prompt-library.zh-CN.md)
2. **选择要使用的版本。** 历史中的版本行仅查看正文；点击「使用此版本」才切换可用预览，「返回当前版本」明确切回。各确切版本的变量值独立保留在当前标签页，刷新或关闭后消失，不进入正文、历史或备份。「清空变量值」会清除使用中及当前版本的值并返回当前版本。可在历史中选择两个已保存版本作逐行比较，查看添加、移除、未变内容与换行摘要；比较不恢复或修改正文。也可用所选正文「从此正文版本新建草稿」，元数据来自当前已保存提示词，保存后成为独立条目。[历史预览](docs/prompt-history-preview.md) · [版本比较](docs/prompt-version-comparison.md) · [历史正文新建草稿](docs/prompt-history-draft.md)
3. **审阅摘录后填入变量。** 选择一条未归档的已保存收藏，核对完整正文和将被替换的旧值，再明确替换这个变量。仅填入所审阅的正文，注释、来源和工具说明不会一起带入；模板和其他变量不变。[摘录填入说明](docs/prompt-excerpt-variables.md#中文)
4. **手动保存结果并关联精确版本。** 从实际使用中的预览点击「为此版本保存结果」，在新标签页打开带版本关联的空白、未保存收藏草稿。填入结果正文、核对关联并明确保存；不会读取剪贴板或预填结果。也可在收藏编辑器中选择提示词及精确版本，审阅后应用关联再保存。预览及历史中的已保存结果列表只显示精确关联该提示词和版本的未归档收藏，不跟随最新版、不作质量排序；卡片在新标签页打开。[收藏指南](docs/ai-collections.zh-CN.md) · [精确关联结果](docs/prompt-linked-results.md#中文) · [新建结果草稿](docs/releases/1.1.36.md)
5. **再次找到需要的内容。** 新标签页的统一搜索匹配已保存提示词与收藏的标题、正文、标签，以及收藏注释；可按类型筛选。关闭后重开会保留本页的关键词和类型并重新读取数据；「清除」只清关键词，刷新页面才重置两者。[搜索范围](docs/ai-library-search.md)

收藏页侧栏的「本页排序」默认「最近更新」，也可选择「最早保存」，按收藏记录首次保存时间排列；修改批注不会改变首次保存时间，这不是正文历史版本排序。排序与搜索、类型、工具、标签及归档筛选组合，仅重排列表，保留当前详情和未保存草稿。清除筛选或刷新已保存数据保留选择，重新加载页面恢复默认；审阅对话框或正文修订进行中暂不切换。[排序范围与验证边界](docs/collection-saved-sort-validation.md#中文)

在带精确版本关联的未归档收藏详情中，点击「对比已保存结果」，再明确选择关联相同提示词 ID 和版本 ID 的另一条已保存结果。两条当前正文按字面并排显示（窄屏堆叠），显示标题、工具说明和正文相同提示，不评分或排名。草稿、已归档条目、其他版本和恢复快照不参与。关联提示词缺失时仍可按已保存的 ID 比较，并提示来源可用性。对比只读，不联网；收藏数据刷新、写入或读取失败会清空对比，需关闭后重新打开并选择，不自动替换候选。

未关联提示词的上下文答案和手动摘录也可使用「手动对照任意收藏摘录」。明确选择另一条当前未归档收藏，逐项查看原样正文、各自来源与正文版本；不假定输入或模型相同。原精确提示词对比保持独立，读取失败或数据变化后需重新选择。[手动收藏对照](docs/manual-saved-excerpt-comparison.md#中文)

「摘录版本历史」中的「并排阅读两个已保存正文版本」可分别选择同一收藏的两个历史版本，默认最近两版，并显示序号、日期、精确版本 ID 与当前标记。仅并排阅读纯文本，不做逐行增删对比，不恢复或保存正文。[历史阅读与验证边界](docs/collection-history-reading.md#中文)

可从网页右键菜单将所选文字送入新的未保存收藏草稿，审阅后再保存；来源网址默认不包含，启用后去除查询参数和片段。浏览器可能改变原文换行。[所选文本审阅](docs/selection-capture.md)

**导出与备份：** 可审阅并下载单条已保存内容为 Markdown；提示词保留变量占位符，收藏仅包含当前正文、注释和元数据，来源网址另行选择。Markdown 是可读副本，不用于恢复历史。请使用资料库的 JSON 导出或选择包含资料库的完整本地备份；普通设置 JSON、Chrome Sync 和 Drive 快照不包含它们。未保存草稿和临时变量不在备份中，本地数据及导出文件未加密。[Markdown 导出](docs/local-ai-markdown-export.md#中文) · [完整备份](docs/complete-backup.zh-CN.md)

收藏页的「导入 / 恢复 JSON」可严格审阅本产品独立收藏 JSON，并明确替换本机全局收藏（非合并）；旧库保留为恢复快照，可在同一入口审阅恢复。取消不写入，数据变化须重审，不确定结果先只读核验。[独立收藏 JSON 导入](docs/collection-json-import.md#中文)

### AI 资料问答：先在本地审阅与复制

仅「回答」模式提供默认关闭的「逐步显示回答」开关，本地审阅和接口审阅都会显示其状态；任务 JSON 始终非流式。渐进文本在独立的「未完成」区域以纯文本显示，不能通过回答按钮保存或复制；完整响应通过严格校验后才成为正式回答。停止、失败、截断均保留明确未完成状态，之前的完整回答单独保留。切换离开页面会停止请求并清除密钥，关闭面板会清除渐进文本，不会在后台持续运行。复用既有严格 SSE 解析器，原有审阅、授权、发送步骤不变。尚未验收真实提供方的流式兼容性，测试仅使用合成 SSE 和 mock。

从新标签页打开「AI 资料问答」，填写问题，按需选择全局 AI 收藏中的已保存摘录和当前工作空间已保存便笺；默认不选择任何资料。无需填写接口、模型或密钥，即可点击「在本地审阅提示词」，核对完整内容后点击「复制已审阅提示词」。提示词包含所选摘录，请在粘贴到外部服务前检查私人信息或密钥等敏感内容。本地审阅与复制不调用模型、不授予接口权限，也不保存内容。

在面板非编辑区域按 `/` 可聚焦来源搜索并全选关键词，不改筛选、勾选或审阅请求。[键盘搜索说明](docs/ai-context-source-search-shortcut.md#中文)

来源列表默认按标题搜索，也可明确勾选「同时搜索当前摘录正文」，仅匹配已加载来源的标题和当前正文，并与范围、「只看已选」取交集。[摘录搜索说明](docs/ai-context-loaded-excerpt-search.md#中文)。点击「清除来源筛选」可一次显示全部已加载资料，保留勾选、摘录编辑和已审阅请求；不会重新加载来源、发送或保存。[筛选说明](docs/ai-context-source-filter-reset.md#中文)

若要在扩展内调用模型，再配置自己的连接，单独审阅完整请求、授权接口并明确发送；本地审阅不会代替这些步骤，服务商可能收费。回答可明确保存到 AI 收藏；提取的待办必须逐条预览后确认添加，不会自动执行。[流程与隐私边界](docs/ai-context-workflow.md)

从外部 AI 网站取得任务后，可选择“提取待办草稿”→“审阅外部任务 JSON”，粘贴纯 `{"tasks":["任务一"]}` JSON，明确载入、勾选任务、审阅确切列表，再确认添加。无需连接或密钥；载入和审阅不会发送请求或保存内容，只有最终确认添加才写入任务。结果标记为手动粘贴，不能保存为回答或来源快照。[格式限制与安全替换](docs/ai-context-external-tasks.md)

AI 上下文回答区可明确点击“复制回答”或“复制任务 JSON”，仅复制当前显示的回答文字，不附带问题、来源快照、连接地址或密钥字段。编辑请求后仍可复制旧回答，其“上次请求”提示会保留。复制不保存内容、不改变任务复核；失败时可手动选择文字复制。模型回答本身可能重复输入中的私人信息，复制前请检查。

### 新标签页与日常工具

- **导出浏览器书签**：在设置 → 数据中，将已保存的网站标题、完整网址和分类文件夹导出为本地 HTML 文件。隐私确认后可预览全部或一个现有分类的网站与文件夹数量，再明确下载已预览范围；相关已保存内容变化后需重新预览。不包含未保存的修改、图标、设置和本地小工具。[范围与限制](docs/bookmark-export.md)。

- **分类快捷方式**：添加、编辑、删除常用网站，按分类筛选；首页与设置可选网格（默认，可拖拽排序）、自由摆放（不吸附网格）或手动吸附网格；切换保留已保存的位置。右键菜单提供网站操作及打开分类内全部网站的入口。 聚焦分类后可用横排左右/竖排上下方向键及 Home/End 移动，按 Enter/空格确认筛选。[分类键盘操作](docs/category-keyboard-validation.md)。

- **二十一种工作台模版**：包括 A「澄明」、B「墨序」、C「拾页」及十八种其他设计，均支持浅色和深色。最近增加的速览、今日、书签、停靠、拼贴和便笺六种模版带来不同的结构、密度与导航方式。[六种布局说明](docs/dashboard-template-expansion.md)。新安装仍默认 A / 浅色。切换只保存外观，不改动网站、分类、待办、背景、布局模式或已有坐标。分组式模版在网格模式展示真实分类，自由布局仍使用同一个坐标平面。[模版说明](docs/template-gallery.zh-CN.md)。

### 完整本地备份

在设置 → 数据中，一次选择导出七个已保存模块：配置（网站、本地图片等）、待办及历史副本、便笺、倒计时、专注偏好、全局提示词库及全局 AI 收藏库（含收藏为 schema 4；不含收藏但含提示词为 schema 3；仅工作区模块为 schema 2）。恢复前预览并选择模块，分别确认所选全局库的目标；未选择的模块保持不变。恢复前保存包含全部工作区模块及本次所选全局库的恢复副本，且不会自动重载页面。未保存草稿和正在进行的计时会话不迁移；未结束的专注会话会阻止恢复专注偏好。此功能不扩展 Chrome Sync 或 Drive 的备份范围。[使用、大小限制与恢复保护](docs/complete-backup.zh-CN.md)。

先选择“**准备导出摘要**”，核对所选模块、生成时间、精确 UTF-8 字节数及已保存数量，再选择“**下载这份备份**”请求同一份已保存快照；后续编辑不会自动加入。摘要不展开私人内容。页面无法核验下载完成，请自行检查浏览器下载列表。

### 本地计算器

在搜索框中以 `=` 开头，按 Enter 或“计算”，例如 `=(12 + 3) / 2` → `7.5`。支持小数、一元正负号、`+ - * /` 和括号。表达式、结果和错误仅留在当前标签页，不发送搜索请求，也不写入存储；自定义搜索地址未设置时也如此。删除开头的 `=` 即恢复普通搜索。编辑输入会清除当前结果。

计算成功后，点击“用结果继续计算”会把搜索框替换为 `=` 加完整结果，并将光标放到末尾；可继续输入 `+`、`-`、`*` 或 `/`，再明确提交下一次计算。此操作会清除旧结果和复制提示，不会自动计算、搜索、复制或保存；输入仍是当前标签页里的未保存草稿。[续算验证范围](docs/calculator-continue-result-validation.md)。

“本页最近计算”默认折叠，仅记录明确提交且成功的最近 5 次计算，最新在前，显示原始表达式和完整结果。每条记录可用“用结果继续计算”替换当前搜索草稿，聚焦并将光标放到末尾；下一次计算仍需明确提交。编辑、错误、普通搜索以及隐藏搜索区域不会清空这些记录；“清空最近计算”只清空记录，不改当前输入或结果。记录不会持久化、同步或导出，重新挂载搜索框或重新加载页面后丢弃；只有记录而没有未保存输入时，不会阻止设置同步重新加载。[本页最近计算验证范围](docs/calculator-recent-results-validation.md)。

计算成功后，可点击“复制结果”，把完整数值（不含 `=` 或标签）写入系统剪贴板；也可按 Tab 移动到只读结果框，选中完整数值，再按 Ctrl/Cmd+C 使用浏览器复制。复制失败会单独提示并保留表达式和结果，便于手动复制。计算和复制均不会主动移动焦点；编辑或开始输入法组合输入会清除结果框。未完成的复制不会重复执行，清除结果或切换界面也无法撤销已经发出的系统写入。结果可能显示为科学记数法，可粘贴到新的计算中，例如 `=1e-7 * 2`。[复制结果验证范围](docs/calculator-result-copy-validation.md)。

<details>
<summary>计算器的范围与精度限制</summary>

限制：`=` 后最多 256 个字符，括号与一元正负号的合计嵌套最多 32 层。使用 JavaScript 浮点数，存在小数舍入、下溢和大整数精度限制（`=0.1 + 0.2` 得到 `0.30000000000000004`），不适合精确财务计算。除以零和非有限结果会显示本地错误。十进制数后可接 `e`/`E`、可选的 `+`/`-` 和至少一位指数数字，数值内部不能有空格（例如 `.5E+2`）。指数数字也计入 256 字符限制；上溢报错，下溢可能变成零。不支持百分比、变量或单位换算。保留计算器输入时，设置同步触发的重新加载会延后；主动重新加载可能丢弃输入。

</details>

## 本地效率工具

### 本地待办

在模块显示设置中启用可选的待办卡片，默认关闭且不填充示例。支持添加、编辑、完成、按文字本地筛选各状态任务、复制单条已保存原文、置顶下一件事和恢复已移除项目。待办及恢复副本仅保存在此设备，不会进入设置导出、Chrome 同步或云盘备份。重置/导入/恢复设置会保留待办。可使用独立的待办导出/导入，或在完整本地备份中选择待办进行迁移。[待办使用说明](docs/local-tasks.zh-CN.md)。

在未完成、已完成或已移除任务的「复制原文」旁点击「用原文新建」，可打开独立可编辑草稿；只有点击「添加」才新建一条未完成待办。原任务、完成记录、置顶、撤销和快捷输入草稿保持不变，多行仍为一项。保存未确认时可明确重试上次原文，新草稿不会被覆盖。[原文新建与验证边界](docs/tasks-reuse-draft-validation.md)。

使用「操作 → 移到列表首位」可一次保存，将未完成待办移到最前，并显示在收起时的四条预览里。其他待办保持相对顺序，独立的「下一件事」置顶不变。请先清除筛选，首项无需再移。[移首验证说明](docs/tasks-move-first-validation.md)。

通过「批量添加待办」粘贴每行一项的内容，查看编号预览后一次性确认添加全部非空行。空格、项目符号和重复行均保留；普通添加仍支持 Shift+Enter 在同一项内换行。预览和取消不写入数据。仍限制 500 条记录（含已完成/已移除）、每项 1,000 个 Unicode 字符及 2 MiB 集合/文件预算。验证失败不添加任何项目，保存结果不确定时安全重试同一批内容。 [批量待办实测与截图](docs/tasks-batch-capture-validation.md)。

点击「选择并完成待办」，从当前实际显示的未完成列表中勾选项目，先看完整编号原文、数量及置顶影响，再「确认完成这 N 项」。整批校验失败时零写入；保存未确认时只明确重试原命令。本页保留最近一次完成或移除的一个撤销位置，批量完成可一次整批撤销；任一成员已变则整批停止，不恢复旧置顶。完成仍计入 500 条记录上限。[批量完成说明与验证范围](docs/tasks-batch-completion-validation.md)。

### 本地专注计时器

在设置中启用可选的专注计时器。默认隐藏，专注 25 分钟、休息 5 分钟；待开始时可将各阶段设为 1–180 的整数分钟。开始、暂停/继续、停止/重置均需手动操作，选择下一阶段不会自动开始。

剩余时间下方显示本阶段进度及“已用 / 本阶段”时长，按已保存的分钟数计算；未保存的输入不会改变总时长。暂停时进度保持不变，完成后保持满格，直到手动重置或选择下一阶段。读取失败、计时不确定或当前空间已失效时，进度会隐藏并保留原有提示。[进度显示与验证范围](docs/focus-stage-progress-validation.md)。

计时已确认运行时，进度下方还会显示“预计结束（设备本地时间）”，包含完整日期、时刻和当地 UTC 偏移。它直接显示已保存的结束时刻；暂停、保存待确认、读取失败或计时不确定时隐藏，继续成功后按新的结束时刻显示。按设备时钟估计，暂停后重新计算；无后台提醒。[预计结束说明与验证范围](docs/focus-expected-end-validation.md)。

每个工作区各有一个本设备上的会话，同工作区的新标签页共享该会话。隐藏卡片会保留会话；仅重置设置会完整保留其状态，切换模版或导入配置不会启动或替换它。配置导出、Chrome 同步和 Drive 备份均不包含计时器。没有任务关联、历史记录、声音、网络请求或系统通知，也不需要新权限。

## 数据、隐私与联网行为

**备份提醒：** 配置 JSON 和 Drive 快照不包含待办、专注计时器、便签或倒计时。已保存的个人模块可通过[完整本地备份](docs/complete-backup.zh-CN.md)迁移，独立导出仍可使用；未保存草稿和专注会话不可迁移。世界时钟偏好属于配置。卸载或清理数据前，请按[迁移清单](docs/migration.zh-CN.md)保存所需副本。

### 更换浏览器或设备

配置备份不包含待办、专注计时器、便笺或倒计时。卸载扩展或清理数据前，请按[迁移清单](docs/migration.zh-CN.md)选择完整本地备份或独立导出保留副本。

日常配置、快捷方式和上传的图片主要保存在 `chrome.storage.local`；网站图标使用本地 IndexedDB 缓存，部分界面状态保存在浏览器本地存储中。扩展不包含分析或广告脚本。

- **搜索**：输入过程中不发送搜索内容；提交搜索或打开网址时才访问所选服务或目标网站。
- **网站图标**：在线获取默认关闭。开启后还需在当前设备授予 `https://www.google.com/*` 的可选访问权限，扩展才会向 Google favicon 服务发送网站域名以获取图标。有效缓存可离线复用，当前缓存有效期为 7 天。
- **本地卡片与背景**：天气、热榜、电影内容和上传的背景不依赖远程内容源。
- **Chrome Sync**：默认配置为关闭。开启后通过 `chrome.storage.sync` 同步配置；若同一 Chrome 账号已有本扩展的已启用同步配置，新安装也可能自动读取并应用它。
- **Google Drive**：需要单独进行 Google 授权。连接、刷新、备份、下载、恢复和删除快照会访问 Google API；没有定时自动备份。

离线优先指核心页面可在本地运行。启用云端功能或主动访问网站后，相应服务仍会接收完成操作所需的数据。

### Chrome Sync：轻量配置同步

适合在使用同一 Chrome 账号的浏览器之间同步快捷方式和设置，受 Chrome 同步状态与存储配额限制。嵌入式背景、海报和图标图片会从同步内容中省略或替换为默认值；需要完整图片时，请使用 JSON 导出或 Drive 快照。

重复网址也可独立摆放；旧坐标会保留。包含独立位置的备份使用格式 2，需要新版导入。旧客户端可能丢弃这些字段，因此 Chrome Sync 遇到不兼容副本会保留本机数据并提示检查。恢复副本与明确替换步骤见[独立位置与兼容说明](docs/layout-identities.md)。

### Google Drive：手动快照备份

- 在设置中连接 Google Drive，并为备份选择一个电脑名称。
- 快照包含配置和本地图片，保存在 Drive 的隐藏应用数据目录 `appDataFolder`，使用 `drive.appdata` 授权范围。
- 可以按电脑名称查看、下载、恢复或删除快照。普通备份完成后会尝试清理该电脑名称下的旧快照，保留最近 20 条。
- 单个快照上限为 25 MiB；超过 5 MiB 时会先提示确认。
- 从 Drive 恢复前，会尝试把当前配置也上传为安全快照。若失败，会询问是否继续；恢复会覆盖本设备当前配置。

此功能依赖 Chrome Identity API、可用的 OAuth 配置和 Google 授权。开发版或自行打包的版本，请确认相应配置可用；本地使用和 JSON 导入导出不依赖 Drive。

### 扩展权限

[manifest.json](manifest.json) 中声明的权限包括：

- `contextMenus`：明确右键操作后，在新标签页审阅未保存的所选文本草稿。
- `storage`、`unlimitedStorage`：保存配置及本地图片数据。
- `identity` 和 `https://www.googleapis.com/*`：供可选的 Google Drive 授权与备份使用。
- 可选的 `https://www.google.com/*`：供在线网站图标获取使用。
- 可选的 `https://*/*`：支持用户选择 HTTPS 模型服务。运行时只请求已审核的主机名和端口权限；授予访问权限本身不会发送内容。

## 文档与界面语言

本 README 默认使用简体中文，另有 [English](README.en.md) 和 [Español](README.es-ES.md) 版本。

扩展目前包含简体中文（`_locales/zh_CN`）和英文（`_locales/en`）界面资源，通过 `chrome.i18n` 使用浏览器语言，默认回退语言为英文。西班牙语目前仅为文档翻译。

主时钟的完整日期（包括日期顺序、星期和月份名称）优先使用当前中英文消息资源内的明确语言标记；不可用或无效时依次回退到 Chrome 预定义的 `@@ui_locale` 消息、Chrome 界面语言、浏览器首选语言和运行环境默认语言。年内天数和 ISO 周数的标签也使用当前界面语言。时间格式及自定义语句中的日期占位符保持不变。新生成的欢迎语会本地化；已保存或导入的语句（包括旧版英文欢迎语）不会被翻译或迁移。原有语句校验行为不变，包括去除首尾空格及空字符串回退为英文欢迎语。缺少语句字段时使用新的本地化默认值。

新生成的默认分类名称使用 Chrome 实际选中的中英文消息资源；其他语言使用英文回退，缺失或不可用的消息也回退为英文。分类 ID、图标和顺序不变。已保存或导入的分类名称不会随界面语言改变，包括与旧版默认名称相同的名称和自定义分类。缺少分类字段或明确恢复默认设置后会生成本地化默认分类；已保存的空分类列表保持为空。

设置页分类编辑器的字段名称和操作按钮提示、主保存状态及错误前缀也使用中英文界面资源，缺失时回退为英文。通过“添加分类”新建的初始名称使用当前界面语言；保存后与其他已有、导入或用户输入的名称一样，不会随界面语言改变。保存的具体错误原因仍原样保留，原有专用冲突及权限提示不变。

设置页背景图片的选择提示、格式与大小提示、移除按钮、上传反馈及移除确认也支持中英文，消息不可用时回退为英文。图片仍在本地读取、解码和保存，原有格式与大小限制不变；文件名和图片内容不会被翻译。具体错误原因原样保留，原有解码失败和设置冲突提示不变。

设置页手动热榜的标题与分数编辑提示、删除确认，以及添加、更新、删除成功反馈也支持中英文，消息不可用时回退为英文。Baidu、Weibo、Zhihu 名称及已有或用户输入的标题、分数保持原样；这仍是手动配置，不会联网抓取热榜。取消、数字解析、保存失败与冲突处理保持原有行为。验证范围见[手动热榜本地化检查](docs/settings-topic-localization-validation.md)。

设置页 Settings JSON 导入/导出的准备、文件处理、预览确认、取消、成功及现有错误分支提示现已支持中英文；反馈中的导入/导出、文件大小和条目标签也随界面语言显示，消息不可用时回退为英文。文件名与底层错误详情保持原文，部分详情仍可能是英文。原有大小提示、恢复副本、导入回执、身份关系保护和下载请求语义保持不变；下载请求不代表文件已保存。验证范围见[设置 JSON 传输本地化检查](docs/settings-transfer-localization-validation.md)。

## 本地开发与检查

项目使用 Manifest V3、原生 JavaScript 和 CSS，没有依赖安装或打包步骤。安装 Node.js 后，在仓库根目录运行：

```bash
# 运行全部回归测试
node --test tests/*.test.js

# 检查 JavaScript 语法
for file in *.js shared/*.js tests/*.js tests/helpers/*.js assets/*.js; do
  node --check "$file" || exit 1
done

# 校验扩展清单和语言资源 JSON
node -e 'const fs = require("node:fs"); for (const file of ["manifest.json", ...fs.readdirSync("_locales").map(locale => "_locales/" + locale + "/messages.json")]) JSON.parse(fs.readFileSync(file, "utf8")); console.log("JSON OK");'

git diff --check
```

这些检查覆盖逻辑回归、JavaScript 语法和 JSON 格式，不能代替真实浏览器验证。发布前还应加载扩展，检查中英文界面、键盘操作、拖拽、跨标签页编辑、导入恢复及可选联网流程。更多发布事项见[发布检查清单](docs/release-checklist.md)。

### 生成并验证扩展 ZIP

加载已解压的开发版无需构建。要离线生成仅包含运行文件的 ZIP，请安装 Python 3.10+（仅使用标准库），在仓库根目录运行：

```bash
python3 tools/package_extension.py --output dist/local-itab-current.zip
python3 tools/package_extension.py --verify dist/local-itab-current.zip
python3 -m unittest discover -s tests -p '*_test.py'
```

上面的命令显式使用已被 Git 忽略的 `dist/local-itab-current.zip`。若省略 `--output`，文件名会自动使用 `manifest.json` 中的版本号（`dist/local-itab-<版本>.zip`），不会覆盖已有文件。可使用 `--output /path/to/new-package.zip` 指定新的输出路径；仓库内的输出必须位于 `dist/`。历史 `release/*.zip` 保持不变，不是当前打包的输入。

显式运行文件清单包含共享模块、两种界面语言资源和实际使用的图标。清单文件缺失，或 HTML 的本地 script/link/image、CSS 的 `url()`/`@import`、manifest 的入口/图标引用缺失时，检查会失败。新增依赖需更新工具中的 `RUNTIME_FILES`；JavaScript 动态生成的路径和动态导入仍需人工检查。测试、文档、截图、工具、未列入清单的文件及旧压缩包均不打包。ZIP 使用排序路径、固定时间戳及不压缩的原始字节，确保相同输入可复现。

命令输出源 Git 提交及工作区状态（下载的源码可能没有提交信息）、文件数量和 ZIP 的 SHA256。`--verify` 将 ZIP 与当前源码字节及规范化 ZIP 元数据比较，因此其他提交生成的包可能无法通过。通过仅代表打包验证，不代表浏览器测试通过或已批准发布。上传前，请把新 ZIP 解压到独立目录，在 Chrome 中加载该目录并完成[发布检查](docs/release-checklist.md)。打包不会修改 manifest 版本，也不会发布扩展。

**提交与发布约定：** 每项功能或修复整理成一个完整提交，测试后及时独立推送到 `master`，普通开发提交保持 `manifest.json` 版本不变。每累计 2～3 个功能提交，再用独立的发布提交将补丁版本加一，并编写整批更新说明；文档维护与发布提交本身不机械计为功能。GitHub Actions 对每次公开仓库的 `master` push 完整测试并校验运行包，普通提交跳过发布；只有明确加版本的发布提交才按准确源码生成对应 tag、Release、精简运行 ZIP 和校验文件。新版本须相对最近祖先正式 Release 补丁加一，前一版未发布完成时先恢复再重跑；同一版本指向其他提交时拒绝发布，已发布文件不覆盖。测试包文件名的短源码哈希只用于追溯，不是扩展版本号。`master` 和 GitHub Releases 可以领先于商店审核版本；Chrome 商店仍按 UTC+08 自然日每天至多提交一个合并版本，仅在有新的已测试变更且没有版本正在审核时提交，否则跳过。CI 不自动追加版本提交，也不提交 Chrome 商店；此约定不保证每日上架或审核完成时间。每个版本同时在 `docs/releases/<版本>.md` 记录真实的新增、修复、注意事项及简短英文摘要，Release 先展示改动、最后展示安装方法。见 [GitHub 发布流程与恢复说明](docs/github-releases.md)。

## 许可

原有项目文档将许可证标为 MIT；仓库目前尚未包含独立的 `LICENSE` 文件。

**审核式提示词优化：**选择已保存提示词，核对发送给模型的模板原文与优化要求，比较建议后明确接受为新版本。不发送变量填写值，保留原始历史，并校验变量占位符及其数量。[使用说明](docs/ai-prompt-refinement.md)

还可在接受前试运行原模板与未保存提案：一次填写同一组临时变量，核对发送到同一模型的两条完整请求。答案仅临时显示，是否接受提案仍需另行决定。

### 用同一份完整提示词对比模型

提示词库的“对比模型”支持选择一至两个已保存的连接，逐一核对端点、模型及同一份完整提示词，再明确发送。各目标使用独立的临时密钥和权限操作，发送前显示最多请求数及分别收费提示。结果并排展示，可独立停止并逐份明确保存；不会自动调用或重试。详见[对比工作流与验证边界](docs/ai-model-comparison.md)。

### 核验此前的 AI 回答保存

如果保存已写入但回读失败，回答面板会保留原操作、标题及快照选项。点击“核验此前保存”只读取原操作回执，不重发模型请求、不写入或重存回答，也不请求新权限。只有原操作摘要与当前集合状态证据均有效时才解除锁定。确认的是历史保存成功，不保证回答当前仍在：它可能已被修改、移除或恢复。备份替换、回收恢复、回执过期或无法读取时可能无法核验；没有有效证据会继续保留原操作及锁定，不猜测成功。

### 从收藏继续上下文问答

当前未归档收藏的详情可点击「以此摘录继续提问」，在收藏页内打开同一个上下文问答面板。入口仅传递收藏 ID、记录版本和正文版本；面板重新读取并显示确切正文、来源标注及版本，点击「用于本次问题」时再次核验。过期、归档、读取失败或未完成的写入均不交接；不会把历史问题/来源快照或批注当作当前正文。原始 CRLF/CR 换行保留到完整请求审阅，实际编辑后使用编辑文本，「恢复原摘录」可恢复原始正文。

来源预览失效时，可直接点击旁边的「加载最新已保存来源」。成功后下方的已保存来源均不选中，需重新选择并审阅；上方旧预览不会被替换或恢复使用。问题、手动摘录及先前回答均保留，有旧勾选或编辑时会先确认，取消或读取失败保持原样。[恢复入口与验证范围](docs/ai-context-source-recovery.md)。

打开、审阅和选入均不发送、复制或保存；既有 prompt 模板仍可显式复用，之后仍须审阅完整问题。已有未保存问答需确认后才能替换，取消原样保留；等待期间的新编辑也不会丢失。此入口仅接入已完成初始化的工作区，不会从收藏页自动开始或恢复迁移；若提示工作区未就绪，先正常打开新标签页完成原有设置或恢复，再返回重试。保存回答或添加任务仍使用原有确认步骤和工作区校验。

配置导入遇到不确定的保存结果时，会通过本地记录核验原操作后再重试。旧版扩展可能拒绝打开包含此记录的工作区，请勿直接降级该配置。[导入中断保护与恢复范围](docs/settings-save-safety.md#导入中断后的保护)。
