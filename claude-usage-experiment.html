Experimental: Claude usage snapshot

Off by default · Manual reads only · Not yet tested with real accounts

A usage snapshot for the organization you select in this page session. Open claude.ai and sign in yourself, then enable this experiment and explicitly choose a tab and an organization each time.

When enabling, grant optional scripting and access only to https://claude.ai/* yourself in Chrome’s native permission dialog; Chrome may not show it again if already granted. The browser authenticates the read with the selected page’s existing session. Cookie and token values are not read or exported. Organizations and usage are not saved, and there is no background refresh.

This is not account binding and does not verify which account is signed in. Different accounts may have the same organization; close and select again after switching accounts. The page can influence the data, so results are not billing evidence. This is an internal API without a public stability guarantee and may change. Only used percentages are shown, not remaining quota, message counts or balance.

Closing clears this page’s in-memory results; it does not revoke permissions already granted in Chrome. You can revoke them in Chrome’s extension details. Under normal browser fetch behavior, an already-started read may continue until completion or its 10-second timeout. After closing, its result will not be displayed and no next-stage request will start.
