# Public fixture attribution

`tests/fixtures/claude-usage/public-window-sample.json` is a minimal transcription
of the two subscription windows in methol-dev/usage-bar's
[ClaudeWebMapperTests.swift](https://github.com/methol-dev/usage-bar/blob/f11d0cfadd298aac1772db6160deab22a942821f/macos/Tests/UsageBarTests/ClaudeWebMapperTests.swift).
The author describes that sample as an owner-captured July 2026 response, stripped
of unrelated fields. This project has not independently authenticated that claim
or performed a live Claude-account test. No organization or account identifiers
from that project are included. The implementation here is independently written.
