# Recommended modules

In Settings → Template & appearance, select a visual template, then choose **Preview recommended modules**. Review the current → recommended visibility of Tasks and Focus timer. **Apply recommended modules** saves those visibility choices in the current workspace; **Cancel** or Escape closes the review without changes.

Visual template selection still changes appearance only. Applying recommended modules changes neither appearance nor task content, previous task copies, timer duration/session, shortcuts, categories, or free positions. A hidden running timer keeps counting. You can change either module independently using the existing settings controls.

The 21 templates offer four deliberately small workspace combinations:

- Neither optional module: Clarity, Prism, Horizon, Dispatch, Bookmark, Dock
- Focus timer: Graphite, Atelier, Quiet, Library, Meadow, Paper
- Tasks: Folio, Ledger, Terrace, Column, Mosaic
- Tasks and Focus timer: Studio, Console, Blueprint, Today

The preview always shows both modules, including ones that will be hidden. No sample tasks are inserted, no timer is started or reset, and no remote service is enabled. Existing browser permissions stay unchanged. These device-local module choices and content remain excluded from settings backups, Drive backups, and Chrome Sync, and are retained by settings import/reset. Use the separate Tasks export, or select Tasks and Focus under Settings → Data → **Complete local backup**. Complete backup includes saved tasks and recovery history, plus Focus visibility and durations; running, paused or interrupted timer sessions and unsaved drafts are excluded. Choose **Prepare export summary**, review the scope, then **Download this backup** and check the browser download. See [complete backup](complete-backup.en.md).

Changing the visual template dismisses an open review. A task/timer edit after preview requires a fresh preview. Reapplying an already matching workspace writes nothing. While a save is pending, controls prevent duplicate actions and Cancel is unavailable. A storage error can mean part or all of a write succeeded: no automatic retry or rollback is performed. Preview again to inspect current visibility before deciding what to apply.

UI languages remain English and Simplified Chinese; Spanish documentation follows the existing project convention.
