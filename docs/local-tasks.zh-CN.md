# 本地待办

在设置的「模块显示」中启用「待办」。待办默认关闭，首次启用为空列表。隐藏卡片不会删除内容。

- **筛选任务**仅在本机按任务文字匹配待办、已完成和已移除的任务，忽略大小写与首尾空格。显示全部匹配的待办；展开**已完成**或**已移除**查看对应结果。**清除筛选**恢复之前的展开/收起状态。清除筛选后可调整任务顺序。筛选不会保存、不会搜索网络，也不会改变任务顺序、置顶、草稿或备份。
- 输入纯文本，按 Enter 添加；Shift+Enter 换行。支持中文和表情。
- 「批量添加待办」打开独立的纯文本编辑框，每个非空行按原顺序成为一项，保留空格、项目符号和重复行。「预览待办」先检查整批内容，显示编号列表、准确数量和剩余名额；只有「添加已预览的待办」才会一次性写入，全部成功或全部不添加。编辑草稿或观察到列表变化时，须重新预览；原有任务、置顶、历史副本和设置均保留。
- 预览和取消不写入数据。保存可能已成功但结果未能确认时，「重试上次添加」仍使用同一批已预览的内容，即使已经输入了新草稿。新草稿保留，须单独预览；若随后已有其他操作被确认，旧重试会要求重新检查。关闭窗口不会撤销已经开始的保存；草稿仅在当前页面内，关闭窗口或页面不会保存尚未提交的文字。
- 展开**已完成**，再点击**选择并重新打开已完成待办**。候选仅为打开窗口时实际显示、符合当前文字筛选的已完成项目；不加入未完成、已移除或隐藏的项目。初始不勾选，先预览完整编号原文及数量，再明确确认一次整批保存。选择、预览及取消均零写入。重新打开保留原文、列表位置、记录总数、恢复副本及**下一件事**，不新增撤销/重做；原有无关撤销在对应记录未变时仍可使用。
- 重新打开会在既有写入锁内复核所预览的列表 revision 及全部已完成成员的身份/版本；任一不符，整批停止。改选或观察到列表更新后需重新预览。保存未确认时保留原始编号预览与命令供明确重试，改选或关闭也不会改变它；后续修改或 receipt 过期将阻止旧重试。[验证范围与限制](tasks-batch-reopening-validation.md)。
- 未完成列表上方的「选择并完成待办」打开独立选择窗口，只包含打开时实际显示的未完成项目：收起时前四条、展开时全部、筛选时全部匹配。不会加入已完成、已移除或列表中不可见的「下一件事」。初始不选；可「选择当前列表全部」，也可逐项选择或取消。重复原文仍为不同记录，完整空格、换行、中文、表情及 HTML 字面量均保留。
- 「预览所选待办」只读取并核验所选身份与版本，不写入。编号预览按显示顺序列出每条完整原文、准确数量，以及是否会清除「下一件事」。改选或观察到列表更新会使预览失效。只有「确认完成这 N 项」才会在同一锁内一次完成整批，增加一个版本及一条确认记录，并核验完整回读；任一所选项目或已预览列表版本变更，都在写入前整批停止。仅清除属于所选项目的置顶，未选项目、原文、顺序和历史副本保持不变。
- 读取、写入或核验使保存结果未确认时，需明确「重试完成原来的 N 项」。即使改动勾选，预览和重试仍保留原来的不可变命令与确切列表；不会自动重放，也不宣称部分成功。关闭窗口无法取消已发写入；未确认的原操作仍可通过卡片「重试」访问，其他页面隐藏待办时也会暂时保留此入口，不改写隐藏偏好。后来已有其他保存，或确认记录已过期时，旧重试停止并要求重新检查。
- 「撤销这 N 项完成」与单条完成、移除共用本页的一个撤销位置。预览、取消及未确认保存不替换旧撤销；只有当前整批保存完整确认后才替换。明确撤销时一次重新打开整批：任一成员已被编辑、重新打开或移除，整批撤销停止，不会只恢复其余项目。无关改动及后来新置顶保留，不恢复旧置顶。没有持久化撤销队列或整批重做，刷新会清除此位置。完成不会释放容量，已完成项目仍计入 500 条总记录。[模型验证与原生浏览器限制](tasks-batch-completion-validation.md)。
- 点击圆形按钮完成或重新打开待办；展开「操作」可编辑、置顶下一件事、上下移动、移到列表首位、移到列表末位或移除。
- **移到列表首位**可一次保存，将未完成的待办移到最前，其他待办保持相对顺序。移后的任务会出现在收起时的四条预览里，刷新后保留新位置。这项操作调整列表顺序；**设为下一件事**则选择独立显示的**下一件事**。移首不会改变置顶、任务文字、完成状态或恢复副本。首项或筛选中不可移首。如果其他页面在保存前修改该任务或待办顺序，请先检查最新列表再操作。
- **移到列表末位**可一次保存，将未完成待办移到最后，保留其他未完成待办的相对顺序、已完成/已移除记录的绝对位置、文字与日期、恢复副本及**下一件事**。刷新后保留新顺序；末项或筛选中不可移末。任务移出收起的四条预览后仍保持收起，只有该旧控件失去焦点时才回到快捷输入；移后仍显示则回到同项「操作」。不会抢走新草稿、搜索或编辑窗口的焦点。其他页面在保存前改变目标或未完成顺序会阻止整次移动；无关编辑与后来置顶会保留。[验证范围与原生浏览器限制](tasks-move-last-validation.md)。
- 三种状态的「复制原文」旁均有「用原文新建」，打开当前行已保存文字的独立可编辑快照。打开、编辑、取消不写入待办存储，也不使用剪贴板。只有点击「添加」才在当前工作空间末尾新建一条未完成待办；原记录及完成/移除状态、顺序、置顶、历史副本、撤销、快捷输入草稿和筛选保持不变。来源后续变化不会重写草稿，也不会引入源任务版本冲突。
- 多行仍属于同一项，编辑框内 Enter 换行。空格、HTML 字面量、中文和表情保留；未发生实际 input 编辑时，提交原始保存字符串，包含 CRLF/CR 换行。编辑后使用 textarea 值，浏览器的该值规范会将 CRLF/CR 归一化为 LF。原有 500 条记录、每项 1,000 个 Unicode 字符及 2 MiB 预算仍适用；拒绝时保留草稿，不截断文字或删除记录。
- 读取、写入或核验失败导致添加未确认时，「重试上次添加」显示并重试同一原文和同一操作，即使已经输入新草稿、改动后又改回或开始输入法组字。未解决旧尝试前，普通「添加」不可用。旧成功不会关闭更新的草稿；再次新建仍须明确点击「添加」。随后已有其他保存被确认时，旧 receipt 重试依既有规则停止并提示检查。这不会延长原有 128 条 receipt 的去重历史，不承诺 receipt 过期后的无限期防重。
- 新草稿保留离页/重载保护；其他页面隐藏待办时，当前草稿与在途保存仍可访问。工作空间离开、退役或暂停后阻止新提交。取消窗口无法撤回已经发出的写入；晚到结果不会清空其他草稿或抢走外部输入焦点。草稿仅在当前页面，不包含在备份里，「保存草稿」也不会自动添加此窗口内容。只有窗口仍拥有焦点时，关闭才返回同一源任务当前的按钮，或快捷输入框。[模型验证与未验证的原生行为](tasks-reuse-draft-validation.md)。
- 「复制原文」复制当前这一行显示的已保存待办文字；未完成、已完成和已移除均可用（前两类在「操作」内）。空格、换行、中文和表情逐字保留，不带日期、状态、ID、其他待办或未保存的编辑草稿。任务保存/读取异常、正在保存、编辑或导入窗口、隐藏或离开的页面暂不提供复制；导入/导出文件自身的错误提示与复制反馈分开保留。每次仅允许一个剪贴板请求，完成或失败后可再次点击。复制不读取或写入待办存储，也不主动联网；它复制页面当前已展示的保存版本，不会额外查询其他页面尚未通知到这里的更新。
- 复制结果单独显示在对应行，不替换保存错误、重试或撤销。剪贴板不可用或被浏览器阻止时，可选中原文手动复制；不会自动重试。等待期间编辑、移除、筛选、重绘、隐藏、离开或打开编辑窗口后，旧结果不再显示或移动焦点。已开始的系统剪贴板写入无法撤回，离开后仍可能完成；系统或其他软件可能同步剪贴板，扩展不控制这些行为。
- 未完成列表上方的「复制当前显示的待办（N）」按当前列表顺序复制带编号的纯文本快照：收起时为前四条，展开时为全部未完成待办，筛选时为全部匹配的未完成待办。已完成、已移除即使展开也不包含；「下一件事」不会重复加入。没有匹配的未完成待办时按钮禁用。每项原有空格、换行、重复文字、表情和 HTML 字面量均逐字保留，只新增 `1. ` 这样的编号前缀和项间换行，不带 ID、日期、草稿或历史副本。
- 展开「已完成」后，「复制当前显示的已完成待办（N）」按保存的列表顺序复制当前筛选显示的全部已完成项目。每项原文逐字保留，只增加编号前缀及项间换行；不含未完成、已移除、草稿或元数据，没有匹配项时禁用。已完成、未完成批量与单条复制共用本视图同一个在途锁。等待期间收起后再展开、打开批量重新打开窗口等会丢弃旧反馈，但必须等已发出的系统写入结束才能再复制。同一容器重复挂载仍使用原视图，不增加跨视图或全局剪贴板锁。[已完成复制检查与原生限制](tasks-copy-completed-validation.md)。
- 展开「已移除」后，「复制可见已移除任务（N）」按保存的列表顺序复制当前显示的全部已移除任务，包含从未完成或已完成移除的项目。筛选决定范围，收起时不可复制，零匹配时禁用。原有空格、换行、Unicode、重复文字和 HTML 字面量逐字保留；只新增编号前缀及项间 LF 换行，不额外添加末尾换行。输出不含未完成／已完成行、移除前状态标签、ID、日期、草稿或历史副本。三个批量按钮与单行复制共用本视图既有在途锁；来源失效、收起再展开、恢复再移除、窗口、错误及工作空间变化会丢弃旧反馈，但已发出的系统写入必须等完成或失败后才解锁。失败保留可选中的原文供手动复制，不自动重试或改变焦点。[已移除复制检查与原生限制](tasks-copy-removed-validation.md)。
- 批量复制与「复制原文」共用一个在途剪贴板请求及相同的可用性检查，不读取或写入待办存储。结果有单独提示，不替换保存错误、重试或撤销。等待期间改变筛选或展开状态、重绘、改变任务、打开编辑/导入窗口、隐藏、离开工作空间或销毁页面时，旧反馈会被丢弃；已发出的系统写入无法撤回，仍须等它完成或失败后才能再复制。已显示的成功提示是过去一次的结果，不代表剪贴板或后来的筛选仍保持相同内容。复制失败时可选中当前显示的原文手动复制。[模型检查与原生验证限制](tasks-copy-visible-validation.md)。
- 同时只能置顶一件事。点击「下一件事」旁的「完成」，即可完成四条预览以外或被筛选隐藏的置顶待办；文字本身仍是普通文本，按钮支持 Enter 和空格键。完成后清除置顶，不会自动选择下一件事。如果其他页面先修改了置顶或该任务，旧操作会停止并提示检查。仅在确认保存成功且您尚未转移焦点时，焦点才返回添加待办输入框。
- 「撤销完成」可重新打开最近成功完成的任务（包括「下一件事」），不会恢复旧置顶。它与「撤销移除」共用当前页面的一个撤销位置：最近一次完成或移除会替换上一次，刷新后清除。该任务后续被修改时无法撤销；其他任务和新置顶不受影响。保存结果不确定时，须主动重试并确认成功后才提供撤销。刷新后仍可展开「已完成」或「已移除」重新打开或恢复任务。
- 展开「待办数据」可单独导出、导入待办，或查看之前的本地副本。
- 选择本地副本的「查看并恢复」后，可展开默认收起的「这份本地副本的内容」，按副本原有顺序查看每条完整原文、未完成／已完成／已移除状态及「下一件事」标记。重复文字和换行均保留；空副本会明确标出。「移除前」表示之后恢复单条已移除待办时，会回到未完成还是已完成；恢复整份副本时，这些待办仍保持已移除。
- 预览只显示所选替换副本，不混入当前列表。打开、展开、收起和取消均不写入。预览与确认来自同一次成功读取的版本；其他页面更新不会改写已经打开的预览，旧确认会停止并要求重新检查。保存结果不确定时，仍重试同一个操作。文件导入的检查窗口保持原样。[模型验证与原生浏览器限制](tasks-recovery-preview-validation.md)。

待办只存储在此设备的扩展本地存储中。设置导出、Chrome 同步和 Google 云盘备份均不包含待办、已完成/已移除内容或历史副本。迁移设备或删除浏览器数据前，请单独导出待办。下载文件并不等于云端备份；卸载扩展或清除浏览器数据可能丢失本地待办。

重置设置、导入设置、应用 Chrome 同步或恢复云盘设置会保留待办及其本地恢复内容。同步更新需要重新加载时，未完成的待办草稿、编辑/批量添加/选择完成/导入窗口和进行中的保存会阻止自动重新加载。页面提供手动重新加载选项；丢弃草稿前会确认，进行中的保存须先完成。

导入待办使用单独的 JSON 格式，先验证完整文件、显示替换范围，再由您确认替换。替换前的列表保留为「之前的本地副本」。取消、无效文件或失败的替换不会清空现有列表。不提供永久删除或自动清理功能。

最多保留 500 条待办（包括已完成和已移除），每条最多 1,000 个 Unicode 字符，最多 8 份历史本地副本，整个待办集合/文件上限为 2 MB。达到限制会阻止新操作，不会悄悄截断文本或删除旧数据。导出不会释放容量；历史副本已满时仍可恢复其中一份，并保留当前列表。

不同页面可独立编辑不同待办。若同一条待办已被其他页面修改，或导入确认期间列表发生变化，旧操作会停止并提示检查最新内容；草稿仍保留。仅在读取存储并核对成功后显示保存完成。保存结果不确定且随后发生其他更改时，重试会要求检查，而不会假定旧结果仍然有效。

首版不提供提醒、日期、链接预览、外部账号或午夜自动重置。

含 8 个历史副本的备份可以导入没有待办记录、置顶项和历史副本的设备。仅在此情况下，不再额外保存空列表副本；所有导入的历史副本均予以保留。目标设备的显示设置保持不变，即使此前曾切换过显示状态。只要目标设备有未完成、已完成、已移除记录或任何历史副本，仍执行原有的保护和容量检查。恢复已有本地副本的行为不变。
