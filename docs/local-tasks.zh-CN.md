# 本地待办

在设置的「模块显示」中启用「待办」。待办默认关闭，首次启用为空列表。隐藏卡片不会删除内容。

- **筛选任务**仅在本机按任务文字匹配待办、已完成和已移除的任务，忽略大小写与首尾空格。显示全部匹配的待办；展开**已完成**或**已移除**查看对应结果。**清除筛选**恢复之前的展开/收起状态。清除筛选后可调整任务顺序。筛选不会保存、不会搜索网络，也不会改变任务顺序、置顶、草稿或备份。
- 输入纯文本，按 Enter 添加；Shift+Enter 换行。支持中文和表情。
- 点击圆形按钮完成或重新打开待办；展开「操作」可编辑、置顶下一件事、上下移动或移除。
- 同时只能置顶一件事。完成置顶待办后清除置顶，不会自动选择下一件事。
- 移除后可立即撤销，也可在重新加载后展开「已移除」恢复。
- 展开「待办数据」可单独导出、导入待办，或查看之前的本地副本。

待办只存储在此设备的扩展本地存储中。设置导出、Chrome 同步和 Google 云盘备份均不包含待办、已完成/已移除内容或历史副本。迁移设备或删除浏览器数据前，请单独导出待办。下载文件并不等于云端备份；卸载扩展或清除浏览器数据可能丢失本地待办。

重置设置、导入设置、应用 Chrome 同步或恢复云盘设置会保留待办及其本地恢复内容。同步更新需要重新加载时，未完成的待办草稿、编辑/导入窗口和进行中的保存会阻止自动重新加载。页面提供手动重新加载选项；丢弃草稿前会确认，进行中的保存须先完成。

导入待办使用单独的 JSON 格式，先验证完整文件、显示替换范围，再由您确认替换。替换前的列表保留为「之前的本地副本」。取消、无效文件或失败的替换不会清空现有列表。不提供永久删除或自动清理功能。

最多保留 500 条待办（包括已完成和已移除），每条最多 1,000 个 Unicode 字符，最多 8 份历史本地副本，整个待办集合/文件上限为 2 MB。达到限制会阻止新操作，不会悄悄截断文本或删除旧数据。导出不会释放容量；历史副本已满时仍可恢复其中一份，并保留当前列表。

不同页面可独立编辑不同待办。若同一条待办已被其他页面修改，或导入确认期间列表发生变化，旧操作会停止并提示检查最新内容；草稿仍保留。仅在读取存储并核对成功后显示保存完成。保存结果不确定且随后发生其他更改时，重试会要求检查，而不会假定旧结果仍然有效。

首版不提供提醒、日期、链接预览、外部账号或午夜自动重置。
