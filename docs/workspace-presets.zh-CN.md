# 推荐模块

在「设置 → 模板与外观」选择视觉模板后，点击「预览推荐模块」。确认待办和专注计时器当前 → 推荐的显示状态，再点击「应用推荐模块」。点击「取消」或按 Escape 关闭预览，不会改变设置。

单独选择视觉模板仍只影响外观。应用仅调整当前工作区中这两个模块的显示状态，不改变外观、待办内容和历史副本、计时器时长与会话、网站、分类或自由布局位置。隐藏正在运行的计时器仍继续计时。也可在现有设置中独立调整模块。

21 款模板提供四种精简组合：

- 两个可选模块均隐藏：清晰、棱镜、地平线、速览、书签、停靠
- 显示专注计时器：石墨、编排、留白、书架、草间、便笺
- 显示待办：书页、条理、层台、专栏、拼贴
- 两者都显示：工作室、终端、蓝图、今日

预览明确列出两个模块，包括将被隐藏的模块。不会插入示例待办、启动或重置计时器、启用网络服务或增加权限。模块显示状态与内容均为本地数据，不进入设置备份、云盘备份或 Chrome 同步；导入或重置设置也会保留它们。可使用单独的待办导出，或在「设置 → 数据 → 完整本地备份」选择待办和专注模块。完整备份包含已保存的待办与历史副本，以及专注显示状态和时长；不包含正在运行、暂停或中断的计时会话，也不会代保存草稿。先「准备导出摘要」，核对范围，再「下载这份备份」并检查浏览器下载。[完整备份说明](complete-backup.zh-CN.md)。

切换视觉模板会关闭预览。预览后若待办或计时器有变化，必须重新预览。重复应用相同显示状态不会写入数据。保存期间禁止重复应用和取消。存储错误可能意味着部分或全部设置已保存，因此不会自动重试或回滚；请重新预览确认当前状态，再决定是否应用。
