# 推荐工作空间

在「设置 → 模板与外观」选择视觉模板后，点击「预览推荐工作空间」。确认待办和专注计时器当前 → 推荐的显示状态，再点击「应用推荐工作空间」。点击「取消」或按 Escape 关闭预览，不会改变设置。

单独选择视觉模板仍只影响外观。工作空间仅调整本设备上这两个模块的显示状态，不改变外观、待办内容和历史副本、计时器时长与会话、网站、分类或自由布局位置。隐藏正在运行的计时器仍继续计时。也可在现有设置中独立调整模块。

15 款模板提供四种精简组合：

- 两个可选模块均隐藏：清晰、棱镜、地平线
- 显示专注计时器：石墨、编排、留白、书架、草间
- 显示待办：书页、条理、层台、专栏
- 两者都显示：工作室、终端、蓝图

预览明确列出两个模块，包括将被隐藏的模块。不会插入示例待办、启动或重置计时器、启用网络服务或增加权限。模块显示状态与内容均为本地数据，不进入设置备份、云盘备份或 Chrome 同步；导入或重置设置也会保留它们。待办需使用单独的导出功能备份。

切换视觉模板会关闭预览。预览后若待办或计时器有变化，必须重新预览。重复应用相同显示状态不会写入数据。保存期间禁止重复应用和取消。存储错误可能意味着部分或全部设置已保存，因此不会自动重试或回滚；请重新预览确认当前状态，再决定是否应用。
