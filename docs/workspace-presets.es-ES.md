# Espacios de trabajo recomendados

En Ajustes → Plantilla y apariencia, selecciona una plantilla visual y pulsa **Preview recommended workspace** (Vista previa del espacio recomendado). Revisa la visibilidad actual → recomendada de Tareas y el temporizador de concentración. **Apply recommended workspace** aplica esas opciones en este dispositivo; **Cancel** o Escape cierra la vista previa sin cambios.

Cambiar la plantilla visual sigue afectando solo a la apariencia. Aplicar un espacio cambia únicamente la visibilidad de los dos módulos: conserva tareas, copias anteriores, duración y sesión del temporizador, sitios, categorías, posiciones libres y apariencia. Un temporizador en marcha sigue contando aunque esté oculto. Puedes ajustar cada módulo por separado en sus controles habituales.

Las 15 plantillas ofrecen cuatro combinaciones sencillas:

- Ningún módulo opcional: Clarity, Prism, Horizon
- Temporizador: Graphite, Atelier, Quiet, Library, Meadow
- Tareas: Folio, Ledger, Terrace, Column
- Tareas y temporizador: Studio, Console, Blueprint

La vista previa muestra ambos módulos, incluidos los que se ocultarán. No añade tareas de ejemplo, no inicia ni reinicia el temporizador, no activa servicios remotos y no cambia permisos. Las opciones y el contenido de estos módulos permanecen en el dispositivo: se excluyen de las copias de ajustes, Drive y Chrome Sync, y se conservan al importar o restablecer ajustes. Para guardar las tareas, utiliza su exportación independiente.

Cambiar la plantilla cierra la vista previa. Si cambian las tareas o el temporizador después de revisarlos, debes obtener una nueva vista previa. Reaplicar las mismas opciones no escribe datos. Mientras se guarda, se bloquean las acciones duplicadas y la cancelación. Un error de almacenamiento puede significar que se haya guardado parte o todo el cambio: no hay reintentos ni restauraciones automáticas. Abre otra vista previa para comprobar el estado actual.

La interfaz continúa disponible en inglés y chino simplificado; esta guía mantiene la documentación en español del proyecto.
