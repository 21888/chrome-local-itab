# 提示词库

从新标签页的「提示词库」入口打开。提示词属于同一浏览器配置中的全局资料库，可跨工作空间复用；当前版本不会自动读取 AI 网站、执行模型请求或上传内容。

## 保存与复用

创建提示词并填写标题和正文，可以添加分类、标签、工具备注和收藏。搜索会匹配标题、正文及这些备注。内容按纯文本显示，代码和 HTML 不会被执行。

正文中的 `{{主题}}` 可作为变量。同名变量只填写一次；空字符串需要明确选择，避免漏填被当成有效输入。变量值只用于当前页面的预览和复制，不进入历史版本或备份。遇到不希望替换的花括号，可以选择原文复制模式。

复制将内容放入系统剪贴板，粘贴到外部 AI 产品后，其处理规则由该产品决定。请不要在可公开分享的示例、截图或提示词中保存密钥。

## 编辑、版本和冲突

正文修改会保留版本；修改标题或标签不会增加正文版本。恢复历史正文会追加一个新版本，不会抹除后来的记录。未保存草稿留在当前页面，离开前请保存或导出需要的内容。

两个页面同时编辑同一条提示词时，过时的保存会被阻止。先查看已保存内容，再决定保留草稿、另存为新提示词或明确放弃。写入结果不确定时保留原操作，不能靠连续点击制造多个副本。

回收站可恢复提示词及历史，不提供永久删除，也不会自动清空。数量上限包含回收站；单条正文最多 32,000 字符，最多 20 个正文版本，资料库最多 200 条、2 MiB。达到版本上限可另存为新提示词，原记录继续保留；达到资料库容量上限时先导出整理，不会自动挤掉旧记录。

## 备份

进入「设置 → 数据 → 完整本地备份」，明确选择提示词模块。恢复前先检查目标和条数，保存页面草稿，并下载需要保留的恢复副本。提示词作为全局资料保存一次，不会因为有多个工作空间而重复复制。

旧版不含提示词的备份不会自动清空现有提示词。恢复结果不确定时按界面检查候选副本；应用会阻止可能覆盖数据的后续写入，不会静默回滚。备份文件含用户文本，请自行保管。

本指南描述使用方式；原生界面、剪贴板与故障验收范围以实际测试记录为准。
