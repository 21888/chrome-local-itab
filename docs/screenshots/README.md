# Local iTab screenshots

These are native Chrome for Testing extension screenshots from the runtime published as `9ce9ccc5eb958607a6d0f59d0c0c143ce2da9f71`. The captured source revision `eafb2b0d840aebb4977c4cece0b9a8d9e465ae67` has the identical tree `d17cd2d634885db58bd8d5b8e460bed716b1ba08`.

The seven PNGs cover Clarity, Graphite, and Folio in light/dark Grid mode, plus a Free-mode example. They show the English interface and a synthetic setup with Chinese category names. Weather, topic, and movie content is manually entered sample data, not live information. Icons and the sample poster are original embedded local images. Online favicons, Chrome Sync, and Drive authorization were off; example websites and searches were not opened.

Capture: Chrome DevTools device toolbar, Responsive **1366 × 768 CSS pixels**, Desktop, **DPR 1**, using **Capture screenshot**. Each original PNG is **1366 × 768 pixels**, copied unchanged. These are viewport captures rather than full-page captures. Below-fold content remains below the fold; in Folio, the first two category groups and sample weather/topics are visible while other groups and the movie card continue below.
