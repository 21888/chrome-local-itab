# 十五种工作台模版

在新标签页的外观选择器或设置中选择模版，每种均可独立切换浅色/深色。原有「澄明」「墨序」「拾页」保持可用；新增十二种通过字体、导航、快捷方式编排和间距呈现不同风格。

- 编排：编辑式页眉、衬线标题、细分隔线与顶部导航
- 留白：居中画布、宽松间距和柔和矩形卡片
- 工作室：带边框的侧栏与错层卡片边缘
- 终端：等宽字体和紧凑的分组命令行式列表
- 棱镜：几何轮廓、不对称圆角和醒目标题
- 书架：衬线分类标题与阅读资料式分组
- 地平线：突出时钟、居中搜索和横向网站条目
- 条理：密集小图标索引、对齐分组与紧凑导航栏
- 草间：开阔居中布局、圆润卡片和衬线标题
- 蓝图：技术字体、方形网格与辅助线细节
- 层台：圆角分组面板与次级导航栏
- 专栏：编辑式左侧导航，启用可选卡片时在宽屏显示右侧区域

切换只改变外观，不替换网站、分类、待办、自定义背景、网格/自由/吸附模式或已有坐标。已有背景图和标题颜色仍然生效，因此最终对比度也取决于您的图片和颜色选择。自由布局保留同一坐标平面，不强制套用网格分组。

模版使用已经启用的真实模块，不生成示例待办、不启用联网功能，也不会自动应用功能组合。模块显示仍在设置中单独选择。无需新增资源下载、权限或账号。

下方画廊包含新增十二种模版的真实浅色和深色截图；README 同时保留原有 A/B/C 与自由布局截图。截图仅展示捕获时可见的页面区域，不能代替交互、响应式或辅助技术验证。
