# 独立工作空间

工作空间把网站、分类、布局、外观、待办、便笺、倒计时和专注状态分开保存。它不是账户、权限隔离区或隐私保险箱；同一浏览器配置中的用户仍可访问这些空间。

## 使用

- 新标签页顶部切换当前空间；「设置 → 工作空间」可新建、改名、复制、移到回收站和恢复。
- 切换弹窗可按实际显示名称搜索：使用打开时已加载的正常空间快照，按字面子串匹配，忽略大小写与查询首尾空白，不搜索 ID 或回收站。清除后恢复原顺序，同名空间分别保留，当前空间计入结果，但本页打开按钮禁用。后台刷新不改变本次列表或输入；关闭重开时清空查询并使用最新已加载列表。输入、清除或按 Enter 不会自动切换；点击空间名称按钮仍经过下述保存等待与草稿确认。
- 「设置 → 工作空间」的「上移 / 下移」每次交换一个相邻正常空间，跳过回收站；默认空间也可移动。首尾按钮禁用。排序只改变列表顺序，不切换空间，也不保存草稿或改变专注计时。其他页面刚改过列表或保存结果无法确认时，会停止并刷新，需先检查新顺序再决定下一次移动。已打开的切换弹窗仍保持本次快照，关闭重开后显示最新已加载顺序。
- 每个已打开页面固定属于打开时的空间。其他页面切换不会把它悄悄变成另一个空间；普通新标签页采用最后选择的空间。
- 切换前会等待正在保存的操作。未保存编辑可选择留在原处、保存后切换或明确放弃。保存失败或发生冲突时，保留草稿并停止切换。
- 复制只复制已保存内容，不复制页面草稿，也不启动一个复制的专注计时器。
- 删除是移入回收站。恢复会产生新的编辑代次，旧页面不能继续写入恢复后的空间。运行中的专注在删除时暂停，恢复不自动计时；已暂停或已完成的状态保留。
- 默认空间用于兼容旧数据和已有云配置，因此不能移到回收站。最多保留 100 个空间（包含回收站），不会为腾出位置自动永久删除旧内容。


### 在新标签页打开

切换弹窗每个正常空间旁都有独立的「在新标签页打开」链接，包括当前空间。同名空间按各自 ID 打开。原生链接固定进入 `newtab.html?workspace=…`，不携带当前页其他查询参数或 hash。

本次入口保留原页和未保存草稿，不选择空间、不保存草稿、不暂停自动保存、不等待正在进行的操作，也不控制原页专注。普通新标签页仍使用最后选择的空间；另开指定空间不会改变这个默认值。新页仍正常启动、读取和初始化专注，运行中的时间正常推进。

筛选重绘或关闭后，旧链接会移除地址。已知目标被删除或代次改变时，该行操作会失效；列表读取失败或冲突会使本次弹窗的旧操作全部失效。后续刷新不会复活它们，需关闭重开后查看最新列表。若激活后目标才被删除，新页会校验并拒绝，不回退到其他空间；这不是跨标签页原子性保证。键盘和中键行为交给浏览器处理，页面不宣称已经成功打开新页。[自动化范围与未测浏览器项目](workspace-picker-new-tab-validation.md)。

## 升级和备份

首次升级会把现有内容保留到 Default。激活前先保存并读回验证原数据副本，再暂存新结构。若发现无效数据或写入不确定，会停止而不是用空白数据覆盖。多步存储不是断电级原子事务。

完整本地备份的新格式覆盖所有正常空间和回收站中的空间。可选择模块；完整替换与选定模块恢复有不同范围，必须先看预览。部分模块恢复要求空间结构匹配，不能暗中新增或删除未选择空间。旧版单空间备份需要明确选择目标空间，其他空间保留。

恢复前建立经过验证的完整恢复副本。旧页面在空间被替换、删除或恢复后失效；其未保存文字仍可复制或导出，然后明确重新打开。

如果旧版页面在迁移后继续写入旧存储，会显示冲突并暂停写入。先关闭旧页面，下载并检查两份数据，再选择「保留当前工作空间并保留旧标签页副本」。此操作保存两份内容，不自动合并、删除或重新加载；预览后内容再次变化时必须重新检查。

## 云服务与设备设置

- Chrome Sync 与 Google Drive 暂时仍只对应 Default 的原有配置范围，不会自动同步全部空间或个人模块。
- 隐私偏好、服务商设置和更新偏好仍属设备级状态，不跟着每个空间复制。授权信息不进入便携备份。
- Default 配置恢复或重置后可能出于安全原因暂停自动同步，需要按提示检查；其他空间重置不改变全局云偏好。
- 本功能不增加浏览器权限。完整备份仍有体积限制，不能因空间多就视为无限存储。

真实浏览器验证与自动化验证是不同证据。发布说明应列出实际通过范围和未验证场景，不把本指南当成验收记录。
