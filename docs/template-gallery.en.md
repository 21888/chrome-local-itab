# Fifteen workspace styles

Choose a style in the new-tab appearance selector or Settings. Each has independent light/dark colors. The original Clarity, Graphite and Folio styles remain available; the twelve additions use different typography, navigation, shortcut composition and spacing.

- Atelier: editorial masthead, serif headline, fine rules and top navigation
- Quiet: centered canvas, generous spacing and soft rectangular tiles
- Studio: framed sidebar and offset card edges
- Console: monospaced type and compact grouped command rows
- Prism: geometric outlines, asymmetric corners and a bold headline
- Library: serif section names and ruled reading/reference collections
- Horizon: prominent clock, centered search and horizontal launch tiles
- Ledger: dense small-icon index, aligned sections and a compact rail
- Meadow: open centered layout, rounded tiles and a serif headline
- Blueprint: technical typography, square grid and guide-line details
- Terrace: rounded grouped panels and a secondary navigation rail
- Column: editorial left rail with a right-side area when optional cards are visible

Selecting a style changes appearance only. It does not replace shortcuts, categories, task content, custom backgrounds, Grid/Free/snap selection or saved coordinates. Existing custom background and title-color choices still apply, so their contrast depends on the chosen image/colors. Free layouts keep their single coordinate plane instead of applying grouped Grid composition.

Styles use the real modules already enabled on your dashboard. They do not create sample tasks, enable online features or apply a functional preset. Optional module visibility remains a separate settings choice. No new asset download, permission or account is required.

The gallery below contains actual light and dark captures of all twelve additions; the README also retains the original A/B/C and Free-layout screenshots. Captures show only the visible area at capture time and do not replace interaction, responsive or assistive-technology testing.
