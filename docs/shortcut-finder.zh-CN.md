# 查找已保存的网站

点击快捷方式标题和布局控件旁的「查找已保存的网站」。此独立本地面板默认按网站标题、地址、分类名称及可用的内置用途／别名搜索当前工作空间的所有分类，不会把查询发送给网页搜索服务。

- 使用**按分类筛选**可精确浏览该分类，无需输入文字，也可叠加文字查询。分类后的数量为文字筛选前已保存的网站总数；结果数量同时反映两个筛选条件。空分类仍可选择。分类名称记录被删除后仍保留所选标识：仍属于该标识的网站会继续显示，并以标识作为分类名称；该标识下没有网站时才显示零条结果，不会自动扩大范围。清空同时重置文字、分类和匹配方式，关闭后也不保留。分类选择框保留原生键盘操作。
- 焦点位于页面内的非编辑区域时，按 **/** 可打开同一面板；网页搜索模块隐藏时也能使用。按实际输入的字符识别：如果键盘需要 Shift 才能输入 /，可保留 Shift；不处理 Ctrl、Alt、AltGraph 或 Meta 组合键。输入法组词、重复按键或其他对话框、菜单打开时不触发。输入框、选择框和范围控件保留原有按键行为；普通按钮和链接上可以使用此快捷键。浏览器和地址栏快捷键不变。
- 如需关闭此单字符快捷键，请在**设置 → 快捷方式 → 模块显示**中取消勾选**使用 / 打开「查找已保存的网站」**并保存。打开新标签页，或先完成当前操作再刷新已有标签页。关闭后仍可点击**查找已保存的网站**按钮，且不再显示 / 快捷键提示。重新启用也需保存并刷新。旧配置默认启用；此偏好包含在设置备份和可选的配置同步中，不保存查询内容。
- **匹配方式 → 连续短语**为默认方式：完整查询需连续出现在同一标题、地址、分类或单条内置用途／别名中，查询中间的空格和标点按原文匹配。
- 选择**匹配方式 → 所有词**，可用空格或其他空白（包括全角空格）分词。每个词都需出现在同一条网站记录的标题、地址、分类或内置用途／别名中，可跨字段、任意顺序匹配。例如 `GitHub 开发` 或 `github.com 开发` 都能找到「开发」分类下的 GitHub。每词按字面子串匹配；标点、引号、`OR` 和 `-` 不作为特殊语法，不做模糊匹配。
- 两种方式均忽略大小写和拉丁字母的规范重音差异，支持中文及其他 Unicode 文本，其余全角字符保留原样。选择全部分类且输入为空时只显示提示；只选分类时，两种方式均可浏览该分类。匹配方式只用于当前面板，切换时保留文字与分类，并回到第一页；清空或关闭后恢复连续短语。筛选操作不会自动打开网站。
- 当已保存网址与内置网站库中的条目对应时，也可按该条目的用途标签、本地化用途名称或别名查找；当内置字段补充了查询匹配时，结果会标明相应的用途／别名。只查找已经保存的网站，不会自动添加网站或联网补充资料。目录缺失或无效时，仍可按原标题、地址和分类搜索。
- 结果显示标题、分类和地址，重复网站仍保留独立条目，每页最多 50 条。
- 上下方向键可在当前面板内选择结果，再用 Enter 或空格激活按钮；Escape 关闭面板并将焦点返回打开面板前的位置。输入法组词不会提前打开网站。
- 清空或关闭即丢弃临时查询。查找不会改变快捷方式、分类、待办、布局或手动坐标。

明确点击结果时会暂时打开一个空白标签页，并读取最新保存的记录进行核对。已删除或发生变化的结果不会打开，而会刷新并提示重新选择。读取失败可重试。取消只关闭本次操作仍拥有的空白页；如果您已自行导航该标签页，不会覆盖或关闭它。有稳定标识的重复记录分别核对，缺少标识且无法明确区分的旧重复条目会被拒绝，不会猜测目标。

打开所选网站属于正常导航，可能使用网络。输入、翻页和关闭不调用外部服务，不读取浏览记录或剪贴板，也不保存查询。面板或目标核对尚未结束时，设置更新不会自动重新加载并丢弃当前操作。

## 复制已保存的网址

每条结果有独立的**复制网址**按钮。可直接点击，或用 Tab 到达后按 Enter／空格。上下方向键仍只遍历原来的打开网站按钮。复制内容是保存的网址原文，包括无协议地址、Unicode、百分号转义、查询参数顺序和片段；不附加标题、分类或工作空间名称，不规范化网址。非法地址或内嵌用户名／密码的网址不能复制。

复制只同步检查已加载的结果及身份，不预留或打开标签页、不额外读取存储、不访问网站、不读取剪贴板、不请求权限，也不后台复制或启用旧式替代接口。接口缺失或写入失败时会提示，可重试或手动选择显示的网址。复制提示与打开网站提示独立。

Finder 同时最多有一项系统剪贴板写入，筛选、关闭重开或宿主重建都不会提前解除占用。已交给浏览器的写入无法撤销。新查询、翻页、筛选、范围、输入法组词、刷新、关闭及页面／节点生命周期变化会使旧提示失效；迟到结果不会抢焦点或在新面板宣告成功。离开并返回页面，或节点归属／可见性变化后，会提示修改查询或关闭重开后再复制。上一项系统写入实际结束前，不会开始下一项。

新增复制控件已有确定性 DOM 模型测试。2026-10-19 补充了中文深色 390px 合成生产界面的窄屏排版、键盘导航、关闭回焦点，以及英文宽屏查询和范围切换验收；未执行真实系统剪贴板或辅助技术播报测试，也不代表已安装扩展、真实数据保存或升级验证。[本轮范围与结果](saved-site-browser-acceptance.md)。

## 主动选择「全部工作空间」

在**工作空间 → 全部工作空间**中，可查找本设备所有未移入回收站工作空间的已保存网站，包括默认工作空间。结果明确显示来源工作空间；分类选择显示「工作空间 · 分类」。不同空间中的相同名称、网址、分类标识或复制的网站标识仍是独立条目。打开结果只在新标签页打开该网站，不切换当前空间、不更新最近使用记录、不修改待办、编辑草稿或布局，也不获取图标或预览。

每次打开面板都默认选择**当前工作空间**，保留其原有读取方式。切换范围保留查询与匹配方式，重置分类并重新检查。清空重置文字、分类与匹配方式，保留当前范围；关闭后全部丢弃。修改查询、筛选或范围，关闭面板、隐藏页面或收到相关数据变更时，会撤销待完成检查，并只关闭该操作仍拥有的空白标签页。仅开页核验有一项例外：本次点击预留的同一个空白页仍受本次操作拥有且可见时，允许它进入前台、暂时隐藏原页。该空白页隐藏、被手动导航或关闭、或无法核对为原空白文档时立即停止；隐藏原页不允许新搜索扫描或接收结果。离开或关闭原页也会撤销检查，即使它之前已被预留空白页遮到后台。每次打开均重新检查来源空间、代际、迁移来源、网址、分类及布局／设置标记；同一空间中没有稳定标识的歧义重复网址不会被猜测打开。

全部范围采用「全部可核验，否则不可用」：任一有效空间缺失、无法读取、格式错误、版本过新、存在冲突或超过限制时，不显示部分结果，也不会把检查失败说成没有网站。新建空空间合法；缺省 links/categories 表示没有已保存条目，不填入默认网站，明确存在但非法的数组仍拒绝。网址内嵌用户名／密码（含可识别的混淆写法）时，整个全部范围不可用，避免把凭据显示到结果中；原始记录不改动。普通查询参数不会被一概视为凭据。其他不支持的网址不能打开。可改用当前范围，或关闭后重新打开重试，不自动修复或恢复数据。

### 本地读取与并发边界

全部范围必须已有正常打开的当前会话，不初始化会话、不迁移、不调用同步或服务商、不切换空间、不写存储。读取固定 30 个控制／旧数据键，以及经过核验的注册表明确列出的现有有效空间 bundle，不读取回收站、孤立或历史代际 bundle，也不直接请求全局同步、隐私、提示词或 AI 摘录键。

Chrome 存储按顶层键返回完整值，不能只读取嵌套网站字段。因此 bundle 中的便签、待办和恢复内容，迁移前快照中的原始未知字段及服务商设置，恢复日志中的历史提示词／摘录数据，可能进入本地校验函数。它们校验后即丢弃，不参与搜索、不进入结果令牌或界面、不记录日志、不导出、不长期缓存、不传到网络。面板仅保留网站／分类投影、空间身份与名称及临时操作所有权。

支持上限：注册表 100 项、20,000 条网站、10,000 个显示分类选项（含孤立分类）、8 MiB 投影 JSON。原始数据每轮校验最多 64 MiB：初轮将完整控制键及全部有效 bundle 的返回 JSON 累计；末轮控制检查（打开时同时含目标 bundle）另有 64 MiB 预算；预先的元数据读取单独限额。重复读取不作为整个面板生命周期累计，64 MiB 也不是峰值内存承诺。固定键的字节预检并非原子操作，预检后数据增大仍可能先分配较大的返回值，再被校验拒绝。含大图片的 bundle 可能超限，不会被静默跳过或截断。

读取依次持有工作空间生命周期、待办、专注和本地写入锁。首末轮均在同一次原生读取中检查旧根数据与控制信息，打开前的末轮还包含目标 bundle；最终跳转在锁内同步执行。该协议串行化遵守锁约定的现有及旧页面写入，显式快照和存储通知提供额外检查。它不是浏览器事务，也不承诺发现最后快照返回后绕过全部锁且不发通知的任意写入。
