# 查找已保存的网站

点击快捷方式标题和布局控件旁的「查找已保存的网站」。此独立本地面板按网站标题、地址和分类名称搜索所有分类，不会把查询发送给网页搜索服务。

- 焦点位于页面内的非编辑区域时，按 **/** 可打开同一面板；网页搜索模块隐藏时也能使用。按实际输入的字符识别：如果键盘需要 Shift 才能输入 /，可保留 Shift；不处理 Ctrl、Alt、AltGraph 或 Meta 组合键。输入法组词、重复按键或其他对话框、菜单打开时不触发。输入框、选择框和范围控件保留原有按键行为；普通按钮和链接上可以使用此快捷键。浏览器和地址栏快捷键不变。
- 输入文字即可匹配，支持中文和其他 Unicode 文本，忽略大小写。空输入只显示提示，不会自动打开网站。
- 结果显示标题、分类和地址，重复网站仍保留独立条目，每页最多 50 条。
- 上下方向键可在当前面板内选择结果，再用 Enter 或空格激活按钮；Escape 关闭面板并将焦点返回打开面板前的位置。输入法组词不会提前打开网站。
- 清空或关闭即丢弃临时查询。查找不会改变快捷方式、分类、待办、布局或手动坐标。

明确点击结果时会暂时打开一个空白标签页，并读取最新保存的记录进行核对。已删除或发生变化的结果不会打开，而会刷新并提示重新选择。读取失败可重试。取消只关闭本次操作仍拥有的空白页；如果您已自行导航该标签页，不会覆盖或关闭它。有稳定标识的重复记录分别核对，缺少标识且无法明确区分的旧重复条目会被拒绝，不会猜测目标。

打开所选网站属于正常导航，可能使用网络。输入、翻页和关闭不调用外部服务，不读取浏览记录或剪贴板，也不保存查询。面板或目标核对尚未结束时，设置更新不会自动重新加载并丢弃当前操作。
