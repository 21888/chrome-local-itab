# 便笺文本副本

便笺是可选的纯文本功能，仅保存在当前设备的浏览器配置中。设置导出、浏览器同步和云盘备份不包含它。卸载扩展或清理浏览器数据可能删除内容。

“导出文本”下载当前草稿，包括未保存或存在冲突的文字。请分别保留需要的草稿。导入预览或保存失败期间仍可导出。

“导入文本”接受一个本地 UTF-8 .txt 文件，最多 128 KiB、32,000 个 Unicode 字符。无效编码、超限或读取失败不会修改便笺。空白、Unicode、表情、换行和开头的 BOM 字符都会保留；文本不会作为 HTML 执行。

只有便笺已加载、可见且没有未保存草稿或冲突时才能导入。选择文件只显示文件名、字符数、字节数和文本预览，不会保存。需要保留原文本时请先导出。“替换便笺文本”替换整份便笺。勾选“保留已保存内容并追加此文件”后，可以预览原文后接文件内容的完整结果，再点“追加到便笺”确认。只有两段文本均非空、且相邻边界都没有 CR 或 LF 时才补一个 LF 换行；原有空白、BOM 和换行均保持不变。预览及字符数、字节数对应最终完整便笺，合并后仍须满足原有限制。超限不会保存：可缩短文件，或关闭追加以预览替换。每次重新选文件默认使用替换模式。“取消”或 Escape 关闭预览且不写入。预览初始焦点位于取消；取消后回到导入，确认导入后回到编辑区。

编辑、输入法组合输入、重新读取或其他页面修改保存状态、读取错误和关闭卡片都会使预览失效。请基于最新保存内容重新选择文件。两种导入方式均检查保存版本；其他标签页的修改不会被静默覆盖。保存失败时，导入草稿留在编辑区，可重试或导出；冲突需明确处理。只有读取核验成功后才显示“已保存在此设备”。

不新增存储键、权限、网络请求、文件监视或导入历史。TXT 文件可能包含私人文字，请妥善保管。

## 当前编辑区行数

原有 Unicode 字符配额旁显示“行数：N”。空字符串为 0 行；任何非空文本（包括只有空格或制表符）至少为 1 行。CRLF 算一次换行，单独 CR 或 LF 各开始一行；末尾换行增加末尾空行，连续空行保留。视觉软换行、制表符、Unicode NEL/LS/PS 和零宽空格不作为这里的 CR/LF 换行。

两项数字在既有重绘时取同一个主 textarea 文本快照，包括已加载、未保存、只读保留、保存中、保存失败、冲突、超限和输入法组合期间的实际文字，不统计旁边的保存冲突预览或导入预览。原生 textarea 会将 CRLF/CR 转为 LF，因此以编辑区显示值为准，不套用控制器原始换行；统计本身不正规化、去除空白或截断任何文字。32,000 字符保存上限保持不变。统计是只读普通文本，不新增每次输入都播报的实时状态，不更改保存错误、重试、查找、复制或导入反馈，不移动光标、焦点或滚动，不增加计时器或后台索引。

[行数模型验证与原生边界](scratchpad-line-count-validation.md)。新增行数的原生 Chrome 绘制、窄屏换行、真实撤销/输入法和辅助技术阅读尚未验收。

## 复制冲突中的已保存版本

冲突显示“最新保存的文本”时，可在冲突操作旁点击“复制已保存文本”，保留这个版本，而不采用它或用本地草稿替换它。一次明确点击会把完整的已保存快照传入剪贴板，保留原始 CRLF/CR、首尾空白、BOM、表情、组合字符和字面标记；原生预览可能显示为规范化后的 LF。主草稿、主编辑区选区、查找内容和导入预览都不是本操作的来源。

已保存内容为空时会单独提示，不清空剪贴板；不完整 Unicode 也不会更改剪贴板。本入口要求已加载且可见的保存冲突预览，以及原视图和工作区。保存或通过“重试”/“使用已保存文本”读取期间、读取失败或存储失败导致保存未确认时不可用。保留的本地超限或非法草稿、既有冲突错误，不妨碍复制已知保存版本。暂时不可用采用 aria-disabled，使原生按钮能保留焦点；冲突预览结束时按钮一起隐藏。复制不读取或刷新存储、不编辑任何版本、不解决冲突、不移动焦点/光标/滚动位置，也不请求剪贴板权限。

三个复制入口共用本视图单个在途剪贴板写入。已保存文本的反馈仅归属于当前显示的版本号/内容，以及原节点和工作区。更新保存版本、解决冲突、更改展示、隐藏/移除/替换来源或离开页面后，旧反馈会失效。相同快照的刷新、选区变化或普通本地草稿编辑可保留正确反馈；IME 组合输入会保守地使它失效。已发出的写入不能撤回，即使关闭视图，其锁也保留到 promise 真正结算。失败后可明确重试或手动复制保存预览，没有回退写入、剪贴板读取或自动重试。操作系统和其他应用可能保存或同步剪贴板内容。

[已保存文本复制的模型证据与限制](scratchpad-copy-saved-validation.md)。此功能尚未验收真实系统剪贴板换行、浏览器激活/拒绝、物理键盘/IME、窄屏布局及辅助技术。

## 复制选中文本

先在主编辑区选中文字，再点击“复制当前全文”旁的“复制选中文本”。复制内容严格取自编辑区当前 UTF-16 选区：保留首尾空白、制表符、BOM、表情、组合字符、多行文字和字面标记。原生 textarea 会把 CRLF 和 CR 转成 LF，因此选区偏移和复制换行以这个 DOM 值为准；全文复制仍使用控制器保留的原始草稿。

空选区、非法或越界范围、切断代理对的选区不会写剪贴板，并给出提示。只有选中片段需包含完整 Unicode；片段外文字不完整，或选区本身超过保存限制，均不妨碍复制。已加载的保留草稿在保存中、读取或保存失败、冲突、超限时仍可复制。此操作不保存、正规化或编辑便笺，不解决冲突，不改变查找或导入状态，也不主动移动焦点、光标或选区方向。

三个复制按钮共用本视图一个在途系统写入及独立状态。选区变化、编辑、控件隐藏/脱离/替换、新挂载或工作区不可用会撤销过期选区反馈。已发出的写入仍可能完成，清理反馈不会提前释放写锁。失败后原选区仍可选取，可明确再次点击重试。没有读取剪贴板、权限预查询、旧式回退或自动重试。操作系统和其他软件仍可能保留或同步剪贴板内容。

[选区复制模型证据与原生边界](scratchpad-copy-selection-validation.md)。本项尚未验收真实系统剪贴板、原生浏览器激活/键盘/输入法、窄屏布局或辅助技术。

## 复制当前全文

点“复制当前全文”，把主编辑区的完整当前草稿交给系统剪贴板，包括未保存、保存中、冲突、保存失败和超限文字。取控制器保留的原始草稿，向剪贴板 API 原样传入 CRLF、空白、BOM、表情和字面标记；不复制旁边的最新保存文本或导入预览，不截断、不保存，也不解决冲突。空内容不会清空剪贴板；含不完整 Unicode 字符时需先修正。加载过的保留草稿即使因读取失败而只读，仍可复制。

原生按钮在点击时直接发起复制。独立的礼貌播报状态显示复制中、成功或失败，保留原保存警告，不改变焦点或选区。浏览器拒绝复制或不支持 API 时，可选中文字后手动复制，或导出文本。不新增权限申请、剪贴板读取、旧式复制回退、存储键或网络请求。系统剪贴板可能被其他应用读取，也可能参与操作系统的剪贴板历史或同步，复制私人文字时请留意。

同一卡片同时最多发起一次系统写入。编辑（包括改回原文）、输入法组合输入、隐藏页面或卡片、脱离页面、离开页面或销毁视图，都会使旧反馈失效。工作区身份与可用性在新复制、控制器重绘及在途写入结算时核验；届时工作区已不可用或身份变更，就不发起新写入或不展示在途旧回执。单独的工作区通知若未触发本卡重绘或生命周期事件，不会立即清除已经结算的成功提示。已提交的系统复制无法撤回，因此要等它结束后才能再次复制；重新显示不会自动复制。同文草稿的正常保存可以与复制同时完成，不会因为保存状态对象更新就错误地使回执失效。未加载、组字期间、页面或卡片隐藏、不可交互或脱离，以及工作区不可用时，不发起复制。“已复制”仅表示浏览器写入已完成且仍对应当前草稿，不表示便笺已保存。

[复制当前全文的模型验证与原生边界](scratchpad-copy-text-validation.md)。本项尚未验收真实系统剪贴板内容与换行表现、浏览器激活或拒绝、原生键盘与输入法、窄屏布局及屏幕阅读器播报。

## 在本页便笺中查找文字

打开“查找文字”，输入要查找的单行原文，再点“上一处”“下一处”，或在查找框内按 Enter。查找区分大小写，空格和标点参与匹配；不去除首尾空白、不做 Unicode 规范化、不使用正则表达式。支持完整的 Unicode 字符，包括表情；空查询不能定位。定位成功后，原有反馈显示“第n处/共m处”，按当前编辑区文本统计，包括重叠匹配。首次“下一处”选择第1处，首次“上一处”选择第m处，均不提示绕回；后续越过首尾时提示绕回，只有一处时再次定位也会提示。没有匹配时保留编辑区原来的选择，并清除旧数字。

主工具栏的“用选中文字查找”紧邻“查找文字”。先在主编辑区选择完整的单行文字，再点它，即可展开查找面板、用这段原文替换旧查询并聚焦查找框。选区的大小写、首尾空格、表情、组合字符和字面符号均原样保留，不依赖编辑区仍有焦点。只读取本次点击时主编辑区的文字与选区，不取旁边的保存预览、页面选择或历史选区；普通“查找文字”入口不会自动预填。

预填不会扫描、计数或定位；旧匹配反馈和按住 Enter 的状态会清除。之后明确点“上一处”“下一处”，或松开后在查找框按新的 Enter，才会定位。空选区、跨 CR/LF 换行、越界或包含半个代理对等不完整 Unicode 的选区不会替换旧查询，而会展开原面板提示先选择完整的单行文字。它不修改编辑区文字、选区方向、保存状态、错误、冲突或导入预览，也不访问剪贴板。已加载的只读保留草稿和超过保存上限的完整选区仍可预填。聚焦期间若文字、选区、查询或当前视图改变，就不再写入旧选区。

[选中文字查找的模型验证与原生边界](scratchpad-find-selection-validation.md)。按钮的原生 Enter/Space、鼠标与反向选择、输入法、Chrome 选择绘制、布局和辅助技术仍待真实浏览器验收。

只查找当前页面主编辑区里的文本，包括未保存、冲突、保存中、保存失败和超限草稿。32,000 字符是保存上限，不会截断查找范围。冲突时的已保存内容、导入预览和其他工作空间均不参与。修改查询或编辑区文本会清除旧结果，不移动焦点。输入查询时不计数；明确定位时才统计匹配、聚焦编辑区并选择文字，选择成功后才显示数字。非法查询或定位失败不会留下旧数字。Chrome 选择绘制及滚动可见性的限域实测见下方日期更新。查找不会编辑、保存、重试、处理冲突或改变导入预览；保存错误与查找反馈分别显示。

查找不接管浏览器 Ctrl/Cmd+F，正常编辑 Enter 的行为不变。按住用于查找定位的 Enter 后，焦点进入编辑区时的续发不会插入换行；松开后可正常输入新的 Enter。此保护由 DOM 事件流测试覆盖，尚未原生键盘复现。输入法组合输入、尚未加载、页面或卡片隐藏、节点脱离页面、祖先 inert 时不定位。关闭查找会清空查询和反馈；只有焦点仍在查找面板内时才返回“查找文字”入口。隐藏或销毁卡片会清空查找且不抢焦点。页面隐藏时清除匹配反馈，回来不会自动重新查找。不保存查询历史或匹配位置列表、不建立后台索引、不请求网络或写入存储。聚焦 DOM 模型测试覆盖偏移、匹配、选择失败与生命周期保护，不能替代原生键盘、输入法、窄屏和滚动验收。
