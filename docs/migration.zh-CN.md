# 更换浏览器或设备

确认新环境中的数据无误前，请保留旧环境。卸载扩展或清理浏览器数据可能删除本地内容。下载文件只保存在你选择的位置，不会自动上传或同步。

## 离开旧浏览器前

- **配置：**在设置的数据页导出设置 JSON，包含快捷方式、分类、布局、外观、本地图片及世界时钟的已保存列表和顺序；不包含**待办、专注计时器、便笺、倒计时**及其仅本设备保存的显示状态/偏好。Chrome 同步、云盘备份和配置恢复副本也不包含这些模块。
- **待办：**在待办卡片的“待办数据”中选择“导出待办”。独立 JSON 包含进行中、已完成、已移除的待办、置顶项和历史本地副本。请先完成编辑并确认保存；导出读取已保存数据。
- **便笺：**选择“导出文本”，保留当前可见草稿，包括未保存文字。不同标签页存在冲突时，请分别保留需要的草稿。
- **倒计时：**选择“导出文本”。卡片导出已保存值；设置页导出当前草稿，可能尚未完整或不符合保存要求。请检查文件中的名称和目标日期。
- **专注计时器：**手动记下专注/休息时长和显示状态。没有独立的偏好或计时状态导出/导入；正在运行或暂停的会话无法迁移。也请记下其他本地卡片的显示状态。

## 在新浏览器中

1. 安装新版 Local iTab。先导出目标环境已有的配置，再导入设置并确认替换。配置导入不会替换目标环境的个人模块。导入后请重新打开设置页和首页，避免继续使用恢复前的旧页面。
2. 按需开启待办，在“待办数据”中“导入待办” JSON。确认前检查替换内容；导入会替换目标列表与置顶项，并非追加合并。请先导出目标环境已有待办。[待办限制与恢复说明](local-tasks.zh-CN.md)。
3. 开启便笺，选择“导入文本”并选取 UTF-8 TXT 文件。检查预览，需要保留现有文本时先导出，再选择“替换便笺文本”并等待保存确认。取消不会修改数据。[便笺限制与恢复说明](local-scratchpad.zh-CN.md)。
4. 在设置中手动填写倒计时名称和日期、选择显示状态后保存。文本文件不是自动导入格式；不完整或无效的草稿需先修正。[倒计时说明](local-countdown.zh-CN.md)。
5. 手动设置专注时长与本地卡片显示状态，需要时开始新的计时。

月历依据设备本地日期标记今天，不保存浏览月份，无需单独迁移。

核对新浏览器中的配置、待办、便笺和倒计时后，再考虑删除旧环境或备份文件。导出文件可能包含私人文字与保存的网址，请妥善保管。
