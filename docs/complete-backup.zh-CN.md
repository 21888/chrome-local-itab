# 完整本地备份

在设置 → 数据 → **完整本地备份**中，可选择七个模块：配置（网站、分类、布局、外观、本地图片）、任务（含已保存历史）、便笺、倒计时、专注偏好、全局提示词库及全局 AI 收藏库。前五项按工作区保存；两个全局库由全部工作区共用，备份中各出现一次。

提示词包含归档记录、不可变正文版本与恢复历史；收藏包含归档摘录、注释、来源网址、精确提示词／正文版本关联与恢复历史。全局库的显示开关和未保存编辑不迁移。包含收藏的文件使用 schema 4；不含收藏但含提示词时使用 schema 3，仅工作区使用 schema 2，旧单工作区文件为 schema 1。

仅迁移已保存数据，请先完成保存。未保存的设置、任务编辑、便笺草稿、倒计时编辑、计算器输入及专注会话不会迁移。原有设置 JSON、任务 JSON、便笺 TXT、倒计时 TXT、书签 HTML 导出仍可使用；Chrome 同步、Google 云盘及配置恢复副本的范围不变。

## 下载前核对导出摘要

先保存要保留的数据，再选择“**准备导出摘要**”。准备只读取一次所选已保存模块，不下载、不写入。可核对模块名称、快照生成时间、JSON 精确 UTF-8 字节数、正常／回收站工作区身份数及既有模块统计。摘要只显示数量和已保存偏好统计，不展开工作区名称、网址、标题、笔记正文、提示词正文或收藏内容；动态状态只宣布已就绪，不朗读私人内容。

摘要另显示同一 UTF-8 JSON 的 SHA-256 指纹。计算在本地异步进行，无需等待即可下载；不可用时仍可下载。可与下载文件的 SHA-256 比较以核对字节，但它不证明下载完成、备份可恢复、文件来源可信或升级安全。取消或更换摘要后，迟到的计算结果不会覆盖新摘要。

工作区统计包含回收站；同一图片的重复引用分别计数。“至少一个工作区已启用”是跨工作区的或值，不表示全部启用。不会虚构或逐项列出跨工作区的专注时长、倒计时标题或日期。schema 1 只有一个工作区的模块内容，未记录正常／回收站身份；摘要会明确说明，并仅统计倒计时标题字符数，不展示标题或日期。每个所选全局库只计一次，包含正常／归档记录、已保存正文版本及历史副本数量。仅全局库文件仍包含工作区身份元数据，但不包含工作区模块内容，摘要会明确区分。

核对后选择“**下载这份备份**”，才请求摘要对应的确切 UTF-8 JSON 字符串。这是显示时间的已保存快照，后续保存不会被偷偷重读或混入；如需更新内容，请重新准备摘要。已就绪摘要及文件只暂存在当前页面、未加密；更改模块、选择新文件、取消准备、销毁视图或宿主／页面离开时会清除。摘要不构成恢复预览或替换授权。

准备期间可取消，不会下载或修改已保存数据、草稿。空选择不能准备文件。普通导出下载按钮对该快照只生效一次；请求未结束时，重复操作、取消和销毁不能假装撤回已提交下载。请求结束后会释放临时文件字符串和本地锁，即使宿主已离开。成功只表示已请求下载；出错时先检查浏览器下载列表再准备新副本，不自动重试。原有恢复前副本与中断恢复副本下载继续采用各自原有流程。

仍遵守 32 MiB 限制及大图片短暂停顿风险；摘要验证完全在本机进行，较大文件可能使页面短暂卡顿。不新增网络访问、权限、同步、服务商调用或遥测。

## 工作区与目标确认

备份包含全部现有工作区及回收站中可恢复的工作区。选择全部五个工作区模块可替换工作区列表、名称、顺序和回收站；部分恢复要求现有工作区与回收站身份匹配，不会新建、重命名、删除或复活工作区。仅恢复全局库不会替换工作区内容。

schema 2 及以上文件在选择全部五个工作区模块时，恢复预览还会显示默认收起的“工作空间名称与去向”。展开后即可看到三组名称及准确数量：备份带入、恢复后不再保留于当前列表与回收站、名称或状态变化。各非空分组独立默认收起，按需展开可查看每项完整稳定 ID；核对移出项时无需先展开带入项。空组明确显示 0，不提供空的展开控件。每行显示当前及恢复后的名称和正常／回收站／不存在状态；同名但 ID 不同的工作区分别列出，同一 ID 同时改名和改变状态只列一行。原有完整恢复前副本的保留语义不变。

清单仅描述已验证预览中的名称与成员状态，不表示恢复成功，也不会处理或解除中断恢复。即使名称与正常／回收站状态无变化，所选模块内容仍会替换，顺序和最近使用的工作区也可能改变；最终确认仍会核对已保存基线。重新选文件或修改模块时，会先清空并收起旧清单再检查；取消、预览失败和关闭视图也会清空。展开／收起本身不读写存储。旧单工作区、部分工作区及仅全局库恢复不显示此清单。

schema 1 文件需在预览中明确选择一个未删除的目标工作区，其他工作区不变，不能以回收站为目标。勾选提示词或收藏后，需分别确认其全局目标，并核对相同 ID 冲突。收藏保留精确的提示词与正文版本 ID；未一起恢复对应提示词时，关联可能无法解析，不会自动绑定同名提示词。

## 批量选择模块

可先点“**全部取消**”，再单独勾选便笺等一个模块。“**全选可用模块**”在尚未载入文件时勾选七个模块；文件检查完成后，只勾选该文件实际包含的模块，缺失模块仍禁用。这两个按钮只修改选择，不会自动导出或恢复；空选择不能导出或执行替换。

修改已载入文件的选择，会先清空旧预览与工作空间影响明细，再进行一次新预览。全部取消时保留文件和已知模块范围，以便重新选择，不会把空选择送入存储层预览。同一文件已经明确选择的目标会保留；全选不会代选工作区或两个全局库的目标，所有必需目标仍需分别明确选择，最终替换也仍需单独确认。全选五个工作区模块会恢复完整工作区替换范围及名称／状态影响清单，请重新核对这一更广的范围。

首次检查文件、等待大文件确认、导出或替换期间，批选按钮与模块复选框采用相同的禁用规则。文件模块范围已知后的再次预览期间仍可修改选择，旧结果不会覆盖新选择。重复全选或全部取消而没有改变勾选时，不重新预览，也不改变当前提示。专注会话、未保存草稿、配置导入及恢复保护继续生效。

## 导出与恢复

1. 勾选模块并选择“准备导出摘要”，核对后再选择“下载这份备份”。页面只能确认已请求下载，无法确认下载完成。卸载旧环境前请检查浏览器下载列表及保存位置。
2. 在目标环境先导出已有数据，并保存或另行保留草稿。选择完整备份 JSON（最大 32 MiB）；文件仅在本机读取。检查大图片备份时页面可能短暂停顿。
3. 核对所选模块、导入／当前数量及替换范围。修改勾选会重新预览；只替换所选模块的当前记录，不追加合并；全局库的恢复历史会保留并导入。未选模块与服务商／认证设置保持不变。
4. 目标设备的专注会话正在运行、暂停或中断时，无法恢复专注偏好。请取消勾选专注，或使用现有控件停止／重置计时后重新预览；不会静默停止计时器。
5. 明确选择“替换所选已保存模块”。保存前会再次核对数据版本；过期预览、当前设置页草稿及待处理编辑会阻止恢复。取消、文件读取失败和预览错误不会替换数据或丢弃草稿。
6. 等待确认结果后，再单独选择重新加载。不会强制刷新页面；请先保留新输入或其他标签页中的草稿。其他打开页面的数据版本冲突会保留草稿供处理。

## 恢复副本与失败处理

替换前会保存并读回验证恢复快照，包含全部工作区（含回收站）的五个模块，以及本次勾选的全局库；未勾选的全局库不进入该恢复副本；此步骤失败则不替换目标数据。仅保留最新一份完整恢复快照，启动下一次已确认的恢复操作可能替换该快照，即使最终替换未完成。如需保留已有副本，请先下载。这与任务模块内部的历史副本不同。

选择“下载恢复前的备份副本”，然后通过相同 JSON 预览流程导入；下载不会自动恢复。最终写入或验证失败时，部分数据可能已经改变。请核对已保存数据并使用恢复副本，不要自动重试。

组合恢复中断后，持久化的待恢复标记可能在重新加载后仍阻止写入。请使用页面提供的检查及单独确认恢复流程，核验旧状态后修复；不要反复导入，也不要认为刷新即可解决未确认写入。这不保证浏览器崩溃时的原子性。

文件可能包含私人笔记、提示词正文、收藏摘录、任务历史、完整网址及图片，请妥善保管。此功能不新增网络权限，也不会将私人模块加入云端备份。

文件未加密。AI 收藏中明确保存的历史问答快照会完整保留问题、来源摘录及标识、完整请求正文和当时的 endpoint／model；这些内容可能含私人资料或用户在正文中填写的秘密。独立收藏导出的“省略来源网址”不会删除该快照或历史 endpoint。分享前请审阅；详见[历史问答快照](ai-context-workflow.md#optional-historical-questionsource-snapshot)。

API-key 输入框及认证头不保存，也不进入备份。连接预设（名称、endpoint、model）另属于本设备偏好，不进入完整备份、独立导出、工作区复制或同步；恢复保留目标设备已有预设，不导入或授予接口权限。新设备需手动重建预设并按需单独授权。[连接预设说明](ai-model-workflow.md#device-local-connection-presets)。
