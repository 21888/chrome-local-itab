# 离线倒计时

在“设置 → 搜索与卡片 → 倒计时”中填写一个里程碑名称和 YYYY-MM-DD 格式的目标日期。日期必须是 0001-01-01 至 9999-12-31 之间的真实公历日期，名称最多 80 个 Unicode 字符。勾选“在新标签页显示倒计时”并保存。取消会重新读取最新保存的状态；放弃已编辑草稿前会询问确认。

卡片默认隐藏。它根据此设备的本地日历显示“还有几天”“今天”或“已过几天”，按日历日期计算，不按每 24 小时计算，因此不会因夏令时变化而偏移。返回页面或页面重新可见时立即刷新；卡片保持可见时，跨越午夜后最多一分钟更新。不含小时、重复事件、通知、定位或网络服务。

隐藏会保留已保存的名称和日期，可在设置中再次开启。编辑会打开倒计时设置，保存后会更新其他已打开的页面。未保存的草稿不会出现在卡片上。

倒计时单独保存在此设备的当前浏览器配置中，不包含在设置 JSON 导出、Chrome 同步、Google 云盘备份或配置恢复副本中。设置重置、导入和恢复都会保留倒计时。移除扩展或清除浏览器数据可能导致内容丢失。

“导出文本”会下载名称和日期。卡片导出已保存值；设置导出当前草稿，包括未填写完整的日期和过长的名称。恢复导出最多支持 32,000 个 Unicode 字符和 128 KiB。文本副本不支持自动导入，需要时可手动重新填写。

若编辑时其他页面保存了更改，您的草稿会保留，并显示最新保存值供对照。“载入已保存内容”会先确认再放弃草稿。“用我的草稿替换”也需确认；若保存值再次变化，仍会提示冲突。保存结果不确定时，“重试”会先核对存储内容，不会盲目覆盖。无法确认保存时，请先导出文本副本。损坏或不可读取的数据不会被默认值悄悄覆盖。
