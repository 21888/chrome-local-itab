# 从本地 HTML 文件导入浏览器书签

先从 Chrome、Edge 或 Firefox 将书签导出为 HTML，再打开 **设置 → 数据管理 → 导入浏览器书签**。选择文件，检查数量、跳过原因与文件夹到分类的对应关系，然后明确点击**应用**。取消或 Escape 只关闭预览，不修改数据。此功能独立于仍会整体恢复 JSON 备份的**导入设置**。

只接受 HTTP(S) 地址。已保存的地址和文件中的重复地址按规范化 URL 跳过，查询参数和片段仍有区别。无效地址、标题或重复 HREF 属性会在预览中计数。含直接有效书签的每个源文件夹都会创建一个新分类，名称为完整文件夹路径。不会与现有同名分类合并；重名会加后缀。根目录书签放入“导入的书签”，空文件夹不创建分类。

导入只追加数据，保留已有快捷方式、分类 ID、顺序、自由布局位置、设置、恢复副本、任务及专注数据。新书签使用本地 🔗 图标。已有身份标识的布局会为新书签分配新 ID，旧式布局保持原样。新书签仍可通过现有 JSON 备份正常导出、恢复。

文件仅在本地作为文本读取，不会被渲染为 HTML、由导入器上传或用于抓取图标。不需要浏览器书签权限、账号或新服务。请注意预览中的现有隐私设置：若 Chrome 同步已开启，保存后的快捷方式可能随后同步；若在线网站图标已开启，主页正常加载图标时可能访问服务商。导入器不会更改这些设置，也不代表整个扩展永不联网。预览后更改任一设置都必须重新预览。

请先保存分类编辑。预览不写入；应用会在本地写锁内重新核对快捷方式、分类、布局身份与隐私设置。其他标签页产生冲突时须重新预览，只有坐标发生变化时会保留最新坐标。保存中禁止重复应用及取消。若写入或回读确认失败，结果可能不确定；请刷新检查已保存数据或重新预览后再决定，切勿假定完全未保存。不会自动重试或回滚。

文件读取前限制为 10 MiB；最多扫描 10,000 条书签，追加 2,000 个链接、200 个分类，文件夹最多 16 层。格式损坏或超过限制会整批拒绝，不会静默截断或修复，请从浏览器重新导出。现有本地数据过大或损坏时也会安全拒绝，不清洗或丢弃原数据。具体规则见[解析器说明](bookmark-import-parser.md)。

界面提供英文和简体中文。自动化样本覆盖 Chrome、Firefox 和 Edge 导出格式；正式发布前仍应对最终解压扩展进行 Chrome 原生文件选择、键盘、辅助技术与视觉检查。
