## Custom-engine editor draft ownership — 2026-10-09

The mounted custom-engine URL editor keeps its current text across engine-selection roundtrips. Its exact value is compared with the last successfully saved baseline, so deleting an existing template to an empty draft and hiding a changed editor both defer an applied-Sync reload. Untouched/reverted values and a successfully saved unchanged draft release this ownership. Detached and superseded editors do not own reloads or start new writes.

Only explicit valid Save persists the editor's custom URL. Selection persists the previously saved template. This mount's configuration writes are serialized so a selection queued behind Save retains the newly saved template. This is a local ordering guard, not a cross-tab/settings transaction or global CAS. A write already started before detachment cannot be canceled. Remounts intentionally initialize from supplied settings; draft text is never persisted.

Pending Save and active custom-field composition retain ownership; duplicate Save is ignored. Custom-field Enter and Save-button default Enter are guarded during composition and key repeat. Save completion updates the saved baseline but cannot replace newer input edits, reset a newer engine choice, or update a detached/replaced editor. Failed/rejected storage writes preserve draft text. Invalid URLs never reach storage. The existing search feedback, navigation, calculator and Finder implementations are preserved.
