# AI 结果收藏（未发布集成候选）

从新标签页的「AI 收藏」打开。收藏保存在当前浏览器配置的本地存储中，是所有工作区共用的一份资料库，切换或复制工作区不会产生独立收藏库。

本功能只保存你手动提供的摘录，并非完整对话备份。不会自动读取 AI 网站、抓取对话、读取剪贴板、预览来源网页或调用模型服务。工具 / 模型标签只是你的备注，不代表已验证的生成来源。

## 收藏与查找

1. 选择「收藏摘录」，填写标题和原文摘录，按需添加注释、类型（回答、代码、计划、其他）、标签、工具 / 模型标签和来源网址。
2. 标签可用英文逗号、中文逗号或换行分隔，不可重复（忽略大小写）。来源可留空；填写时须为不带账号密码的 HTTP(S) 网址。
3. 选择「保存到本地」。正文和来源相同的已有记录（含归档）会触发重复提示；确认后仍保存为独立记录，不自动合并。
4. 搜索匹配当前已保存的标题、摘录正文、标签及注释（批注），不区分大小写；多个空白分隔的关键词须全部命中，可分别命中不同字段。搜索与类型、工具、标签筛选取交集，「已保存」和「已归档」保持隔离。来源网址、历史正文、恢复快照、上下文快照和未保存草稿不在搜索范围内；工具名称可通过专用筛选选择。详见[收藏页批注搜索](collection-annotation-search.md)。

在已保存或已归档摘录详情中，点击真实标签可按完整标签精确筛选（`a` 不匹配 `ab`，导入标签中的逗号和 Unicode 保持原样）。类型和工具仍是文字。标签与当前搜索、类型、工具及归档范围取交集；点击不会切换详情、清空草稿或写入存储。侧栏标签下拉和按钮选中状态同步，可用「清除筛选」取消。

内容按纯文本显示，保存的代码和 HTML 不会执行。「复制摘录」只复制当前正文，不附带注释；剪贴板被阻止时可选中文字手动复制。点击来源链接才会在新标签页打开，可能仍需原账号或访问权限。

## 注释、正文版本与归档

- 「编辑详情」可修改标题、注释及其他信息，已保存正文在此只读。修改注释等信息不新增正文版本；正文历史也不保存旧注释或旧来源详情。
- 修改原文请用「修订摘录」：输入拟修订文本，审阅当前 / 拟修订全文，再选择「确认新正文版本」。仅打开或取消审阅不会改动已保存正文；拟修订文本保留在当前标签页，可继续修订、用于新草稿或明确放弃。
- 「摘录版本历史」可查看旧正文。「审阅恢复此文本」仍需确认，并将旧文本追加为新的当前版本；之后的历史不会被抹除。与当前正文相同的内容不会新增版本。
- 「归档」将记录移至「已归档」，保留正文、注释及历史，可「从归档恢复」。归档记录须先恢复才能编辑；当前界面没有永久删除或自动清空功能。

## 以当前摘录新建草稿

未归档的已保存摘录详情中，可选择「以此摘录新建草稿」。这只在当前标签页打开独立、未保存的可编辑草稿，预填当前标题、正文、类型、标签、注释、工具标签、来源网址和原来的精确提示词关联。不会自动保存、读取来源网页或剪贴板，也不会调用模型。

新草稿不复制原记录 ID、正文历史、归档状态、历史问题或来源快照；它沿用当前正文，即使原记录已有 20 个版本。未实际编辑的正文和注释保留原始换行，未改变的标签保留原数组（包括标签内部的逗号）。实际编辑仍使用既有文本框和标签输入规则。提示词关联可在下方核对或移除；精确版本缺失时保留原 ID，不改用最新版。

若已有新收藏草稿，按钮只切换到它并提示先完成或放弃，不覆盖其内容；其他记录草稿及拟修订文本也会保留。即使新草稿尚未编辑，离开页面仍会提示未保存工作。草稿生成后，原记录的后续改名、修订或归档不会自动改变它。

只有明确选择「保存到本地」才会写入新记录。正文和来源相同会沿用现有重复确认，取消不保存；确认后生成独立 ID 和一个初始正文版本，原记录及其历史不变。容量不足或保存结果不确定时，继续使用现有草稿保留、同次操作重试或只读核验流程。[本项有界开发验证](collection-reuse-draft-validation.md)不等同于真实 Chrome 验收。

## 提示词关联

1. 在新草稿或「编辑详情」中，选择「本地提示词」，再选择「精确正文版本」。当前版、旧版、归档及恢复快照中可找到的精确版本均可选择；预览按纯文本显示。
2. 核对正文后，选择「将链接应用到草稿」。这一步只修改草稿；仍需「保存到本地」才会保存关联。摘录正文和注释不会被提示词替换。
3. 取消关联请用「在草稿中移除链接」，然后保存。只改变选择、不点击应用，不会改变原关联。

关联始终保留提示词 ID 和正文版本 ID。提示词改名或新增正文版本不会改变已关联正文。归档或恢复快照来源会单独标注；精确版本缺失时保留原 ID，不按标题、正文或最新版本代替。提示词读取失败与版本缺失会分别提示，可「刷新本地提示词」重试。完整备份恢复未确定完成时不会读取或应用新关联；收藏保存结果不确定时，先检查 / 重试同一次保存。

在未归档的已保存收藏详情中，若精确版本仍在当前已加载、未归档提示词自身的历史内，可点击「在提示词库打开当前详情（新标签页）」。新页打开提示词当前已保存详情，本页精确历史关联与正文不变；不会选择某版本用于使用。归档、仅恢复快照可见、缺失或读取失败时不提供入口。可用性以成功读取的快照为准，不承诺尚未收到跨标签页通知的瞬时变化。[返回提示词的范围与验证边界](prompt-linked-results.md#从已保存结果返回提示词)。

## 草稿与保存失败

草稿和拟修订文本仅留在当前标签页，切换记录可保留，关闭、刷新或离开页面可能丢失；它们不进入任何备份。离开前请保存或另行保留文本。

跨标签页编辑冲突时，过时保存会被拒绝，草稿仍保留。核对最新数据后，可将草稿另存为新记录，或明确放弃。无法确认写入是否成功时，先使用「检查 / 重试同一次保存」，不要反复新建副本。完整备份恢复中断造成的写入阻止，应在完整备份界面检查恢复状态。

## 容量限制

- 收藏和归档合计最多 200 条；归档不会释放名额。
- 每条标题、工具标签各最多 200 字符；正文 32,000 字符；注释 16,000 字符；来源网址 2,048 字符。
- 每条最多 20 个标签，每个 64 字符；搜索框最多 500 字符。
- 每条最多 20 个正文版本，包含初始版本。达到上限可将拟修订文本用于新记录，但仍受总条数与容量限制。
- 收藏库总预算为 2 MiB，内部另预留 16 KiB；正文历史和恢复快照也占容量。收藏内部恢复快照最多 8 份。

超限会拒绝整次操作，不截断文字，也不自动淘汰历史。导出用于保留副本，本身不会减少已占容量；当前界面没有清理历史或恢复快照的入口。

## 导出与恢复

**收藏独立 JSON 可在收藏页「导入 / 恢复 JSON」中审阅并恢复；多模块迁移可使用「设置 → 数据 → 完整本地备份」。**

1. 勾选「AI 收藏与已保存版本」，按需取消其他模块，然后「导出所选模块」。收藏作为全局资料只保存一次。需要同时迁移提示词正文时，另勾选提示词模块。
2. 先保存草稿、导出目标设备现有数据，并下载需要保留的「恢复前的备份副本」。选择完整备份 JSON（文件上限 32 MiB）。
3. 核对当前 / 导入数量、版本、归档和冲突提示，明确选择「此设备的全局 AI 收藏」作为恢复位置，再重新预览。提示词库的恢复目标需另行选择。
4. 选择「替换所选已保存模块」。这是替换而非合并，包含所选收藏的归档记录；未选模块和旧备份中不存在的收藏模块不会被清空。数据已变化时需要重新预览。
5. 等待结果。替换前会保存并验证恢复副本，原收藏及历史也进入收藏恢复快照；容量不足时拒绝操作。完整恢复前副本只保留最新一份，下一次已确认恢复可能替换它。下载副本后须经同一预览流程恢复，下载本身不会恢复。

写入或验证结果不确定时，可能已有部分数据变化；这不保证浏览器崩溃时的原子恢复。按界面检查中断状态、保存候选副本并明确确认恢复，不要盲目重试或假定已经自动回滚。详见[完整本地备份](complete-backup.zh-CN.md)。

收藏页另有「导出」，下载包含所有已收藏、已归档记录、正文历史、注释、精确关联及恢复快照的独立 JSON 副本。可勾选仅从该副本移除来源网址，不改变本地记录。独立收藏文件通过收藏页「导入 / 恢复 JSON」审阅后明确替换全局收藏，也可从同一入口审阅恢复旧库快照。文件上限 2 MiB，替换不是合并，取消不写入，数据变化后须重审。它与完整本地备份格式不同，不能直接导入完整备份界面。[独立导入范围与故障处理](collection-json-import.md#中文)。请检查浏览器下载列表和保存位置，不要仅凭点击导出就删除原数据。

## 隐私与范围

收藏不是加密保险库，导出文件也未加密。不要保存密钥或其他不宜泄露的内容。移除来源网址不会清除正文、注释或历史中的链接与个人信息，更不等于匿名化。

备份不包含未保存草稿、服务商凭据、认证信息或设备隐私设置；但手动粘贴进正文和注释的秘密仍会原样进入备份。分享前请检查文本和历史。此集成不把收藏加入原有设置 JSON、Chrome 同步或 Google 云盘配置备份。

本指南描述未发布集成候选的代码行为，不代表已完成原生浏览器、下载、剪贴板或故障验收，也不代表更广泛的 AI 功能路线已经完成。

## 手动选区传递（未发布候选）

在 HTTP(S) 页面选择文本后，通过右键菜单打开新的未保存草稿。先审阅、填写标题，再明确保存。新增 `contextMenus` 权限；不扫描页面、不调用模型、不发起新网络请求。可编辑字段和无痕窗口不采集。来源默认不勾选，候选地址移除查询参数与片段标识；路径仍可能含私人信息。临时数据仅在 session 存储中有界保留十分钟，只有保存后进入现有收藏与备份。[完整范围、隐私与限制](selection-capture.md)。

## 保存结果不确定时

写入成功但回读失败时，页面会保留草稿与原操作，暂停新的保存、另存和修改，并在离开前提示。可选择「核验保存结果（只读）」检查原操作凭据，不会新增或修改收藏。若「检查 / 重试同一次保存」被后续操作拒绝，之后仅允许只读核验，不把先前可能成功的保存当成普通冲突重新另存。

核验成功只证明原操作曾成功，当前记录可能已被其他操作修改；页面显示最新保存状态，不回滚后续修改。凭据缺失、过期、内容不匹配或读取失败时会继续保留草稿并阻止新保存。保持此页打开，检查资料库后再决定下一步。第一次保存就遇到确定的版本冲突仍可按普通冲突审阅并明确另存。
