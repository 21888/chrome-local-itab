# 1.1.94 · 详情状态与上一回答保护 / Details state and previous-response protection

## 新增

- 导航库在当前面板内记住各站详情展开状态，跨勾选、筛选隐藏/恢复和目标草稿更新保持，关闭重开重置。

## 修复

- 替换未保存回答需明确确认；当前审阅与发送门槛保持，旧快照不包含 API key 或认证头。
