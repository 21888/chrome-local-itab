# 1.1.81 · 核验导航库运营与定价信息 / Reviewed operator and pricing metadata

## 新增

- 为既有 17 个条目补充经官方来源核验的资料：明确 16 项运营主体所在地、3 项免费加付费定价分类，并更新对应主体名称、说明和证据来源。

## 修复

- 运营主体所在地依据对应服务条款或官方联系资料，不把服务器位置、区域隐私控制者或相邻产品主体误当作服务运营方。

## 注意事项

- GitHub、GitLab 的所在地限于已核验的一般服务主体，并非所有区域隐私控制者或单独订单的签约主体；Canva 按地区采用不同实体，其所在地继续 unknown。
- Canva、GitLab、TinyPNG 的免费加付费分类仅描述对应网页服务及限制，不等同 API 免费或无限使用。Photopea、Hoppscotch、MDN、freeCodeCamp 等证据不足的所在地继续 unknown。
- 仍为 108 个网站、154 个用途标签；不改站点 URL、界面、权限或运行时行为。2331 项 Node 与 53 项 Python 回归通过；限定中文桌面原生检查确认代表主体/来源、GitHub US 保留与 CN 排除、Canva 未知保留与 AU 排除及 TinyPNG 网页定价限制。未逐项原生复核全部条目，不保证外部条款永不变化。
