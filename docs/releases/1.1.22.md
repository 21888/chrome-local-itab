## 新增

- 独立工作空间：网站、分类、布局、外观、待办、便笺、倒计时和专注状态按空间保存；支持新建、改名、复制、切换和可恢复的回收站。
- 已打开页面固定属于各自空间。切换时可保存未完成编辑、明确放弃或留在当前页，防止多个页面互相覆盖。
- 完整本地备份扩展为覆盖全部工作空间和回收站；支持模块预览、选定模块恢复，以及把旧版单空间备份恢复到明确选定的空间。

## 修复

- 首次升级先验证原有数据副本再激活新结构，保留原始快捷方式布局、个人模块及暂停中的专注状态。
- 复制空间不会启动第二个专注计时器；移入回收站会暂停运行中的计时，恢复不会自动开始。
- 旧版标签页继续写入旧结构时暂停新写入并提供两份数据下载与明确处理，避免静默覆盖。
- 恢复后的旧页面不能继续写入已替换空间；Default 配置恢复后自动同步按安全提示暂停，避免旧云配置立即覆盖恢复结果。

## 注意事项

- 云端 Linux 原生 Chrome 已验证旧版迁移、跨页面隔离、草稿切换保护、回收站、全空间备份恢复与恢复副本逐项对比，并完成深浅色和 510 像素窄窗口检查。[真实验收及未测范围](https://github.com/21888/chrome-local-itab/blob/v1.1.22/docs/workspaces-native-validation.md)。

- 工作空间不是账户或权限隔离。默认空间不能删除，上限 100 个包含回收站；不会自动永久清理旧空间。
- Chrome Sync 与 Google Drive 仍只对应默认空间的原有配置范围，不会自动同步所有空间。设备隐私、服务商授权和更新偏好不随空间复制。
- 完整恢复前建立经过验证的本地恢复副本；存储不是断电级原子事务。遇到不确定结果应保留数据并按提示检查，不能把自动化测试视为所有故障场景保证。
- 部分模块恢复需要空间结构匹配；旧版备份必须明确目标。页面未保存草稿不属于备份内容。

## English

- Adds independent workspaces for sites, categories, layout, appearance and personal modules, with create, rename, duplicate, switch and recoverable Trash.
- Existing tabs stay pinned to their space; switching handles unsaved drafts explicitly. Duplicating does not start another Focus timer, and recovering a deleted space does not resume a timer automatically.
- Verified legacy migration preserves the original saved data. Complete archives cover live and trashed workspaces, while partial restores require matching topology and legacy archives require an explicit destination.
- Detects old-page writes and stale generations instead of silently merging or replacing data. Existing cloud services remain limited to the Default configuration scope.
- No new permissions or automatic permanent deletion. Workspaces are not security boundaries; pre-restore recovery and readback checks do not make multi-step storage crash-atomic.
