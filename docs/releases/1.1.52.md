# 1.1.52 · 卡片顺序与宽度 / Card order and width

## 新增

- 自定义面板增加卡片排序箭头与 1–4 列宽度，提供包含隐藏卡片的微型预览。
- 保存后同步实际 DOM 与键盘阅读顺序；移动现有卡片，不重建模块或丢弃未保存输入。

## 修复

- 狭屏限制宽度到可用列数，保留原保存值；边界箭头与保存失败保持键盘退出能力。
- 按字段校验顺序与宽度并发修改，工作区保存保持原会话边界。

## 注意事项

- 行数随内容自动增加，不支持固定行数；使用顺序排列，不密集回填空隙。隐藏卡片不会自动启用。
- 预览不写入；取消恢复最新保存布局。仅排序/宽度重置与全部预览重置均需显式保存。
- 布局字段进入配置备份，但不改写模块内容、快捷方式或自由布局坐标。
- 合成测试不替代原生几何、键盘和完整发布验收。

- 修复旧版完整备份缺少新布局字段时的兼容性；原始合成备份文件未改写并通过恢复。最终完整本地测试通过 1,965 项，Python 检查通过 53 项。
- 云端原生英文浅色模式通过旧备份恢复、便笺移到专注前并占两列、保存布局保留任务草稿、重载后布局持久化（测试草稿在重载提示中明确丢弃）、320 CSS 像素宽度收敛到单列，以及仅布局重置预览后取消恢复。范围不含全部模板/隐藏模块、辅助技术或并发冲突矩阵。
