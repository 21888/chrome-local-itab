# 1.1.126 · 优化提示词差异与换行审阅 / Refinement differences and line-ending review

## 新增

- 优化已保存提示词后，可显式查看当前原文与未保存提案的逐行差异，标注移除、新增和未变内容，并分别显示精确换行类型及末尾换行。复用既有 250,000 格有界比较；大段修改明确提示降级，完整保留两侧文本。
- 空提案、相同提案或缺少占位符的完成草稿也可诊断差异，但原有试跑及接受校验不放宽。编辑、隐藏、来源失效、试跑、保存和关闭清除差异，不自动重新计算。修正未编辑 textarea 显示标准化导致的原文试跑误失效；试跑与接受仍保留原始 CRLF/CR 字符串。

## 修复

- 修复浏览器预格式请求审阅中单独 CR 可能视觉连行的问题。普通对比、试跑及重试只在展示副本将 CRLF/CR 显示为单个 LF 换行；请求对象、发送 JSON、响应、提案和历史不改写，字面反斜杠与有意空行不变。
