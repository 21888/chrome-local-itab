## 新增
- 建立 GitHub 自动发布流程：每次向 master 推送一个补丁版本提交，测试通过后生成对应 tag、Release、运行 ZIP、校验和及源码溯源信息。
- 增加独立的只读测试与发布检查；发布前重建运行包并比对 SHA256。
- 作为首个 GitHub Release，本包也包含此前已完成的世界时钟固定时刻对比、待办批量录入与编辑校验焦点修复；这些不是本次发布流程提交中新加的功能。

## 修复
- 本版本主要完善发布交付流程，未单独新增浏览器功能修复。

## 注意事项
- 支持中断后继续上传草稿附件；版本与源码冲突、已发布附件内容不一致时停止，不覆盖旧包。
- Chrome 商店仍是每天至多一次的独立合并提交流程，GitHub 发布不等于商店已上架。

## English
- Added tested, versioned GitHub Releases with runtime ZIPs, checksums and source provenance for each single-commit master push.
- This initial public release also packages previously completed world-clock comparison, reviewed task batch capture and edit-validation focus fixes.
- Rebuild verification and guarded draft recovery preserve published assets. No separate browser-feature fix is introduced here; Chrome Web Store submission remains independent.
