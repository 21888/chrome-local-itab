# 1.1.50 · 自定义背景与卡片 / Custom backgrounds and cards

## 新增

- 首页与设置增加自定义抽屉：原背景、纯色或双色渐变；信息卡片的内边距、间距、圆角、不透明度与 1–4 列。
- 本地实时预览，保存后持久化；取消恢复已保存外观，重置预览仍需显式保存。

## 修复

- 按字段合并独立设置修改，并拒绝同字段冲突或过期替换，避免覆盖较新设置。
- 模板切换保留自定义覆盖；恢复原背景不会删除已有图片或背景设置。

- 浏览器报告无效数字输入时保持保存禁用，避免把未完成输入误作默认值。

- 自定义深色或明暗混合背景为裸露文字区域提供匹配当前配色的实色阅读底板；保留周边背景、卡片与对话框的原配色。

## 注意事项

- 卡片行数随内容自动增长，窄屏自动减少列数，不支持任意固定行数。
- 指定卡片列数时，信息卡片排列于快捷方式下方；快捷方式列数、自由布局坐标和个人内容不改写。
- 颜色仅接受六位十六进制值，不执行任意 CSS。此版本不增加权限或远程请求。
- 原生显示、键盘、跨标签页和完整发布验收单独执行。

- 最终完整本地测试通过 1,937 项，Python 检查通过 53 项。云端原生英文浅色模式验证 Today/Column 四张已填充卡片在 1440 CSS 像素宽度排在快捷方式下方，Folio 及深色纯色/黑白渐变文字可读，40%/100% 卡片不透明度有可见差异，320 CSS 像素宽度回落单列。
- 颜色通过普通设置导入的合成数据验证，原生颜色选择器仍未验证；该范围不代表全部模板、深色界面、中文或跨标签页冲突验收。

## English

- Adds a local Customize drawer for original/solid/gradient backgrounds and card padding, spacing, corners, surface opacity and 1–4 columns.
- Preview locally, Save explicitly, or Cancel to return to saved appearance. Reset changes the preview until saved.
- Field-level concurrent updates merge independent changes and reject conflicts or stale replacement generations. Templates preserve overrides; original background restores existing configuration without deleting it.
- Rows grow with content and columns reduce on narrow screens. Explicit card columns place cards below shortcuts. Shortcut geometry, free-layout positions and personal content are not rewritten.
- Incomplete number input marked invalid by the browser blocks Save, including empty-valued bad-input states. This safeguard is model-tested, not a reproduced native defect.
- Opaque palette-matched reading surfaces protect exposed dashboard text over dark solids or mixed gradients without recoloring cards/dialogs or changing surrounding backgrounds.
- Only validated six-digit colors are accepted, with no arbitrary CSS, new permissions or remote requests. Native and full release acceptance remain separate gates.

- Final complete local suite: 1,937 tests passed, plus 53 Python checks. Native English/light essentials passed: four populated cards below shortcuts in Today/Column at 1440 CSS pixels, readable Folio and dark-solid/black–white-gradient surfaces, visibly distinct 40%/100% card opacity, and single-column reflow at 320 CSS pixels.
- Colors were supplied through ordinary Settings imports of synthetic fixtures; native color-picker interaction remains unverified. This is not an all-template, dark-interface, Chinese or cross-tab conflict acceptance claim.
