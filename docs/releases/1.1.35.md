# 1.1.35 · 对照提示词正文版本 / Compare prompt body versions

## 新增

- 在正文历史中明确选择两个已保存版本，对照增加、删除和保留的行，亦可展开两份原文。
- 分别显示 CRLF、LF、CR 数量及末尾换行状态，说明看起来相同的空白差异。
- 英文与简体中文界面和使用说明。

## 修复

- 版本对照不改变正在使用的预览变量和历史选择；切换记录、版本消失或读取失败会关闭失效对照。

## 注意事项

- 只读且完全本地，不保存对照状态、不联网、不调用模型，也不改写原文。
- 精确逐行对照最多使用 250,000 个比较单元；较大输入显示明确标记的整块回退，不冒充精确最小差异。
- HTML、Unicode、换行符按原文本处理。最终源码通过 1,681 项 Node、53 项 Python 回归；独立算法检查覆盖 15,644 个对照案例。原生 Chrome 验证版本切换、原文展开、关闭/Esc 焦点、变量及历史范围保留、深色与 200% 缩放。物理窄窗口与屏幕阅读器未实测。

## English

### Added

- Explicitly select two saved body versions in history to compare added, removed and unchanged lines, with expandable literal originals.
- Separate From/To summaries explain CRLF/LF/CR counts and final-newline differences.
- English and Simplified Chinese labels and documentation.

### Fixes

- Comparison preserves preview variables and the selected history version. Record navigation, missing versions and read failures invalidate the comparison.

### Notes

- Read-only and local: no persisted comparison state, networking, model calls or rewritten source text.
- Exact line comparison is capped at 250,000 cells; larger changes use a clearly disclosed block fallback rather than claiming a minimal diff.
- HTML, Unicode and line endings remain literal. Final source passed 1,681 Node and 53 Python tests; independent algorithm checks covered 15,644 cases. Native Chrome verified selectors, literal originals, Close/Escape focus, preserved variables/history scope, dark theme and 200% zoom. Physical narrow-window and screen-reader acceptance were not performed.
