# 1.1.83 · 选择当前筛选结果 / Select current filtered results

## 新增

- 网站库新增显式「选择当前结果」，只选择当前筛选下尚未添加、尚未选中的条目，并与已选条目合并，包括被其他筛选隐藏的选择。
- 显示可新增选择数量；合并超过 20 时禁用并提示缩小筛选，不静默截取前 20 项。

## 修复

- 已添加条目、零结果、已全部选中、待保存或确认中的状态不允许重复扩展选择；完成选择后焦点留在批量操作区。

## 注意事项

- 只改变待确认选择，不直接写入快捷方式；仍须审阅完整名单及目标分类后明确确认。原保存、去重、工作空间和隐私保护不变。
- 不增加权限、默认链接或运行文件。46 项针对性、全部 2341 项 Node 和 53 项 Python 测试通过；限定中文 Clarity 桌面/320px 亮色原生检查通过新增数量、默认超限阻止、隐藏选择合并、键盘 Return 与确认中禁用、完整名单及取消零写；未在本轮执行实际保存或挂起竞争。
