## 新增

- 设置「隐私」页新增「版本与更新」，显示当前安装版本，并可手动检查 GitHub 最新已发布版本。
- 可选择每天最多检查一次；使用新标签页时最多每 24 小时轻提示一次，支持忽略单个版本。
- 根据解压加载、商店、组织管理或未知安装来源提供更新说明，中英文界面均可使用。

## 修复

- 此版本以新增版本检查为主；检查采用数字版本比较，并处理断网、超时、请求限流及过期响应，避免误报或覆盖较新的检查结果。

## 注意事项

- 自动检查默认关闭；手动检查或主动启用后会连接 GitHub，GitHub 可见 IP 地址及常规连接信息，不发送书签、任务或设置。
- GitHub 已发布版本不代表商店已通过审核，也不代表另有经过筛选的稳定版渠道。
- 不会自动下载、替换文件或重新加载扩展。解压版先保存和备份，再替换原固定文件夹中的文件并手动重新加载。
- 更新偏好仅保存在本设备，不随设置备份或云同步迁移。恢复默认设置会关闭自动检查。

- 验证范围：逻辑与界面模型测试通过；原生浏览器已检查离线反馈、偏好保存和草稿保留。当前云端原生浏览器直接连接 GitHub 被拒绝，联网成功态及真实商店安装仍需独立验证。

## English

- Adds installed-version display, manual GitHub release checks and optional at-most-daily checks in Privacy settings, with quiet notices and per-version ignore.
- Provides installation-specific guidance without automatic installation or reload. GitHub publication is separate from store review.
- Network access is off by default. Explicit checks contact GitHub for public metadata; no bookmarks, tasks, settings, account or token are sent.
- Handles numeric versions, timeout/offline/rate-limit failures, cross-tab checks and late responses while preserving unsaved Settings edits. Preferences remain device-local.
- Validation: native offline feedback, preference persistence and draft retention were checked; successful online browser UI and a real store installation remain unverified because this cloud native browser refused the GitHub connection. Public GitHub metadata parsed successfully in a separate Node integration check.
