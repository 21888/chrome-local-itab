# 1.1.62 · 本地编辑优化建议 / Edit refinement proposals locally

## 新增

- 优化建议可以在本地编辑；保留原模型响应供核对，不必为文字调整重新请求模型。
- 验证占位符后，试跑与明确接受使用当前编辑的确切建议正文。

## 修复

- 编辑使旧试跑失效；试跑、接受与不确定保存期间冻结建议，防止旧结果或保存回执绑定到另一份文字。
- 不确定接受继续保留同一操作并检查结果，不创建另一次写入。

## 注意事项

- 本地编辑不自动调用模型，不自动保存；原提示词只在明确接受后产生新版本。
- 真实模型、授权、费用与扩展持久化仍需独立验证。

- 本地独立检查通过 2,072 项，Python 检查通过 53 项。20,000 链接用例未在本地重跑，完整本地验证仍不完整；发布须对应提交的原有完整 CI 通过，未放宽断言。
- 独立浏览器页面使用 18 个生产匹配资产、合成响应/权限和内存存储，验证缺失占位符阻止试跑/采纳、修复后的确切编辑文本用于试跑和新版本、模型原响应保持只读。最终三次请求、两次写入（含种子）和两个历史版本，原版本保持不变。中间写入计数被弹窗遮挡，未单独可见读取。
- 中文/深色页面使用实际目录与主题钩子验证显示、Escape 和零请求；不代表扩展设置选择/持久化，也未重复中文响应流程。已知外观文字问题：采纳成功后标题仍称“可编辑/未保存”，成功状态、禁用控件与实际保存版本正确。
- 真实服务商、权限、费用、持久化、窄屏、完整键盘以及原生竞态矩阵未验证；测试控制不进入生产包。

## English

- Allows local edits to an unsaved refinement proposal while retaining the original model response for comparison. Wording changes do not require another model request.
- Placeholder validation gates the exact edited text used for trial and explicit acceptance. Editing invalidates an earlier trial; active trials, acceptance and uncertain saves freeze the proposal.
- Uncertain acceptance retains the identical operation and checks its outcome rather than creating another write. Local edits make no automatic model request or save; only explicit acceptance adds a version to the original prompt.
- Real providers, grants, billing and durable extension storage require separate verification.

- Local checks passed 2,072 unique cases plus 53 Python checks. The 20,000-link case was not rerun locally, leaving local validation incomplete. Publication requires the exact commit’s existing complete CI gate; no assertions were relaxed.
- Native browser interaction using 18 byte-identical shipped assets, synthetic responses/permissions and memory storage verified invalid-placeholder blocking, repair, exact edited text in trial and accepted version, and the read-only original model response. Final totals were three requests, two writes including the seed, and two history versions with the original intact. Intermediate write counters were obscured rather than independently read.
- A Chinese/dark fixture using the actual catalog/theme hook passed rendering, Escape and no-request checks; this does not establish extension setting selection/persistence or a repeated Chinese response flow. Known cosmetic issue: after acceptance the heading still says editable/not saved, while success status, disabled controls and exact saved history are correct.
- Real providers, grants, billing, durability, narrow layout, complete keyboard coverage and native race matrices remain unverified. Fixture controls are excluded from production.
