# 1.1.89 · AI 素材查找与已选视图 / Find and review selected AI sources

## 新增

- AI 上下文素材列表支持本地标题搜索，并显示可见、已选及隐藏已选计数；查询不进入发送内容或预算。
- 增加“只看已选”切换，与标题查询取交集，方便检查已选素材；隐藏不会自动取消选择或丢弃临时摘录编辑。

## 修复

- 清除查询后焦点返回搜索；已选视图取消勾选时焦点移至相邻可见项或切换按钮。取消/清空草稿重置查询及视图，单纯切换视图不算未保存内容。

## 注意事项

- 两个独立功能提交合批发布；实现全部 2414 项 Node 与 64 项 Python 回归通过。本发布提交仅升版与文档。
- 开发快照限定原生覆盖单个合成素材、ASCII 标题查询、隐藏选择/预算/编辑保持、单项取消焦点、清空与 320px 亮暗。多行焦点、201/13 项边界、Unicode 输入、实际请求预览及 ARIA 读屏未原生验证，相关合成证据不冒充原生。
- 不新增持久化、权限、素材读取或 provider 请求；最终 89 包仅 manifest 与已验开发包不同，普通原生重新加载确认版本及搜索/已选视图空态，不代表全部原生场景重跑。

## English

- Adds local AI source-title search with visible/selected/hidden-selected counts and a selected-only view intersecting the query. Search is excluded from request contents and budgets; hiding does not deselect or discard edited excerpts.
- Clearing search restores focus; deselecting a row in selected-only view recovers focus to a neighboring row or toggle. Cancel/Clear resets view filters, while view-only changes do not mark a draft dirty.
- This batch combines two feature commits. The implementation passed 2414 Node and 64 Python tests. Bounded development-native checks used one synthetic source and ASCII input, including hidden selection/edit/budget retention, sole-item focus and 320px light/dark layout. Multirow focus, 201/13 boundaries, Unicode, actual request preview and ARIA/screen-reader behavior remain outside native coverage.
- No added persistence, permissions, source reads or provider requests. The final version-89 package differs from the tested development runtime only in manifest; ordinary native Reload confirmed version and search/selected-view empty state, not a repeat of every native scenario.
