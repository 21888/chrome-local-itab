# 1.1.45 · 站点批量分类整理 / Reviewed batch category organization

## 新增

- 从分类操作进入独立的站点整理面板，逐条选择网站、选择已有目标分类并核对后，一次性移动。
- 同名分类、重复网址和缺少旧标识的记录按实际条目精确区分，失去分类名称的网站仍可整理。

## 修复

- 使用同一写锁与完整快照校验，分类或网站被并发修改时拒绝过期提交。
- 只更改所选网站的分类字段，保留顺序、标识、图标、坐标及其他字段。
- 未确认写入提供安全重试；尚未保存成功的拖动布局会阻止整理提交，保留失败的拖动意图。

## 注意事项

- 移动需要明确预览确认；取消不更改数据，不创建或删除分类。
- 不修改查找面板的只读行为。原生浏览器验收与自动化覆盖分别记录。

## English

- Select exact saved-site records, review an existing destination category and move them in one guarded transaction.
- Preserves identities, order, positions and unrelated fields, including legacy duplicate records and orphaned category IDs.
- Snapshot and lock checks reject stale reviews; uncertain writes support guarded retries. Unresolved layout saves block movement without discarding failed drag intent.
- Cancel writes nothing. Native acceptance is recorded separately from deterministic tests.
