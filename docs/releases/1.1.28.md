# 1.1.28 · 复制反馈与当前内容保持一致 / Clipboard feedback stays current

## 新增

本版本没有新增功能。

## 修复

- 提示词复制尚未完成时，修改变量、切换字面模式、清空值、切换提示词或更新正文，不再让旧操作对新预览提示“已复制”，也不会把焦点抢回旧预览。
- 切换提示词后，旧复制完成会正确恢复当前按钮的可用状态，同时继续遵守缺失变量、进行中保存和待处理操作的限制。
- AI 收藏在复制期间切换记录、离开后返回、更新正文或关闭控制器，旧操作不再覆盖当前记录的成功或失败提示。
- 每次复制仍只由明确操作触发；不会自动再次复制。未发生内容变化时，原有成功提示和复制失败后的手动选择方式保留。

## 验证与范围

最终集成运行源码与通过完整回归的候选一致，仅 manifest 版本和本说明不同。候选通过 1,556 项 Node、52 项 Python 测试；新增 32 项界面回归，独立审阅的 12 项定向检查通过。去掉修复的基线会失败 26 项新增检查。

## 注意事项

这些延迟剪贴板、导航和控制器退出场景由确定性的模拟 DOM / Promise 测试验证；本次没有新增原生浏览器剪贴板时序测试，不将历史原生验收冒充为本次验证。不新增权限、网络请求、存储格式或界面布局。

## English

### Added

No new features in this version.

### Fixes

- A pending prompt copy no longer labels changed preview text as copied or steals focus after variable, literal-mode, record or body changes, including changes away and back.
- Copy completion restores the current button eligibility while respecting incomplete variables, busy state and pending commands.
- Collection copy results no longer overwrite feedback for a different or updated record, a navigated-away-and-back detail, or a disposed controller.
- Copying remains explicit and double-click guarded. No automatic second clipboard write is introduced. Unchanged previews retain success and manual-selection fallback behavior.

### Verification

The candidate passed 1,556 Node and 52 Python tests, including 32 added view regressions. Twelve independent focused audit checks passed. The unfixed baseline fails 26 added checks. Integrated runtime matches that tested candidate except the manifest version; this release note is documentation-only.

Deferred clipboard, navigation and disposal cases use deterministic synthetic DOM/Promise tests, not a new native browser timing exercise. No new permissions, network requests, storage schema or layout changes.
