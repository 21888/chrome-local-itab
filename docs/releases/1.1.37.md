# 1.1.37 · 直接试用历史提示词 / Use historical prompt previews

## 新增

- 正文历史中的「使用此版本」可临时试用旧版本，不需要恢复成新版本；预览可明确返回当前版本。
- 同一标签页内按精确提示词、版本及正文隔离变量和字面模式，切换回来仍保留对应输入。

## 修复

- 复制、摘录填入、关联结果和新结果草稿链接始终跟随实际预览版本。
- 来源不可用或正文被替换时保留输入并阻止过期操作，等待明确恢复；读取中、超限输入、过期对话框及离页回调都有保护。

## 注意事项

- 选择历史行本身仍只读。使用旧版本不增加保存历史、不修改当前正文、不持久保存变量，也不联网。
- 「清空变量」保持原有返回当前正文的行为，清空活动和缓存的当前版本值；其他历史值仍保留。确认后的标签页级清空可释放全部预览缓存。
- 缓存上限为 100 个会话和 2 Mi 个 UTF-16 值单元；达到上限时明确拒绝，不静默淘汰已输入值。关闭标签页会失去这些临时值。
- 1,725 项 Node、53 项 Python 测试通过；云端 Chrome 原生验收通过历史切换、真实复制粘贴、精确结果关联、清空、键盘焦点和深色主题。[验收范围](../qa/historical-prompt-preview/native-acceptance.md)。

## English

### Added

- Explicitly use a saved historical body in a temporary preview without restoring it as a new version, and return to the current body deliberately.
- Keep variable values and literal mode isolated by exact prompt, version and body within the tab.

### Fixes

- Copy, excerpt insertion, linked results and new-result draft links follow the actual active preview version.
- Unavailable/replaced sources retain input but block stale actions until explicit recovery; pending reads, rejected edits, stale dialogs and disposal are guarded.

### Notes

- Selecting history alone stays read-only. Historical use does not grow saved history, alter the current body, persist values or access the network.
- Clear values preserves reset-to-current behavior and clears active/current cached values while keeping other historical values. Confirmed tab-wide clearing can reclaim all cached previews.
- Cache is limited to 100 sessions and 2 Mi UTF-16 value units. Capacity refusal is explicit, with no silent eviction; closing the tab loses temporary values.
- 1,725 Node and 53 Python tests pass. Native cloud Chrome checks cover historical switching, real copy/paste, exact result links, clearing, keyboard focus and dark theme. [Bounded acceptance](../qa/historical-prompt-preview/native-acceptance.md).
