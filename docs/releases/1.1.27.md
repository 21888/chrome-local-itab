# 1.1.27 · 明确选区收藏 / Explicit selection capture

1.1.27 新增明确选区收藏，延续统一 AI 资料库搜索与原有收藏、提示词和工作空间功能。原生验收在冻结的 88 文件运行包（manifest 1.1.25）上完成；本版本除 manifest 版本外，运行文件字节完全一致。历史版本记录与证据保持原始来源。

## 新增

- 在 HTTP(S) 页面选择文本，右键选择「将所选文本保存到 AI 收藏…」，打开新的未保存草稿。先审阅浏览器提供的文本、填写标题，再明确「保存到本地」。右键采集本身不写入持久收藏。
- 来源默认留空，包含来源的复选框默认不勾选。候选地址通过既有安全校验后移除查询参数与片段标识；不安全框架来源不会替换为顶层网页来源。路径仍可能包含私人信息，勾选前请核对。
- 临时数据仅使用有界 `chrome.storage.session`：最多八条待审阅选区，总量不超过 512 KiB，十分钟后不可读取；后续传递操作清理过期数据，浏览器会话结束也会清除。随机 token 绑定确切扩展页面、标签页及选区，成功填入草稿后才确认消耗。延迟响应不会覆盖已有草稿或待完成操作。
- 排除可编辑字段和无痕窗口；无效、过长或容量已满时拒绝整个选区，不截断或静默驱逐仍有效的文本。不支持 session 存储的浏览器明确提示手动粘贴，不回退到 local/sync。

## 修复

本版本没有单独的既有功能修复项；新增功能的保护与限制见下文。

## 注意事项

### 权限、隐私与限制

**仅新增 `contextMenus` 权限**及 MV3 后台 worker。不新增 tabs、activeTab、scripting、主机访问、通知或剪贴板权限，不扫描网页、不调用模型、不增加网络请求。现有可选联网功能不变；收藏存储 schema 和备份格式不变。明确保存后，内容才进入现有本地收藏及其显式导出 / 备份范围。

保留的是 Chrome 提供的 selectionText，不是原网页格式。本轮 Chrome 原生测试中，多行预格式文本的换行变成了空格；标记与 Unicode 仍为字面文本。请审阅多行代码，需要保留原排版时使用手动复制粘贴并核对。这不是完整对话备份或加密保险箱。

## 验证

集成候选完整回归通过 **1,524 项 Node 和 52 项 Python 测试**。独立安全审阅及自动化覆盖传递生命周期、失败重试、sender/tab/token 边界、Unicode/容量限制、并发与未保存草稿保护。

有界原生 Chrome 验收通过明确菜单 → 未保存草稿 → 来源选择 → 保存、保存前导出不变、可编辑字段拒绝、已消耗 token 后复制标签页及重新加载不重放。**无痕窗口与强制 worker 终止恢复未在原生浏览器实测**；其他故障与竞态自动化覆盖不等于原生验证。

## English

1.1.27 adds explicit selection capture and retains unified AI library search, collections, prompts and workspaces. Native acceptance used the frozen 88-file candidate, manifest 1.1.25; this runtime differs only in its manifest version. Original evidence keeps its provenance.

### Fixes

No separate fixes to existing features are included; safeguards and limitations of the new feature are documented below.

### Changes

Select text on an HTTP(S) page and choose **Save selected text to AI collection…** in the context menu. A fresh **unsaved** draft opens. Review the browser-provided text, add a title and explicitly Save locally. The menu action alone does not persist a collection record.

Source inclusion starts unchecked and the source field blank. The optional validated candidate has query and fragment removed; unsafe frame URLs never fall back to the outer page. Paths may still contain private information. Editable fields and incognito selections are excluded. Invalid or oversized text is rejected entirely, without truncation.

The bounded session-only handoff allows eight pending selections within 512 KiB, inaccessible after ten minutes and cleaned on later handoff activity or browser-session end. Opaque tokens bind the exact extension page and target tab. Only successful draft hydration is acknowledged; retries cannot overwrite current work or replay consumed text. Unsupported session storage produces a clear manual-paste alternative rather than a local/sync fallback.

### Permissions, privacy and limits

**contextMenus is the only added permission**, alongside an MV3 worker. No tabs, activeTab, scripting, extra hosts, notifications, clipboard permission, page scanning, model call or new network request is added. Existing optional network features are unchanged. Collection storage and backup schemas remain unchanged; only explicit Save makes text durable and eligible for existing exports/backups.

The feature preserves Chrome-provided selectionText, not original webpage formatting. Native Chrome flattened the preformatted fixture's newlines into spaces, while literal markup and Unicode remained. Review multiline code carefully; use manual copy/paste and verify formatting when necessary. This is not a full conversation backup or encrypted vault.

### Verification

Full integrated regression passed **1,524 Node and 52 Python tests**. Independent audit and automated coverage include lifecycle/retry, sender/tab/token boundaries, limits, concurrency and draft preservation.

Bounded native acceptance passed explicit menu → unsaved draft → optional source → Save, unchanged pre-Save exports, editable rejection, and post-consumption duplicate/reload safety. **Incognito and forced worker termination/recovery were not exercised natively.** Automated fault/race coverage is not a native claim. Original synthetic downloads, ten screenshots, checksums and a portable verifier are retained.
