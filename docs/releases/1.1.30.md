# 1.1.30 · 保留 AI 资料库搜索状态 / Retain AI library search context

## 新增

- 在同一新标签页面内，关闭并重新打开 AI 资料库搜索，会保留最后的搜索关键词和记录类型筛选，无需重新输入。
- 每次重新打开都会重新读取当前已保存的提示词与 AI 摘录；读取期间不展示旧结果，已删除记录不会因保留搜索状态而重新出现。

## 修复

- 已关闭对话框的旧按钮、输入与输入法事件不能清空、关闭或影响新打开的搜索。
- 销毁搜索视图后，解除数据订阅并禁止该视图再次打开；旧读取的延迟结果不能覆盖新对话框。

## 注意事项

- 搜索状态仅保留在当前页面内存中，不保存到浏览器存储、历史记录或 URL；刷新、新开页面或销毁后重新创建视图都会恢复空关键词和“全部类型”。
- “清除”只清空关键词，保留当前类型筛选；关闭后再次打开也保持这一选择。选择“全部类型”可取消类型限制。
- 搜索结果原本就在新的标签页打开精确记录，回到原标签页会继续保留现有搜索；本次没有更改浏览器后退／前进或标签页导航规则。
- 不修改提示词、收藏、草稿或其他保存数据，不新增权限、持久化格式、网络请求或模型调用。
- 最终候选通过 1,643 项 Node 与 52 项 Python 自动化测试。新增五项回归测试覆盖返回原搜索、重复关闭／打开、关闭期间删除记录、旧控件、延迟读取、清除和视图销毁；这些是自动化 DOM／事件模型检查，不是原生浏览器验收。
- 本次新流程尚未进行原生 Chrome 验收；不以早期版本截图或验收结果代替本次原生覆盖。

## English

### Added

- Closing and reopening AI library search in the same new-tab page retains the last query and record-type filter.
- Every reopen rereads current saved prompts and AI excerpts. Old results remain hidden during reads, and removed records do not reappear simply because the search context was retained.

### Fixes

- Buttons, input events and IME events from a closed dialog cannot clear, close or interfere with a newer search dialog.
- Destroying the search view releases data subscriptions and prevents that view from reopening. Late reads from an older dialog cannot replace the newer results.

### Scope, privacy and verification

- Context lives only in current-page memory. It is never written to browser storage, history or URLs. Reloading, opening a new page, or creating a new view after destruction resets the query to empty and the filter to All types.
- Clear empties only the query and retains the selected type, including after reopening. Choose All types to remove the type restriction.
- Exact-record results already open in native new tabs; returning to the original tab retains its existing search. This change does not alter browser Back/Forward or tab-navigation rules.
- No saved prompts, collections, drafts or other saved data are modified. No new permissions, persistent formats, network requests or model calls are added.
- The final candidate passed 1,643 Node and 52 Python automated tests. Five new regressions cover returning to the existing search, repeated close/reopen, records deleted while closed, stale controls, late reads, Clear and view disposal. These use an automated DOM/event model and are not native browser acceptance tests.
- This new flow has not yet had native Chrome acceptance testing. Screenshots and acceptance results from earlier versions are not claimed as native coverage for this release.
