# 1.1.124 · 模型答案阅读与代码复制 / Model answer reading and code copy

## 新增

- 单模型、模型对比各列及只读试用答案复用安全阅读器，提供排版/原文独立切换。完成答案支持标题、列表、代码与表格；流式片段、失败/停止的部分答案及可编辑提案保持原文。
- 阅读中的非空代码块支持“复制代码”，复制所见代码文本，不含围栏或语言标记。整篇复制、保存、导出与历史仍使用完整原始字符串。

## 修复

- 代码块、整篇及模型对比共用所属视图的剪贴板锁，防止未完成写入互相覆盖；关闭、隐藏、切换原文与过期结果不会夺回焦点或显示旧反馈。已开始的剪贴板写入不能撤销。
- 补充可选 Claude 会话用量快照的隐私处理说明，不改变权限、存储或请求行为。

## 注意事项

- 本批包括两个独立功能及文档维护。123 个运行文件，无新增权限、远程脚本、正文链接或图片请求。代码复制与展示一致，可能包含 Markdown lexer 的换行/缩进标准化；不是围栏源码的逐字节复制。
- 合成原生验收：收藏代码 87 字节及全文 765 字节剪贴板精确相等；英文深色单模型代码 700 字节精确相等；中文深色双模型分别反馈成功；Raw/Reading、键盘焦点及收藏 200% 布局可用。模型阅读此前通过单列/双列、宽表滚动与 200% 堆叠代表检查。
- 比较列剪贴板未单独存证，真实 provider/API、原生流式竞态、拒绝剪贴板、屏幕阅读器及全部主题/缩放组合未测。隔离 harness 使用固定内存结果；不声称真实网络或性能验收。
- 功能集成与最终 124 strict 全测均通过 3075 Node / 84 Python，精确功能 CI 同数通过。124 原生身份冒烟确认版本与基线保持。原有合成数据保持 4 活跃 + 1 归档、Default14；未调用真实模型、接入账户或发布 Chrome 商店。
