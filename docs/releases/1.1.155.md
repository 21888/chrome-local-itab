# Local iTab 1.1.155

## 新增
- 临时专注视图：在当前页面暂时只显示专注计时卡，退出后恢复原来的模块节点、显示状态和布局。已有未保存编辑或模板预览等工作会阻止进入；进入和退出本身不保存布局。退出视图不会停止正在运行的计时，开始、暂停、继续、重置仍由现有计时器处理。
- 标签页计时状态：前台运行时标题显示剩余时间与“专注”或“休息”；切到后台后显示不含数字的静态计时标题，避免把未刷新的数字当作实时倒计时。返回前台重新计算状态，到期后完成并恢复原标题。标题不包含任务、便笺或摘录内容；其他功能接管标题后不再抢回。

## 修复
- 配套处理临时视图的嵌套 Escape、原模块恢复和计时完成退出，以及页面本地化完成后的标题接管顺序；本批次未另行声明修复历史数据丢失事故。

## 注意事项
- 临时视图是当前页面的展示状态，不是保存的新布局，也不是浏览器全屏。未增加权限、外部服务或后台通知。暂停、重置及自然完成等原有计时操作仍可能写入计时状态。
- 后台标题有意保持静态，不承诺后台逐秒更新或后台准点通知。真实后台超过截止时间后，回到页面时才在本次原生测试中确认完成；本次不保证浏览器挂起、关闭或所有系统条件下的精确定时。
- 临时视图原生验证使用生产计时组件、合成内存存储和示例模块，覆盖宽屏、390px窄视图、真实键盘/鼠标、退出/Escape/暂停继续/重置，以及未加速的一分钟自然完成；21模板×2宽度的42项是浏览器脚本矩阵，不是逐模板人工验证。该夹具未执行完整 newtab 初始化。
- 标题原生验证执行真实 newtab 的两次本地化及标题挂接顺序，但仪表盘初始化与无关模块由合成夹具替代。17项观察、31次可信输入事件覆盖暂停/继续/休息、其他标题所有者，以及真实后台86.287秒跨截止时间后回前台完成。不是已安装扩展的完整集成验收。其他销毁、失效、工作区变更和冲突分支以自动测试为准；网络计数仅为夹具拦截范围。

## English
- Added a temporary, page-only focus view that shows the timer card and restores the original dashboard nodes, visibility and layout on exit. Pending edits or template previews block entry. Entering/exiting does not save a layout, and exiting leaves a running timer active. Existing timer controls still own Start, Pause, Resume and Reset.
- Running foreground titles show the remaining time and Focus or Break. Background titles intentionally become static and nonnumeric; returning recomputes the current state and restores the original title after completion. No task, note or excerpt content is included, and an external title owner is respected.
- Companion handling covers nested Escape, dashboard restoration, completion exit and title attachment after page localization. This release makes no claim to repair a historical data-loss incident.
- This is not browser fullscreen or a persisted layout. No permissions, external services or background notifications were added. Existing timer operations can still persist their state. Static background titles do not promise per-second updates or on-time background notifications; suspension, closure and all operating-system timing conditions are not guaranteed.
- Native temporary-view checks used production timer components with synthetic RAM and sample modules, covering wide/390px views, real input, exit/Escape, pause/resume/reset and an unaccelerated one-minute completion. The 21-template × two-width matrix was 42 scripted browser cases, not manual testing of every template; that fixture did not execute full newtab initialization.
- Native title checks executed production newtab's two localization passes and title attachment order with a stub dashboard and unrelated setup. Seventeen observations and 31 trusted input events covered title ownership, pause/resume/break and a real 86.287-second background interval across the deadline, completing on return. This was limited component/bootstrap QA, not an installed-extension integration pass. Other invalidation, destruction, workspace and conflict branches were automated checks; network counters cover fixture interception only.
