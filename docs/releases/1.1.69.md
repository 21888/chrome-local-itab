# 1.1.69 · 可选单模型流式预览 / Optional single-model streaming

## 新增

- 单提示词运行提供默认关闭的流式选项，完整审阅绑定当前选择；仍需明确发送一次请求。
- 逐步显示只读纯文本，标注未完成；只有正常停止标记及完整结束事件后才允许明确保存。

## 修复

- 分段 UTF-8/SSE 解析受总字节、事件大小、输出长度与截止时间限制；错误、截断、工具结果及非正常结束不会成为可保存回答。
- 停止、关闭、来源变化和旧请求回调不会覆盖新请求；部分输出不保存，密钥继续按临时规则清除。

## 注意事项

- 仅单模型提示词运行支持，比较、优化和问答仍保持非流式行为；不添加存储字段、提供商或权限。
- 停止不保证撤回服务商费用；兼容服务商必须提供受支持的事件格式，严格限制可能拒绝过长流。
- 真实提供商、实际扩展授权和耐久存储未验证；下列原生验收限定于声明的合成传输页面。

- 集成聚焦检查通过 164 项，Python 检查通过 53 项，运行包验证通过 108 个文件。独立审查另覆盖 UTF-8/BOM/CRLF 分段及截断/取消边界；测试存在重叠，不相加。本地未重跑聚合，发布仍须本次确切提交通过原有完整 CI。
- 原生浏览器使用 20 个生产匹配资产和显式内存传输/权限验证默认关闭、准确模式审阅、逐块文本、协议 stop 仍不可保存而 DONE 才可保存；真实 Stop 与 EOF 保留不可保存的部分内容。旧块/回调未覆盖新 STREAM2，新流完成后单独明确保存一次。
- 英文浅色界面中显示了中文响应文本，不代表中文界面验收。测试控件加入焦点顺序，未验证完整键盘/辅助技术、深色/窄屏或所有服务商错误变体；没有真实请求或密钥。

## English

- Partial plain text is read-only and marked incomplete. Only normal stop plus the complete terminal event enables explicit saving; failed, stopped, truncated or unsupported output is never saveable.
- Incremental UTF-8/SSE parsing enforces wire/event/output/deadline limits. Stop, close, source changes and late callbacks remain request-fenced, with temporary-key clearing preserved.
- Comparison, refinement and Q&A remain non-streaming. No storage fields, provider or permissions are added. Stop cannot reverse provider charges; defensive limits may reject unusually large streams.
