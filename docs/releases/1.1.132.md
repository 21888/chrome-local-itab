# 1.1.132 · 筛选焦点与导航目标修复 / Filter focus and navigation destination fixes

## 新增

- 本批修复两条既有交互，无新增权限、依赖或存储格式。

## 修复

- 提示词页面明确激活“清除筛选”时，在按钮被隐藏前将其拥有的焦点移回搜索框。其他控件及较新的渲染焦点保持原处；隐藏、inert、禁用、脱离文档或退役视图的旧按钮不再执行清除。草稿、变量和预览保持不变。
- 导航库同名个人分类使用完整当前快照生成稳定区分标签，目标选择、审阅、成功回执和已保存位置一致。处理大小写/NFC同名、字面名称仿冒生成标签及特殊旧ID碰撞，保存仍按原始分类ID，不重命名数据。
- 当前目标被删除并刷新后，明确选择有效目标只清除本次刷新拥有的过时“目标不可用”提示；保留刷新结果、取消选择数量、只读重载指引和较新的错误，不解除原有只读或写入防护。

## 注意事项

- 两项修复分别独立提交；合并严格串行全测 3464 Node / 84 Python 通过，运行包 123 个白名单文件。提示词独审 21 项、补充边界 8 项及受影响 128 项；导航独审 22 项通过。
- 云端 Chrome 155 使用精确生产页面和合成内存适配。提示词中英文浏览器合成矩阵各 20/20，另有真实键盘清除、变量及未保存草稿检查，原始回执独立验证 49 项。适配器的 manifest 标签曾为130，但生产候选实际为131，源码/ZIP/123文件绑定明确；历史嵌套对象不是深拷贝，未冒充逐帧快照，时序结论依据复制标量、可信输入及同步断言。
- 导航中英文合成矩阵各 14/14，六份回执独立核验 613 项。原生同名目标、删除目标后重选、只读重选分别产生 1/1/0 次合成内存写入，写入完整封包与最终原始ID一致；网络、CSP违规、权限、provider、剪贴板、外部打开及错误计数为零。模拟外部修改属于明确标记的fixture操作，不称作真实跨标签行为。
- 初版导航harness把一项inline style CSP违规误归为网络；修订wrapper恢复生产允许的样式语义，仍禁止外部连接及内联脚本，并分别核验网络/CSP。初版无效空白分类名fixture由生产验证正确拒绝，已换为有效NFC测试数据；旧诊断不算最终通过。未修改生产CSP或浏览器安全设置。
- 此批未安装候选，不代表实际扩展持久存储、系统输入法、屏幕阅读器或真实模型服务验收。没有截图上传或Chrome商店提交。
