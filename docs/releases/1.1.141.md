# 1.1.141 · 同步保护提示与快照时间 / Sync guard messages and snapshot times

## 新增

- Claude 用量实验页将已取得快照的读取时间和重置时间按当前界面语言及设备时区显示，并附明确 GMT 偏移。原始时间戳保留在可展开的详情中；无效或缺失时间显示「未知」。

## 修复

- 设置页中，保留旧网址拼写与布局关系而暂停 Sync 的状态和失败提示改用界面语言显示。
- 精确识别配置保存时截断为 240 字符的同一保护错误，避免本地化状态旁重复显示英文原文；无关或仅前缀相似的其他错误仍保留。

## 注意事项

- 时间格式化只处理已经取得的快照，不自动读取账户、不增加提供方请求、不启用权限。Claude 用量仍为手动实验功能；本次不验证真实账户、计费或实时额度。
- 同步保护规则、保存数据、启用偏好及权限保持原有行为。先推送两个独立功能及一项原生验收发现的修正，再以本版本合并发布。
- 冻结组合源码通过 4103 Node / 84 Python 及静态检查。130 项运行文件白名单不包含测试、验收回执或用户资料。
- 合成内存原生验收保留初版中英文 Claude 选取、关闭、重新开启、不同组织选取的回执；最终修正只改变 options.js，Claude 文件逐字节相同，不将旧回执重标为新运行。最终中文设置页原生上传及启用操作验证本地化状态和真实 240 字符保存边界。
- 日期跨日、夏令时回拨的不同偏移、无效时间，以及无关和前缀相似错误为另行标注的脚本用例。测试使用完整生产文件及合成 Chrome API，未安装扩展、使用真实账户或验证磁盘持久性。选项页仅合成内存错误与保护状态变更，保存内容及启用偏好保留；页面级计数为零云端写入及网络请求，不是浏览器全局网络抓包。
- 仅发布 GitHub，不上传截图或验收资料。Chrome 商店已上传的 1.1.137 仍等待资料校验提示处理，不替换上传包或提交本版本。
