## 新增

- 设置 → 数据新增「完整本地备份」：一次选择导出已保存配置、网站、本地图片、待办及历史副本、便笺、倒计时和专注偏好。
- 本地 JSON 导入提供模块预览及明确替换确认；只恢复所选模块。替换前保存并验证完整的本地恢复副本，可下载后重新预览恢复。
- 支持中文、英文界面及中英西文指南，保留原有单独导出入口。

## 修复

- 为旧版已保存设置补齐合法缺省字段、缺失的可选网站／分类图标和历史数字间距格式，避免升级用户无法导出完整备份；不放宽导入文件校验。
- 小模块单独导出不再受未选择的大体积数据影响；替换仍要求能建立完整恢复副本。
- 完整备份替换按钮采用独立的浅色／深色高对比度配色，保留清晰键盘焦点。

## 注意事项

- 仅包含已保存数据，不包含页面草稿、服务商认证、设备同步状态或进行中的计时会话。目标专注会话未结束时，不能恢复专注偏好，可取消选择该模块。
- 不新增权限，不扩大 Chrome Sync 或 Google Drive 的内容范围。文件可能包含私人内容，请妥善保存。
- 最大 32 MiB；超过 10 MiB 需明确确认后读取。大文件验证可能短暂停顿，下载请求不代表文件已保存完成。
- 仅保留最新一份完整恢复快照；启动下一次已确认恢复可能替换此前快照。最终写入结果不确定时不会自动重试或回滚，请先核对数据。
- 云端 Linux 原生 Chrome 已完成合成数据导出／选定模块恢复、恢复副本对比、草稿保护，以及中英文、深浅色和窄窗口检查；[真实验收记录](https://github.com/21888/chrome-local-itab/blob/v1.1.21/docs/complete-backup-native-validation.md)。不代表所有系统或故障场景已验证。

## English

- Adds a selected-module complete local archive for saved configuration/sites/images, Tasks/history, Scratchpad, Countdown and Focus preferences, with preview and explicit replacement.
- Establishes verified pre-restore recovery, preserves unselected modules and provider preferences, and fences stale reviews, writes and unsaved page edits. No automatic reload.
- Supports known legacy stored settings without relaxing portable-file validation; partial exports isolate selected data and the replacement action is readable in light/dark modes.
- No new permissions or broader cloud backup scope. Unsaved drafts, authorization, device sync state and active timer sessions are excluded. Unfinished destination Focus sessions block preference replacement.
- Archives are bounded to 32 MiB and large files require confirmation. The latest recovery snapshot may be replaced by a later confirmed restore; uncertain writes are never silently retried or rolled back.
