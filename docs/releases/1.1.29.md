# 1.1.29 · 当前已保存条目导出 Markdown / Current saved item as Markdown

1.1.29 新增当前单个已保存条目的 Markdown 导出。原生 Chrome 验收包含第一版广泛流程及最终焦点修正版的定向复测；两轮范围分别记录，自动化结果与历史截图不作为本次原生覆盖。

## 新增

- 在提示词或收藏详情中，明确选择“将当前已保存条目导出为 Markdown”，检查条目身份、保存版本、正文版本及字面原文，再选择“下载 Markdown”。取消或按 Escape 不会请求下载。
- 提示词仅导出当前已保存的模板正文及元数据，保留 `{{变量}}`，不包含临时填写值。收藏仅导出当前摘录、注释及元数据；已有提示词关联仅写入精确 ID，不读取或导出关联正文。
- 一次只导出当前单个已保存条目，包括选中的已归档条目；不包含草稿、修订提案、其他记录、历史正文或恢复快照。
- 收藏来源网址默认不包含。每次导出需单独勾选，核对保存的网址原文后才会包含；不访问来源网址。即使不包含网址，正文和注释仍可能含有私人信息。

## 修复

- 修正 Markdown 审阅对话框的初始焦点，避免长预览打开时把标题和隐私警告滚出视野；两类对话框均已完成定向原生复测。

## 注意事项

### 隐私与可靠性

- 文件是可读、未加密的 Markdown 副本，不是可导入恢复的备份。原有 JSON 备份流程不变。导出不修改保存数据，不新增权限、存储格式或网络请求。
- 正文及元数据以字面文本围栏输出，围栏长度超过内容中最长的连续反引号；保留 Unicode、换行、制表符、空白及 HTML 原文，不解释模板变量或内容。各节另加分隔换行。
- 使用固定文件名 `local-itab-prompt.md` 或 `local-itab-collection.md`。临时下载链接和对象网址会清理；“已请求下载”仅表示已交给浏览器，不证明文件已保存至磁盘。
- 审阅后若条目、保存版本或正文版本变化，切换页面或触发 `pagehide`、控制器退出，或保存／刷新仍在处理，则不会沿用过时审阅发起下载。打开编辑器时也不能导出；重复点击不会启动并行审阅，不会延后自动下载或重试。

## English

1.1.29 adds Markdown export for one current saved item. Native Chrome acceptance includes the first candidate’s broader workflows and a targeted recheck of the final focus correction. Their scopes are recorded separately; automated results and historical screenshots are not presented as native coverage for this change.

### Added

- In a saved prompt or collection detail, choose **Export current saved item as Markdown**, review the item identity, saved record version, body version and literal content, then choose **Download Markdown**. Cancel or Escape makes no download request.
- Prompts export the current saved template and metadata, preserving literal `{{variables}}` and excluding temporary filled-in values. Collections export only the current excerpt, notes and metadata. Existing prompt references contribute exact IDs only; linked prompt bodies are neither resolved nor included.
- Each export contains one selected saved item, including an archived selected item. Drafts, proposed revisions, other records, body history and recovery snapshots are excluded.
- Collection source URLs are omitted by default. Each export requires a separate opt-in and review of the exact saved URL before including it. No source is fetched. Body text and notes can still contain private information with the URL omitted.

### Fixes

- Corrects initial focus in the Markdown review dialogs so tall previews do not open scrolled past the title and privacy warning; both dialog types passed targeted native rechecks.

### Privacy and reliability

- The output is a readable, unencrypted Markdown copy, not an importable recovery backup. Existing JSON backup workflows are unchanged. Export does not modify saved data or add permissions, storage formats or network requests.
- Content and metadata are fenced as literal text, using a delimiter longer than any embedded backtick run. Unicode, original line endings, tabs, whitespace and HTML remain literal; variables and content are not interpreted. Sections add framing newlines.
- Fixed filenames are `local-itab-prompt.md` and `local-itab-collection.md`. Temporary download anchors and object URLs are cleaned up. **Download requested** means the browser received a request, not that a file was saved to disk.
- Selection, saved-version and body-version changes, navigation, `pagehide`, controller disposal, and pending save/refresh work prevent a stale review from downloading. An active editor also blocks export. Repeated clicks do not open parallel reviews; there is no deferred automatic download or retry.
