# 1.1.58 · 保留模板的卡片排序 / Template-preserving card order

## 新增

- 卡片布局可明确选择保留模板结构或自定义网格；全新仅排序的修改默认保留模板。
- 模板模式延续原侧栏与响应式排列，仍按保存顺序调整真实 DOM/键盘阅读顺序。

## 修复

- 已保存的旧列数、宽度和排序覆盖保持原网格行为，避免升级后意外改变布局。
- 切回模板模式会清除预览中的列数和跨度，但保留顺序；取消可恢复原已保存值，保存才提交变化。
- 备份对缺失新模式字段保持兼容，非法模式与未知字段仍拒绝。

## 注意事项

- 自定义卡片宽度依赖网格模式；模板模式不保证每个模板有相同列数。
- 隐藏卡片不会自动启用，个人内容与快捷方式自由坐标不改变。
- 自定义背景使用保证对比度的底板，卡片不透明度混合该底板而非任意墙纸。
- 合成测试不替代最终原生模板/响应式/键盘验收。

- 本地独立检查通过 2,033 项，Python 检查通过 53 项。未重跑资源受限的 20,000 链接规模用例，完整本地验证仍不完整；此版本更改了存储依赖，不能凭前版依赖相同推断该用例通过。发布须对应提交的原有完整 CI 通过。

- 非默认单卡跨度清除、设置宽度自动切网格、中文/深色和完整键盘/辅助技术矩阵未进行原生验证。
