# Local iTab 1.1.158

## 新增
- 本次为数据保护维护版本，没有新增产品功能、扩展权限、OAuth 范围或外部服务。

## 修复
- 浏览器页面未捕获有效 Workspace Session 时，存储管理器拒绝读取、保存和同步，不再退回旧根键存储。不会接管后来出现的全局 Session，不清空、重置或自动恢复数据；正常已绑定会话及显式 CommonJS 独立环境保持原有用途。
- 新标签页延迟启动分类导航失败时，捕获该异步错误并保留持久加载失败提示，不渲染默认分类或产生未处理的拒绝；正常导航路径不变。

## 注意事项
- 本次仅发布 GitHub，不提交 Chrome 商店，不修改 1.1.157 标签或资产。运行变更限于上述启动/存储访问边界及版本号，没有存储格式、迁移或权限变更。
- 回归使用实际生产脚本与合成浏览器 API/DOM 模型，覆盖缺脚本、无效工作区参数、拒绝访问时原始值不变、会话不改绑、正常保存，以及整页失败时表单锁定、个人模块不挂载和恢复/离开入口。模型不等于真实浏览器点击、恢复文件下载或安装升级验证。
- 历史 1.1.71 升级丢失事故的实际原因和用户数据恢复尚未获证明。条件性旧存储路由机制不证明该事故触发过此路径；没有复现自动默认值覆盖。本版不宣称事故已解决，不解除商店发布冻结，也不能保证所有设备或故障下绝不丢失。
- 同身份安装升级、浏览器重启、原生崩溃/配额和受影响资料恢复仍未完成实证。升级前保存草稿并导出所需备份；手动安装保持原加载目录，不卸载、清空存储或换目录排障。诊断数据不会自动合并或恢复；SHA-256 校验不是签名或恢复保证。

## English
- Data-protection maintenance only: no new product feature, permission, OAuth scope or external service.
- Browser storage without a captured Workspace Session now refuses reads, saves and sync instead of falling back to legacy root keys. It never adopts a later global Session or clears, resets or automatically restores data. Valid bound sessions and explicit standalone CommonJS use remain supported.
- Deferred category-navigation startup failures are caught and retain the persistent load-failure notice without rendering default categories. Normal navigation is unchanged.
- Actual production scripts with synthetic browser API/DOM models cover missing bootstrap, invalid workspace tokens, unchanged raw values on refusal, stable session binding, normal saves, locked Settings and unmounted personal modules on page failure. This is not native browser navigation, recovery-file download or installed-upgrade acceptance.
- GitHub only; no Store submission, schema/migration/permission change or modification of v1.1.157 assets. The historical upgrade incident is not attributed or resolved, and automatic default overwrite was not reproduced. Same-ID installed upgrades, restart, native crash/quota and affected-profile recovery remain unverified. Save drafts, export backups and preserve the original loaded directory; do not uninstall or clear storage. Checksums do not guarantee recovery or absolute safety.
