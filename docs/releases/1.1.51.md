# 1.1.51 · 本机模型连接预设 / Device-local model connection presets

## 新增

- 在提示词运行与已保存内容问答中共用连接预设，保存名称、HTTPS 接口地址与模型 ID。
- 支持显式保存、选择与删除；选择预设不会授权站点或发送请求。

## 修复

- 跨标签页修改使用互斥锁与精确旧值校验，避免覆盖过期设置。
- 切换预设清空临时密钥并撤销旧请求审核；仍需重新审核和显式发送。

## 注意事项

- 预设为本机未加密元数据，仅允许名称、地址与模型 ID；这些字段不得填写凭据。API 密钥不进入预设。
- 预设不进入导出、完整备份、同步或 Drive 快照；恢复备份保留目标设备已有预设。
- 未使用真实凭据、真实站点授权或提供商调用；原生预设操作与完整发布验收单独执行。

- 最终完整本地测试通过 1,948 项，Python 检查通过 53 项。云端原生英文浅色模式通过：在问答保存合成连接、重开默认不自动选择、主动选择、提示词对话框共用与完整审核、删除撤销审核、问答重载确认删除。未输入密钥、点击授权或发送。
- 原生范围不含备份、同步、并发冲突、提供商调用、中文、深色或窄屏；这些不据此声称通过。

## English

- Shares explicitly saved name/HTTPS endpoint/model presets between prompt runs and saved-context Q&A, with selection and deletion controls.
- Selecting a preset neither grants permission nor sends anything. It clears the temporary key and invalidates prior review.
- Cross-tab locks and exact previous-value checks prevent stale metadata overwrites.
- Metadata is local and unencrypted. Only name, URL and model are allowed; never enter credentials in those fields. Keys are not stored.
- Presets are excluded from exports, Complete Backup, Sync and Drive. Restoring backups preserves existing destination-device presets.
- No real credential, site grant or provider call was used. Native preset interactions and complete release acceptance are separate gates.

- Final complete local suite: 1,948 tests passed, plus 53 Python checks. Bounded native English/light checks passed for saving synthetic metadata in context Q&A, reopening without automatic selection, explicit selection in both dialogs, exact prompt review, deletion invalidating review and persisted deletion after context reload. No key, grant or Send was used.
- Native backup/sync, concurrency conflicts, provider calls, Chinese, dark and narrow-screen behavior remain outside this gate.
