# 1.1.40 · 滚动时保持拖动位置 / Keep shortcut dragging aligned while scrolling

## 新增

- 收录 1.1.39 的旧版原位升级、旧备份定向恢复、完整及选择性恢复验收记录，保留精确比对范围与来源限制。

## 修复

- 拖动快捷方式时，实时计算页面与容器滚动后的坐标，避免因旧画布位置导致跳偏或保存错误坐标。
- 滚动后直接松开、最终指针位置、嵌套与横向滚动均有处理；完成或取消后清理监听与动画回调，防止影响下一次拖动。

## 注意事项

- 完成拖动只写入目标快捷方式；取消不写入。整个应用窗口尺寸变化仍沿用取消当前拖动并重新布局的行为。
- 1,756 项 Node、53 项 Python 测试及 16 项独立事件模型检查通过；原生实测覆盖已滚动页面拖动、吸附、240px 横向滚动、单项位置保存和重新打开。[明确范围与限制](../qa/scroll-drag/native-acceptance.md)。
- 旧版升级记录针对 1.1.21/1.1.32 到 1.1.39，验证重新打开页面，不代表完整浏览器重启、崩溃耐久性或所有平台。

## English

### Added
- Bounded 1.1.39 acceptance records for same-path historical upgrades, legacy destination restore, full and selective backup recovery, with precise provenance and comparison limits.

### Fixes
- Shortcut dragging uses live page/canvas coordinates after scrolling instead of stale pointer-down geometry.
- Handles scroll followed directly by release, the latest pointer endpoint, nested and horizontal scrolling, with listener/frame cleanup after completion or cancellation.

### Notes
- Completed drag writes only the moved identity; cancellation does not write. Whole-app resizing continues to cancel the current gesture and reflow.
- 1,756 Node tests, 53 Python tests and 16 independent event-model checks pass. Native smoke covers scrolled-page dragging, snapping, 240px horizontal scrolling, one-position persistence and reopening. [Exact scope and limits](../qa/scroll-drag/native-acceptance.md).
- Historical upgrade evidence covers 1.1.21/1.1.32 to 1.1.39 and fresh-page reopening, not whole-browser restart, crash durability or every platform.
