# Local iTab 1.1.154

## 新增
- 本批次整合两项编辑体验修复，未新增权限或外部服务。

## 修复
- 待办编辑保存、取消或按 Escape 退出后，适合返焦时回到同一待办的新“编辑”按钮；该待办已被过滤隐藏时回到添加输入框。用户已主动移走焦点时不抢回焦点。
- 编辑快捷方式时，如果原分类 ID 已不在分类列表中，显示“未在分类列表中”的临时选项，避免仅修改标题等字段时意外改变原分类归属。实际选中的分类 ID 保留原始 Unicode 和空白字符；也可明确选择其他已有分类。

## 注意事项
- 临时分类选项只用于当前编辑器，不重建已删除的分类，不自动修复其他记录，也不改变导入验证、存储格式、恢复副本或同步协议。本次不承诺恢复已经丢失的真实用户数据。
- 待办返焦的原生验证使用生产组件和合成内存存储：真实键盘保存后返回同一待办的新编辑按钮、Enter 重开、取消零新增写入，以及过滤后回到添加输入框；两次显式保存产生两次预期内存写入。主动移焦、异步竞争等其他分支由脚本测试覆盖，不代表所有浏览器或辅助技术行为均已实测。
- 分类原生验证使用生产快捷方式组件与合成内存存储，英文实际标题修改保留原 research 分类，取消不新增写入，明确选 Work 并提交后才迁移；中文检查临时选项标签与取消零写入。两次英文显式保存仅写链接数据，其余原始内容和坐标保持一致。分类删除初始状态由测试夹具提供，删除操作本身由脚本覆盖；未执行扩展安装或实际恢复导入。初始夹具依赖顺序错误导致的两次零写失败记录保留，按生产加载顺序重载后通过，未修改生产代码。

## English
- Task editing now restores focus to the same task's replacement Edit button after Save, Cancel or Escape when appropriate. If filtering hides that task, focus returns to the Add field. Deliberately moved focus is not reclaimed.
- Shortcut editing retains a saved category ID that is absent from the category list through a temporary “Not in category list” option. Editing only the title no longer implicitly changes that assignment. Actual selected IDs retain their exact Unicode and whitespace; users can still explicitly choose another listed category.
- Temporary options do not recreate deleted categories or repair unrelated records. Import validation, storage formats, recovery copies and Sync protocols are unchanged. This release makes no claim to recover previously lost real user data.
- Native task checks used production components with synthetic in-memory storage and real keyboard input: Save-to-Edit, Enter-to-reopen, Cancel without an extra write, and a filtered-out task falling back to Add. Two explicit saves made two expected RAM writes. Other focus-relocation and race branches were script-tested; this is not exhaustive browser or assistive-technology certification.
- Native shortcut checks used production components with synthetic RAM: an English title-only save retained research, Cancel added no write, and an explicit Work selection moved the shortcut only on submission. Chinese checks covered the temporary label and cancellation without writes. The two English saves wrote links only and preserved all remaining raw content and coordinates. The fixture began after category deletion; deletion itself was script-tested. No installation or recovery import was tested. Two initial zero-write fixture failures from dependency load order remain recorded; reloading in production order passed without changing production code.
