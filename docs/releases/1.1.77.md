# 1.1.77 · 网站库添加状态筛选 / Filter sites by saved state

## 新增

- 「发现网站」增加全部、未添加、已添加筛选与数量，结合当前搜索、分类和高级筛选查找网站。
- 添加状态按当前工作空间全部个人分类中的标准化网址判断，改名或切换目标分类不影响识别；不读取其他工作空间。

## 修复

- 在未添加视图成功添加后，移除对应卡片并更新数量，保留成功提示；焦点移到邻近卡片，最后一条移除后移到空结果提示。

## 注意事项

- 清除筛选会重置添加状态；重新打开读取最新工作空间并重置筛选，并发变更继续遵循既有冲突保护。
- 不改权限、目录内容或快捷方式保存格式；候选完整回归为 2293 项 Node 与 53 项 Python 通过。
- 限定原生验收通过：英文 Clarity 桌面的筛选/计数、末条添加后空结果与成功提示、下一 Tab 到 Close、已添加视图、目标分类独立性、清除/重新打开重置，以及 320px 亮暗状态按钮换行。未直接确认空提示 activeElement，未测剩余卡片前后自动焦点、中文或完整矩阵。
