# 1.1.59 · 保留问答回答标题 / Preserve Q&A answer titles

## 新增

- 区分用户主动编辑的回答标题与自动建议标题，支持在请求等待期间继续编辑。

## 修复

- 响应到达不再覆盖发送前或等待期间填写的标题，包括主动清空的标题。
- 未编辑的默认标题仍来自该次已审核的问题；清空草稿会重置标题编辑状态。
- 过期响应、关闭或工作区代次变化不覆盖新标题；持久化及不确定重试期间保持既有冻结规则。

## 注意事项

- 不扩大问题、来源、回答或快照保存范围，不改变 API 密钥与权限处理。
- 合成测试覆盖标题与生命周期边界；原生真实提供商行为与扩展持久化需独立验证。

- 本地独立检查通过 2,039 项，Python 检查通过 53 项。20,000 链接规模用例未在本地重跑，完整本地验证仍不完整；发布须对应提交的原有完整 CI 通过，未修改工作流或放宽断言。
- 独立原生浏览器测试页面使用 19 个与生产逐字节匹配的资产、合成响应/权限与内存存储，验证发送前标题、真实等待期间编辑标题、保存后可见标题、主动留空拒绝写入后补填恢复，以及清空后重新使用问题默认标题。最后一份默认标题回答故意未保存。测试延迟控制不进入生产扩展。
- 这不验证真实提供商、Chrome 权限、扩展持久化、工作区切换或原生 Stop/迟到响应；相应竞态另有合成模型检查。

## English

- Tracks explicit answer-title edits separately from generated defaults and allows editing while waiting for a response.
- Replies no longer overwrite pre-send or in-flight titles, including deliberately cleared input. Untouched defaults use the exact reviewed question; clearing the draft resets title intent.
- Stale reviews/results, closed views and generation changes cannot replace newer titles. Existing persistence/retry freezing remains intact.
- This changes no question/source/answer/snapshot save scope, credentials or permissions. Synthetic lifecycle checks do not establish real-provider or durable-extension behavior.

- Local checks passed 2,039 unique cases plus 53 Python checks. The 20,000-link case was not rerun locally, leaving local validation incomplete. Publication requires the exact commit’s existing complete CI gate; no workflow or assertion was relaxed.
- Native browser interaction on an isolated test page using 19 byte-identical shipped assets, synthetic responses/permissions and in-memory storage verified pre-send titles, edits during an actually held response, exact visible saved titles, intentional blank rejection without a write followed by recovery, and Clear restoring question-derived defaults. The final default-title answer was intentionally unsaved. Test delay controls are not shipped.
- Real providers, Chrome grants, durable extension storage, workspace changes and native Stop/late responses are not claimed; additional races remain covered by synthetic model tests.
