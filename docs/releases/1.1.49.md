# 1.1.49 · 已保存内容问答与任务草稿 / Saved-context answers and task drafts

## 新增

- 从首页选择全局 AI 收藏摘录或当前工作区的已保存便笺，逐项审核后向自己选择的模型提问。
- 展示完整目的地址、模型、问题、模式与选中摘录；默认不选中任何内容，编辑后必须重新审核。
- 可显式保存回答到 AI 收藏，或审核严格解析的任务 JSON 并确认批量加入当前工作区待办。

## 修复

- 关闭面板、切换工作区与过期回调不会发起新的保存；较新的任务版本与重复确认受到校验保护。
- 不确定的保存结果保留原命令身份，避免重试重复添加；无法安全重试时要求先检查现有待办。

## 注意事项

- 复用可选 HTTPS、非流式模型请求；站点授权和发送分别操作，密钥不持久化，服务商可能收费。
- 仅包含主动选择的已保存摘录，不读取未保存草稿或自动抓取来源网页。AI 收藏明确标为跨工作区全局内容。
- 模型回答、引用和任务均未被验证为事实；任务只在用户审核并确认后写入，不自动执行。
- 合成测试不代表真实提供商、原生权限或完整原生浏览器验收；没有使用真实密钥、授权站点或发起真实模型请求。

- 最终完整本地测试通过 1,878 项，Python 检查通过 53 项。云端原生 Chrome 英文浅色模式通过默认不选来源、编辑发送摘录、完整请求审核、取消、Escape 焦点与关闭后重开清空连接检查。取消清空问题/来源/审核，地址与模型保留到关闭；原始收藏重载仍为 1 项、1 个版本。
- 上述保留证据仅限界面，未采集全存储差异或网络轨迹。原生响应保存、任务提取、工作区便笺、深色、窄屏与中文仍未验证。

## English

- Adds opt-in questions over selected global AI collection excerpts and the current workspace's saved note.
- Shows the complete reviewed destination, model and outgoing request. Nothing is selected by default; edits invalidate review.
- Answers can be explicitly saved to the global collection. Strict task JSON is reviewed and confirmed before an atomic add to workspace Tasks; tasks are never executed.
- Workspace fences, stale-callback checks and immutable receipt retries protect against late or duplicated writes. Ambiguous receipt conflicts require inspecting existing Tasks.
- Reuses optional HTTPS non-streaming model requests; permissions and sending remain separate. Keys are not persisted; providers may charge. Unsaved drafts and source-page fetches are excluded.
- Model statements and citations are unverified. Synthetic tests do not establish real-provider, native-permission or complete browser acceptance; no real key, grant or provider request was used.

- Final complete local suite: 1,878 tests passed, plus 53 Python checks. Native English/light checks passed for default-off source selection, edited outgoing excerpt, complete request review, Cancel, Escape/focus and close/reopen connection reset. Cancel clears question/source/review but retains endpoint/model until closing. The original collection remained one item/one version after reload.
- Preservation evidence is UI-bounded, without whole-storage diff or network trace. Native response saving, task extraction, workspace notes, dark/narrow/Chinese remain untested.
