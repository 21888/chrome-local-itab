# 1.1.43 · 便签文本追加导入 / Reviewed Scratchpad append

## 新增

- TXT 导入新增保留已保存文本并追加的显式选项，预览完整合并文本及字符数后再确认。

## 修复

- 合并时保留原有换行，仅在两段非空且相接处没有换行时添加分隔换行。
- 合并总长度、未保存草稿、并发更新及重试均受保护，取消不会写入，重试不会重复追加。

## 注意事项

- 追加需要明确选择并确认，不会自动替换已有内容。
- 自动化测试与原生浏览器验收分别记录。

## English

- Added an explicit keep-and-append TXT import mode with a complete merged preview and character count.
- Preserves adjacent newline boundaries and enforces combined limits, draft and concurrent-change guards.
- Cancellation writes nothing; guarded retries avoid duplicate appends. Native acceptance is recorded separately from automated tests.
