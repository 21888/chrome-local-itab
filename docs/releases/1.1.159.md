# Local iTab 1.1.159

## 新增
- 本次为提示词库和收藏库的失败恢复维护批次，没有新增产品方向、权限、OAuth 范围或外部服务。

## 修复
- 收藏页的辅助提示词监听注册失败时，隔离该异常，仍展示可正常读取的已有收藏；关联提示词保持不可用，不接纳缺少订阅保护的快照，并明确提示保留草稿页面、另开页面重试。
- 提示词库或收藏库自身监听注册失败时，不再停留在启动加载状态，而是显示双语不可用提示。该实例拒绝主库读取及写入，停止后续摘录/结果交接，不认领或确认摘录令牌，不显示无效的读取重试。
- 提示词页辅助收藏监听失败时，关联结果区不再提供无法恢复该实例的“重新读取结果”，改为保留旧页草稿及变量、另开页面的准确说明。普通读取失败仍可通过原重试按钮恢复；新实例注册成功后才读取原保存内容。

## 注意事项
- 本次仅 GitHub 发布，不提交 Chrome 商店，不修改 1.1.158 标签或资产。没有存储格式、迁移、默认值写回、自动恢复或权限变更。
- 回归使用实际 Store、Controller、View 及页面启动脚本，配合合成 RAM、DOM 和事件故障，覆盖失败提示、拒绝不安全读取/写入、原始值和写次数不变、旧草稿及变量保留、新实例正常关联和普通读取重试。此证据不是原生浏览器重开、跨标签 Chrome 存储传播或安装持久化验收；另开页面不会迁移旧页未保存草稿。
- 本批次也包含跨入口备份结算与关联返回的集成回归证据，未因此声称新增恢复功能或解决历史事故。原生跨标签返回流程仍未完成验收。
- 历史 1.1.71 升级丢失事故的实际原因和受影响数据恢复仍未获证明。商店冻结保持；同身份安装升级、浏览器重启、原生崩溃/配额及受影响资料恢复的实证缺口不因这些模型测试解除。不保证任何设备或故障下绝不丢失。
- 升级前保存草稿并导出所需备份；手动安装保持原加载目录，不卸载、清空存储或换目录排障。诊断数据不自动合并或恢复；SHA-256 校验不是签名或恢复保证。

## English
- A recovery-maintenance batch for the prompt and collection libraries, without new permissions, OAuth scopes or external services.
- An auxiliary prompt-subscription failure no longer aborts a collection page whose own saved-data backend is available. Existing collections remain visible, while prompt links fail closed and explain that registration requires a separately reopened page.
- Failure to register either library's main subscription now shows an explicit unavailable state rather than leaving startup rejected at its loading screen. That instance admits no main-library read or mutation and stops before capture/result handoffs, without claiming or acknowledging a capture token.
- The prompt page's unavailable saved-result subscription no longer offers an ineffective read-retry button. Its message explains keeping the old page for unsaved drafts and variable values and reopening separately. Ordinary read failures retain their working retry action; a fresh instance must register successfully before reading saved data.
- Real Stores, Controllers, mounted Views and bootstrap scripts with synthetic RAM/DOM/event faults verify visible failures, unchanged raw data/write counts, retained old draft/session objects, successful fresh registration and normal read retry. Cross-entry backup settlement and linked-result return integration evidence are also included. These are not native reopening, Chrome cross-tab storage, installed persistence or historical-incident acceptance; unsaved drafts are not transferred to a new page.
- GitHub only: no Store submission, schema/migration/default-write/automatic-restore change or modification of v1.1.158 assets. The historical data-loss incident remains unattributed and unrecovered; installed same-ID upgrades, restart, native crash/quota and affected-profile recovery remain unverified. Save drafts and export backups before upgrading, preserve the original loaded directory, and do not uninstall or clear storage. Checksums do not establish signatures, guaranteed recovery or absolute safety.
