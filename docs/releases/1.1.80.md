# 1.1.80 · 网站库确认后批量添加 / Review and add selected sites

## 新增

- 网站库支持逐项明确选择最多 20 个网站，切换筛选时保留选择；无默认全选或自动添加。
- 提交前显示完整网站名单与目标分类，确认后一次保存；可返回浏览或清空选择，原单站 Add 继续可用。

## 修复

- 批量保存先验证全部条目、分类、布局及隐私/工作空间状态，标准化网址去重并保留原链接和布局；失败或结果不确定时不报告成功或盲目重试。

## 注意事项

- 添加沿用已有 Sync 与在线图标设置，无新增权限、目录请求或默认快捷方式。
- 实现候选完整回归为 2328 项 Node、53 项 Python 通过；独立事务审查未发现必须修复项，但不替代原生界面验收。
- 限定中文 Clarity 桌面与 320px 亮暗原生检查通过：跨筛选两条选择的完整名单和学习目标、返回取消不写、确认后从 6 条增至 8 条且重复不增，以及另一个未提交选择的取消/Escape 返回入口。20 项上限、挂起保存竞争等仍仅由合成测试覆盖，不代表完整原生矩阵。
