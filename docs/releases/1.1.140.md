# 1.1.140 · 审核保留副本并下载配置 / Review retained copies and download configuration

## 新增

- 独立恢复页增加「审核配置文件」和审核后的单独下载步骤。先显示所选原始来源、校验依据、时间限制、范围、数量及原始网址，再允许下载配置文件；不会自动导入或覆盖当前数据。
- 只有自身带有历史 SHA256 且校验匹配、字段完整、受现有导入器支持并能逐值无损保留的 rawConfiguration 或 Manual payload 才可下载。保留网址原始拼写、顺序、重复项、layoutId 与坐标；不把缺失字段补默认值，也不静默删除未知字段。

## 修复

- 将现有配置导入/导出规则提取为无副作用共享 codec，独立恢复页无需加载 Storage 或工作区管理器。以冻结 139 导入器作独立对照，确认同值接受及同样拒绝。
- 加强调查导出和配置审核的含凭据网址检查；未知、缺失、隐含字段及会发生值改写的来源拒绝生成可导入文件。刷新、来源变化、关闭和页面隐藏使旧审核失效，重复下载受限。

## 注意事项

- preMigration 本体没有持久化的历史 checksum，仍只能调查；现在计算的 hash 或来源登记不能补足历史完整性证据。独立带校验的嵌套恢复副本可单独审核。调查 JSON 仍不能作为恢复包导入。
- 本功能不保证找回已丢失的数据，不能重建未保留的内容。校验匹配不证明来源真实、最新或包含全部资料。页面不写入、删除、迁移或恢复存储，也不连接 Sync/Drive。
- 下载的是配置文件，不是完整备份：不含个人模块、其他工作区、历史副本或提供方状态；文件使用既有禁用 Sync 的传输对象，不改变设备的 Sync 设置。后续导入仍是另行确认的替换操作。文件可能包含私人标题、网址和文本，请自行妥善保管。
- 两个独立功能提交后合并发布。组合冻结源码通过 4059 Node / 84 Python 及静态检查；130 项运行文件白名单排除测试、历史 oracle 和用户资料，未新增扩展权限。
- 原生验收使用四份中英文合成内存回执；两份实际配置下载各 7371 字节，与产品 Blob 完全一致，当前与 139 的纯导入器均接受且配置逐值一致。未知/缺失字段即使 hash 匹配仍拒绝；坏 hash 和无校验 preMigration 不开放下载；记录零存储写入、网络或 provider 调用。
- 原生验收使用精确生产文件及合成内存适配，不等同于安装扩展、真实用户恢复、磁盘持久性、设置页导入或真实 Sync/Drive 验证。原生晚到异步、强制下载失败及精确节流时间未覆盖；自动化测试是独立证据。合成回执和下载文件不随版本发布。
- 本次仅发布 GitHub。Chrome 商店已上传的 1.1.137 继续等待资料校验提示处理，不替换上传包、不提交本批版本。

The existing disabled-Sync transport object does not change this device's Sync setting. Later import remains a separately confirmed replacement. Keep private titles, URLs and text secure.
