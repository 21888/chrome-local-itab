# 1.1.93 · 导航可读性与地区显示 / Navigation readability and country labels

## 新增

- 运营主体所在地在筛选框、已生效条件标签和详情中统一显示本地化名称及 ISO 代码；未知仍显示未知。

## 修复

- 小幅加深浅色导航的次要文字与焦点描边，改善已选卡片可读性；深色、入口与禁用样式不变。
- 地区名称格式化不可用或异常时回退 ISO 代码，不改变目录数据或精确筛选逻辑。

## 注意事项

- 两项修复合批；合并与第二精确 CI 通过 2478 项 Node、64 项 Python。发布提交仅版本与文档。
- 对比度数字来自声明的不透明色对 sRGB 计算，不是浏览器像素测量或完整 WCAG 认证。限定中文桌面亮色原生检查了已选卡文字/焦点及美国 (US)/未知三处一致与代表筛选；其他语言、Intl 故障、暗色/320px 未原生重测。
- 无新增权限、持久化或外部请求；最终 93 包已独立核实仅 manifest 与开发包不同，普通重新加载显示实际版本且新标签页基线正常；不是本次重跑全部功能。
