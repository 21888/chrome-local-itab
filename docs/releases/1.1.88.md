# 1.1.88 · 筛选状态与 AI 输入反馈 / Filter visibility and AI input feedback

## 新增

- 网站库高级筛选折叠后仍显示可逐项移除的条件标签；移除单项保留其余筛选、所选网站与分类草稿，并维持明确的键盘焦点。
- AI 上下文面板实时显示所选素材数、问题/摘录及完整提示的 UTF-16 长度，标明现有限额和无效输入；不自动截断，不把字符数称为 token、价格或服务配额。

## 修复

- 提示计数与严格打包共用序列化逻辑，异常字段读取有防御性检查；不放宽现有校验、审阅或显式发送要求。
- 修正文档中的模板总数为 21 种，并采用每个提交完整 CI、每 2～3 个功能合并发布的流程；维护提交不计功能数。

## 注意事项

- 本批包含两个独立功能提交。实现合并后的全部 2404 项 Node 与 64 项 Python 测试通过；本发布提交仅升版及添加说明。
- 限定原生检查覆盖中文筛选标签移除/焦点/保留草稿及 320px 亮暗换行；AI 小样计数、模式变化、撤选/清空、取消保留和 320px 可读性。实际预览 payload 相等、长输入边界、全语言主题矩阵未原生验证，相关边界为合成测试证据。
- 不新增权限或网络行为，不调用真实 provider；开发快照以精确包哈希区分，详见源码内两份验证记录。最终 88 包仅 manifest 与第二开发包不同，原生重新加载已核版本及两功能入口存在；不是全部原生场景重跑。

## English

- Keeps removable advanced-filter chips visible when controls are collapsed, preserving remaining filters, selected sites, category drafts and predictable keyboard focus.
- Shows local AI source counts and UTF-16 question/excerpt/full-prompt budgets using the strict packer's serializer. These are not tokens, prices or provider quotas; no automatic truncation or relaxed review/send validation.
- Adds defensive input inspection, corrects the documented 21-template inventory and batches releases after two or three independently validated feature commits.
- The combined implementation passed 2404 Node and 64 Python tests. This release commit only changes version and documentation. Bounded Chinese native checks cover filter chips/focus/drafts and AI small-input counters/mode/clear behavior with 320px light/dark readability. Actual preview-payload equality, long native boundaries and full locale/theme matrices were not verified natively. The final 88 runtime differs from the second development package only in manifest; native Reload verified version and minimal presence of both features, not a full repeat of native scenarios. No new permissions, external behavior or real-provider calls.
