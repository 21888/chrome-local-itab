# 1.1.135 · 按用途找网站 / Find saved sites by use

## 新增

- 已保存网站搜索可匹配内置导航目录的用途与中英文别名。仅完整规范化网址匹配的已保存网站获得只读元数据；不会按同域名猜测，不添加网站或个人标签。
- 结果明确标注「内置用途/别名匹配」，短语与所有词模式仍保留原有语义，分类、排序与分页保持不变。

## 修复

- Finder 打开时读取精确原始快照，合法旧记录的缺省图标、分类或属性顺序不再导致首次或重复打开被误判为数据变化。
- 真实原始数据变化、重复旧网址、读取失败、过期回调仍受保护；关闭后重开可重试读取。

## 注意事项

- 两个功能独立提交；其间两项原生验收文档维护不计作功能。无新增权限、依赖、存储格式或外部请求。
- 用途搜索同源严格串行全测 3570 Node / 84 Python 通过；首次本地全测的导航视图文件被 SIGKILL，未计为通过，同源码限制 Node 堆到 512 MB 后全套通过。未断言该终止的具体原因。
- 原生验收包含中英文界面各一条 ASCII writing 搜索、重复打开及 Escape；18 个合成浏览器场景另行验证中文「翻译」「必应」、缺省字段、原始变化及异步保护。工具未能原生输入中文，不冒充原生中文输入覆盖。
- 使用精确生产文件与合成内存适配；未验证真实网站、provider、Chrome 存储或安装态升级。旧快照修复另有两条原生流程和 14 个合成浏览器场景。123 个运行文件白名单不变，不含测试资料、用户备份或凭据。
- 本次为 GitHub 批次发布，不代表 Chrome Web Store 已提交或上架。

## English

- Search saved sites by built-in directory uses and bilingual aliases. Metadata is read-only and attached only to an exact canonical saved URL, never inferred from the hostname. Results label the built-in metadata source; phrase/all-words semantics, categories, ordering and pagination remain intact.
- Read a raw snapshot when Finder opens, avoiding false stale-state failures for legal legacy default fields or property ordering and repeated opens. Real raw changes, duplicate legacy URLs, failures and retired callbacks retain their guards.
- Two independent functional commits; intervening QA documentation is not counted as a feature. No added permissions, dependencies, storage format or external requests.
- Same-source serial tests: 3570 Node / 84 Python. An initial local full run had a navigation-view file terminated by SIGKILL and was excluded; the same source passed with a 512 MB Node heap limit. The termination cause is not asserted.
- Native scope: one EN and one ZH UI flow using ASCII writing, repeated opens and Escape. Eighteen separate synthetic browser cases cover Chinese queries and freshness/async guards. Native Chinese text entry was unavailable. The preceding raw-snapshot fix has two native flows plus fourteen synthetic cases.
- Exact production assets and synthetic memory adapters were used, not real provider/website, Chrome storage or installed-upgrade acceptance. The allowlist remains 123 runtime files, excluding test data, user backups and credentials. GitHub publication does not imply Chrome Web Store submission or availability.
