# Local iTab 1.1.160

## 新增
- 本次为三项失败处理和页面生命周期修复的 GitHub 维护批次，没有新增产品方向、权限、OAuth 范围或外部服务。

## 修复
- 提示词页控制器已销毁后，旧确认回调不再发起新写入；视图销毁时清理自有确认框且不恢复旧焦点。已经进入后端的写入仍按真实结果结算，不伪称取消或回滚。
- 搜索 URL 准备失败时，保留原输入并显示双语“修改后重试”提示，不再让提交异常静默退出；不自动改写文字、重试导航或保存查询。回归中的未配对 UTF-16 来自程序赋值，尚未证明原生键盘或粘贴可产生该值。
- 便签的后端监听注册失败时，不再停在加载状态。首页和设置页显示双语重开提示，保持禁止编辑并移除无效 Retry；失败实例拒绝后续读取和写入，新实例成功注册后才恢复读取与正常自动保存。普通读取失败的重试及正常自动保存逻辑不变。

## 注意事项
- 仅 GitHub 发布，不提交 Chrome 商店，不修改 1.1.159 标签或资产。没有存储格式、迁移、默认值写回、自动恢复或权限变更。
- 本批次包含完整备份关联库恢复、当前工作区书签导入及已完成页面旅程的回归和验收记录。原生云浏览器补证包括确认框打开时离页、当前提示词返回链接和双页归档/恢复传播；这些使用合成数据及浏览器 API 桥接，不等同于安装扩展后的 Chrome 存储或真实落盘。新页面不迁移旧页未保存草稿。
- Scratchpad 故障和搜索异常使用真实实现配合合成后端/DOM 验证；未证明原生监听故障、所有输入方式或所有故障组合。程序边界修复和新增验收均不作为历史事故归因。
- 历史 1.1.71 升级丢失事故的实际原因和受影响数据恢复仍未获证明。商店冻结保持；同身份安装升级、浏览器重启、原生崩溃/配额及受影响资料恢复的实证缺口未解除。不保证任何设备或故障下绝不丢失。
- 升级前保存草稿并导出所需备份；手动安装保持原加载目录，不卸载、清空存储或换目录排障。诊断数据不自动合并或恢复；SHA-256 校验不是签名或恢复保证。

## English
- A GitHub maintenance batch containing three failure-handling and page-lifecycle fixes, without new product directions, permissions, OAuth scopes or external services.
- Disposed prompt pages reject new mutations from old confirmation callbacks and do not restore focus into destroyed views. Writes already dispatched to the backend retain their actual outcome; they are not falsely reported as cancelled or rolled back.
- Search URL preparation failures now retain the input and show a dedicated edit-and-retry message instead of leaving a rejected submission without feedback. The fix does not rewrite text, automatically retry navigation or persist a query. The unpaired UTF-16 regression uses programmatic assignment; native keyboard or clipboard reachability has not been established.
- Scratchpad subscription registration failures now show a reopen instruction on the card and Settings instead of remaining at loading. Editing stays disabled, ineffective Retry is hidden, and the failed instance admits no later reads or writes. A fresh instance must register successfully before reading saved text and resuming normal autosave. Ordinary read-retry and autosave behavior remain unchanged.
- This batch also includes bounded complete-backup/linked-library recovery, current-workspace bookmark import and production-page acceptance evidence. Cloud-browser checks cover leaving an open prompt confirmation and cross-document current-details, archive and restore navigation with synthetic data/API bridges. They do not establish installed Chrome storage, native disk persistence or transfer of unsaved drafts into a new page. Synthetic registration/input failures are not evidence of the historical incident's cause.
- GitHub only: no Store submission, schema/migration/default-write/automatic-restore change or alteration of v1.1.159 assets. The historical data-loss incident remains unattributed and affected-data recovery unproven. Same-ID installed upgrades, restart, native crash/quota and affected-profile recovery remain unverified. Save drafts and export backups before upgrading, keep the original loaded directory, and do not uninstall or clear storage. Checksums do not establish signatures, guaranteed recovery or absolute safety.
