# 1.1.105 · 来源重载与本地提示词审阅 / Source reload and local prompt review

## 新增

- AI 面板内显式重载已保存来源；有选择或摘录编辑时先确认。成功后清理全部来源选择/编辑并使旧审阅失效，保留问题、连接、筛选和已有回答的原快照；取消或失败保留当前内容。
- 无需端点、模型或密钥即可本地审阅完整提示词，并显式复制当前已审阅文本。本地审阅不授予网络权限，也不能替代发送前的独立请求审阅。

## 修复

- 来源重载与复制使用当前面板/代际保护，旧行、关闭后回调或已失效审阅不能操作新状态；不自动发送或保存。

## 注意事项

- 普通提交完整回归分别通过 2624/81 与 2640/81 项 Node/Python 检查。实际 105 完整回归通过 2640 项 Node 与 81 项 Python；普通重新加载核实实际版本、两入口及首页基线，仅最小身份检查。
- 中文桌面浅色原生覆盖重载取消/确认和原摘录恢复；空连接本地审阅后实际复制 431 字符合成提示词并粘贴到本地未保存问题，视觉首尾与计数匹配，编辑/重载立即失效，Allow/Send 始终禁用。并非逐字节剪贴板读取断言。
- 无 provider 请求、凭据、保存或权限新增。外部来源变化、失败/竞争、已有回答、任务模式复制、长 Unicode、暗色/窄屏等仍仅合成或未测。
