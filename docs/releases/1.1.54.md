# 1.1.54 · 审核提示词优化 / Reviewed prompt refinement

## 新增

- 对当前已保存模板填写优化要求，审核完整请求后调用自己选择的模型；不发送已填写的变量值或其他提示词。
- 以纯文本对照原模板与建议，显式接受后才新增历史版本，原模板留在历史中。

## 修复

- 验证占位符名称、数量与有效语义；拒绝过期来源、工作区替换或未保留变量的建议。
- 不确定保存重用原命令与回执；关闭、页面离开和相同输出不会自动创建新版本。

## 注意事项

- 优化针对当前已保存模板，即便预览正在显示历史版本。模型建议可能改变含义，必须人工审核。
- 复用临时密钥、非流式请求与本机连接预设；服务商可能收费，测试未使用真实密钥、权限或请求。
- 自动测试不代表真实提供商与完整原生验收；原生验证单独执行。

- 最终完整本地测试通过 1,981 项，Python 检查通过 53 项。云端原生英文浅色发送前检查通过：历史已填预览显示旧版内容时，优化仍仅审核当前已保存模板、优化要求及完整目的地址/模型，排除填写值和旧版正文。Escape/焦点/重开清空临时连接，原两版本历史保持不变。
- 没有授权、发送、生成回复或接受建议；真实模型、接受新版本、占位符拒绝和保存竞态未进行原生验收。
