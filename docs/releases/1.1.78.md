# 1.1.78 · 流式响应空元数据兼容 / Empty streaming metadata compatibility

## 新增

- 无新增产品功能。

## 修复

- AI 流式响应与普通 JSON 响应使用相同的可选工具/拒绝元数据检查，接受无内容的 null、空字符串、空数组和空对象，避免把普通文字回答误判为工具或拒绝结果。
- 有效载荷及 false、0 等畸形标量仍拒绝，不发布混合工具/拒绝文字。

## 注意事项

- 完成回答仍须 stop 与 [DONE]；截断、缺少终态及其他结束原因仍不能保存为完整回答。
- 不改权限、超时、大小限制或请求次数，不调用真实服务商进行验证。
- 与前置导航筛选候选集成后，完整确定性回归通过 2296 项 Node 与 53 项 Python；这是合成解析验证，不是实时服务商兼容性或原生网络取消验收。

## English

- No new product feature. Streaming and ordinary JSON responses now share the optional tool/refusal metadata check, accepting null, empty strings, empty arrays and empty objects without misclassifying ordinary text.
- Actual payloads and malformed scalars such as false or zero remain rejected before mixed text is published.
- Completion still requires stop plus [DONE]; truncated or other incomplete responses remain incomplete. Permissions, deadlines, limits and request counts are unchanged.
- Integrated deterministic verification passed 2296 Node and 53 Python tests. No live provider was called; this is not a real-provider compatibility or native network-cancellation acceptance claim.
