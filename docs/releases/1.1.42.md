# 1.1.42 · 按精确分类查找站点 / Exact saved-site categories

## 新增

- 站点查找增加精确分类选择，可不输入关键词直接浏览分类，并与文字搜索组合。
- 显示已保存分类总数和当前结果数，提供原生下拉键盘操作、中英文界面及使用说明。

## 修复

- 分类切换会正确重置分页，重名分类与重复网址仍按记录身份区分。
- 分类名称被删除后仍按原标识显示剩余网站，无剩余网站时保留空结果，不擅自扩大到全部分类；清空或关闭后明确重置筛选。

## 注意事项

- 分类筛选只影响本次查找，不改写已保存站点、分类或布局。
- 原生浏览器验收与自动化模型测试分别记录。

## English

### Added
- An exact category selector supports browsing without a query and combining category scope with text search.
- Distinguishes saved category totals from current result counts, with native-select keyboard support and English/Chinese UI copy.

### Fixes
- Category changes reset pagination while duplicate URLs and same-name categories retain exact record identity.
- Deleting category metadata retains exact-ID filtering of orphaned sites; no remaining sites means an empty result rather than silently widening to all categories. Clear and close deliberately reset filters.

### Notes
- Filtering does not write saved sites, categories or layout.
- Native browser acceptance and automated model coverage are recorded separately.
