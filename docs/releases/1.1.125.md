# 1.1.125 · 原文差异与待办子集 / Original text differences and task subsets

## 新增

- 两个模型都成功完成同一当前提示词后，可显式打开“比较原文差异”。按行显示共同内容及各模型独有内容，保留精确换行类型与末尾换行信息；这不是质量评分或模型推荐。超过既有 250,000 格计算预算时明确提示降级，完整显示两侧中间原文。
- AI 提取待办后可勾选要添加的子集，默认全选。按原顺序保留重复项；先审阅所选待办，再明确添加。选择变化使旧审阅失效，JSON 编辑重置候选及选择；零选不能审阅或添加。不确定写入仍核验原操作，不新建批次。

## 修复

- 修复原生浏览器合成验收发现的“添加这些待办”旧计数残留。旧审阅失效时清除按钮计数，重新审阅后显示当前批次计数；提交中或不确定写入仍保留原审阅计数。
