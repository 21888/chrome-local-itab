# 1.1.127 · 导航多词搜索与上下文模板复用 / All-words search and context prompt reuse

## 新增

- 已保存站点搜索新增显式“全部词语”模式：用空白分词，每个词都需出现在标题、地址或分类中，可跨字段匹配，不要求顺序。默认仍为连续短语，标点保持字面含义；支持分类交集和原有分页。清空或关闭重开恢复默认模式，不持久化搜索条件。
- AI 上下文问答可选择当前未归档提示词模板，填写变量或明确使用空值，先预览完整替换问题，再明确替换。没有默认选择，不自动发送、复制、授权或保存。替换仅更新当前内存问题并使旧审阅失效；选中的摘录、过滤、输出模式、连接及旧答案的原始来源信息保持不变。

## 修复

- 模板预览只在显示副本将 CRLF/CR 转为单个 LF，修复浏览器中单 CR 视觉连行；应用与审阅保留原始问题、尾空白和精确字符预算。4000 UTF-16 单位可完整应用，4001 或纯空白拒绝，不截断。真实编辑后以编辑文本为新草稿。
- 预览/应用重新验证模板身份、当前版本、未归档状态及工作区；库变更、较新操作、关闭、离开和失效读取拒绝陈旧结果。不确定写入继续使用原有锁。

Continuous phrase stays the default; punctuation remains literal. Category filtering and pagination are retained. Clear or close/reopen resets the mode without persistence.
- Reuse an active saved prompt in AI context Q&A: explicitly choose a template, fill variables or choose empty values, preview the full replacement, then explicitly replace the in-memory question. Nothing sends, copies, grants access or saves automatically. Existing excerpts, filters, mode, connection and the previous answer's original provenance remain intact; prior reviews are invalidated.

Allow a complete 4000-UTF-16-unit question; reject 4001 or whitespace-only input without truncation.
