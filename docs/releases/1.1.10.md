## 新增
- 快捷方式新增/编辑表单有未保存改动或保存尚未完成时，刷新、离开或关闭标签页会请求浏览器原生提醒。

## 修复
- 保存失败后的未保存草稿继续受保护；较早保存操作结束不会错误解除较新草稿的保护。
- 完全还原初始标题、网址、图标和分类后不再误判为有改动；无需输入事件的图标变更也能识别。

## 注意事项
- “取消”、关闭按钮、遮罩及普通 Esc 仍是主动丢弃操作；输入法组字时的 Esc 保持原有保护。
- 提醒是否出现由 Chrome 决定，选择离开、强制关闭或浏览器抑制提醒仍可能丢失草稿。本版本不增加离页保存或草稿持久化。

## English
- Added native departure warnings for changed shortcut drafts and pending saves.
- Fixed protection across failed or older saves, exact field restoration and icon changes without input events.
- Explicit dismissal still discards drafts. Chrome controls warning display; this is not persistent draft storage.
