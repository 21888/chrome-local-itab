# Local iTab 1.1.157

## 新增
- 本次为维护版本，没有新增功能、扩展权限、OAuth 范围或外部服务。

## 修复
- 跨工作区网站查找在读取中或无法完整读取时，不再显示上一范围的旧分类计数或允许选择失效分类。成功读取后恢复经校验的分类；同范围刷新保留原筛选，必要时将焦点留在查询框内，不抢回用户后来选择的控件。
- GitHub 发布工具校验新建标签的返回目标，仅在随后明确报告标签暂不存在时进行少量有界重读。目标不符、权限或其他错误仍立即停止；不改写标签、不覆盖发布资产。此前一次创建后回读失败的原因尚未证实，不能据此认定服务存在确定的可见性故障。

## 注意事项
- 补充已完成功能的合成浏览器流程验收：待办复用的取消/独立新增、写前失败和回执失败的重试、旧结果晚到时保护新草稿；便笺选区查找与循环导航；跨工作区查找隔离、范围恢复和变更刷新。这些验收不是新增功能，也不是全部路径或持久化证明。
- 本次仅发布 GitHub，不提交 Chrome 商店，不修改 1.1.156 标签或资产。扩展运行时仅有查找视图修复和版本号变更，没有存储、迁移、数据格式或权限变更。
- 数据保留仍是发布门禁，不能保证所有设备、磁盘故障或未验证环境下绝不丢失。历史升级事故的实际原因及用户资料恢复尚未获证明；本版不宣称解决该事故，也不解除商店更新的独立待核验条件。
- 自动回归覆盖生产方法中的合成迁移、写入冲突、权威回读、恢复副本和事务保护。浏览器验收使用合成内存后端，不等于同身份安装升级、浏览器重启、磁盘持久化、崩溃/配额、真实输入法或辅助技术验收。
- 升级前请保存未提交草稿并导出所需备份；手动安装保留原加载目录，不要卸载、清空存储或改用新目录排障。SHA-256 只比较文件字节，不是签名、下载成功证明或恢复保证；诊断包不会自动合并或修复数据。

Installed same-ID upgrades, browser restart, native crash/quota and affected-profile recovery remain unverified.
