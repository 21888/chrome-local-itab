# 1.1.103 · 空态恢复与保存回执核验 / Empty-state recovery and save receipts

## 新增

- 导航库区分未选择、已选被隐藏、普通无匹配和目录不可用等状态，提供对应本地恢复按钮，保留选择、目标与分类草稿。
- AI 回答保存不确定时可显式“检查此前保存”，只读核验原始操作回执；仅严格确认已提交才解除锁定，不发起新保存或 provider 请求。

## 修复

- 保存证据缺失、冲突或读取失败时保留原操作、标题和快照选择。确认的是历史操作，不保证记录现在仍存在或未被后续修改。
