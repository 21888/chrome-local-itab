# Local iTab 1.1.153

## 新增
- AI工作台可添加临时手动摘录，默认不选中；选择后可审阅、编辑、恢复原文或移除，明确标记来源未经核验。重新加载已保存来源时保留临时摘录与其选择、编辑及原节点。
- 离线导航库新增 Ollama、ComfyUI、LibreChat 三个官方入口及中英说明，总计149个网站。既有146条记录原顺序和字段保持，分类及用途词表不变。

## 修复
- 本批未单列既有功能修复；新增临时摘录的配套草稿保护包括：临时摘录参与草稿放弃确认与异步失效检查；修改会撤销旧请求审阅，晚到操作不会覆盖更新后的草稿。此前已完成回答的历史请求和来源不被改写。

## 注意事项
- 添加和本地审阅临时摘录不自动保存、不自动联网、抓取来源或读取剪贴板。确认清除或关闭后临时内容丢弃；默认关闭的“同时保存问题与摘录”若明确启用并保存，选中摘录可随原请求快照进入全局AI收藏及未加密备份。回答本身也可能复述私人输入，请检查后再保存。
- 临时候选最多12条，标题最多200个Unicode码点且400个UTF-16单位，正文最多16000个UTF-16单位；所有来源合计仍受12项选择和32000单位完整提示词限制，无静默裁剪或自动选中。手动外部回答仍不能附加虚构上下文快照。
- 新目录仅提供网站发现入口，不安装软件、下载模型或连接本地/云端模型。硬件、部署、模型许可及外部API/托管费用须自行核对；Ollama含可选云端服务，ComfyUI入口指本地下载，LibreChat入口指自托管指南。来源查阅日期不保证当前价格、可用性或离线性。
- 原生摘录检查为生产对话框与组件加合成RAM：实际粘贴、选择、本地审阅、编辑、重载、清除取消/确认及关闭共12点，零写入/网络；未实测模型发送或快照保存。目录原生检查覆盖中英三卡详情及六个搜索别名，英文选择后审阅并返回浏览，14检查点零写入/网络；中文未重复审阅流程，未外部重核价格或安装扩展。
