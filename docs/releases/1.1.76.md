# 1.1.76 · 内置网站导航库 / Built-in site discovery

## 新增

- 新标签页快捷方式区域新增「发现网站」，内置 84 个网站与 116 个双语用途标签，可按类别浏览、搜索，并组合用途、运营主体所在地、组织与定价筛选。
- 网站卡片提供本地文字标记、简介、用途与来源信息；选择已有个人分类后可明确添加，不自动写入预设网站。
- 目录随扩展离线提供；不获取远程目录或图标，不新增权限或分析追踪。

## 修复

- 网站来源详情摘要显式加入键盘焦点顺序，并在共享对话框焦点边界中排除收起 details 的隐藏后代；保留首个直接 summary 子树并处理嵌套详情。
- 导航库英文结果数在单条时显示 `1 site`，其余使用 `sites`；中文保持「个网站」。
- 无独立的既有功能修复；新增入口复用并补强现有快捷方式保存边界，检查当前分类、布局与隐私设置，识别重复网址并验证保存结果。

## 注意事项

- 网站目录为编辑整理，并非流量或热度排名；来源检查日期不保证当前价格、功能或地区可用性，未知信息仍标为 unknown。请以官方网站最新说明为准。
- 添加链接遵循已有 Sync 和在线图标设置，保存前重新检查；关闭导航库不会添加选择。保存结果不确定时不声称成功或盲目重试。
- 首个摘要焦点修复包的收起详情焦点逃逸已由后续 closed-details 修正解决：2281 项 Node、53 项 Python 及七项旧实现失败的焦点回归通过。英文 Clarity 暗色桌面原生复测确认未添加/已添加单结果正反 Tab、展开/收起详情及普通添加快捷方式对话框的代表焦点回环；不代表所有对话框、多卡片、语言或辅助设备均已验收。
- 限定原生检查覆盖英文 Clarity 桌面/320px 亮暗布局及代表性搜索、筛选、详情、添加 Learning 分类、防重复与关闭/键盘路径；最终 1.1.76 另核版本、入口、两条合成快捷方式保留与 `1 site`。未逐项验收全部 84 站、筛选组合、中文或所有主题，官网链接未实际打开。

## English

- Result counts use English `1 site` and plural `sites`, with unchanged Chinese count wording.
- Cards provide local text marks, descriptions, use tags and source information. Explicitly add a site to an existing personal category; nothing is added automatically.
- The catalog works offline, with no remote catalog/icon fetching, analytics or new permissions. Adding follows existing Sync and online-icon settings, rechecks current state, deduplicates URLs and verifies the save.
- This is an editorial catalog, not a popularity ranking or a guarantee of current prices, features or regional availability. Check official sources for current terms.
