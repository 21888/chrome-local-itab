# 1.1.74 · 亮色删除按钮文字 / Light-mode Delete text

## 新增

- 无新增产品功能。

## 修复

- 通用危险操作按钮在显式亮色模式下使用较深的文字色，修复 Clarity 亮色本地话题 Delete 标签过淡的问题；无显式色彩模式的旧版 ink-paper 同样采用较深文字。
- 显式暗色模式保留原有浅色文字；完整备份等已有专用按钮仍使用自身文字色规则。

## 注意事项

- 仅改通用危险操作文字色令牌，不改删除确认、保存逻辑、背景色或权限。
- 静态测试按已声明的表面及半透明图层计算 Clarity、Graphite、Folio 两种色彩模式与旧 ink-paper 示例的对比度，不代表所有主题、背景、状态或渲染像素均已达标。
- 已完成限定原生检查：Clarity 英文亮色桌面/320px 的 Delete 可读性和布局、320px 编辑与删除的确认/取消，以及暗色桌面可读性。未重测暗色 320px、未原生覆盖 Graphite/Folio 或全语言/主题矩阵；未测量原生像素对比度。

## English

- No new product feature. Generic danger buttons use darker text in explicit light mode and legacy ink-paper without an explicit color mode, addressing faint Clarity light topic Delete labels.
- Explicit dark mode keeps the existing pale text. Specialized controls such as complete-backup actions retain their own text-color rules.
- Changes only the generic danger-text token, not confirmation, saving, backgrounds or permissions.
- Static alpha-compositing checks cover declared Clarity, Graphite, Folio light/dark surfaces and legacy ink-paper examples. They do not establish every theme, background, state or rendered pixel's contrast.
- Bounded native checks passed for English Clarity light desktop/320px Delete readability and layout, 320px edit/delete confirmation and cancellation, and dark desktop readability. Dark 320px was not repeated; Graphite/Folio, all-language/theme coverage and native pixel contrast measurements were not included.
