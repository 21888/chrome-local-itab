# Local iTab 1.1.151

## 新增
- 新标签页“浏览21种布局”支持用当前网站、分类、背景与卡片设置临时试看模板，明确点击“应用”后才保存；取消、关闭、收起或 Esc 结束临时预览。

## 修复
- 首次读取前将当前模板按钮的焦点交给状态提示，避免禁用按钮时丢失焦点；后续选择保持焦点，晚到读取不会抢回已移到输入框或图库标题的焦点。
- 应用自身精确提交的外观事件不再清空已确认的本地保存提示；其他来源或不同外观、设置代次变化仍使待完成预览失效。

## 注意事项
- 预览与取消不写存储、不修改保存的布局坐标或切换工作区，仅使用已有图标缓存。快捷方式和分类编辑在预览期间暂停，其他模块独立授权的保存并未全局暂停。
- 应用仅保存模板字段，在既有写锁中核验状态、合并最新外观并读回确认；旧配置首次建立外观对象时保留有效明暗模式。写入或读回失败提示结果未确认，不自动回滚或盲目重试。已提交存储的应用不能靠关闭图库撤销。
- 本地保存确认后沿用既有已启用的 Chrome Sync 调度；不保证远端同步已完成。紧凑模板选择器和设置页图库仍按原方式立即保存，设置示意图并非实时仪表盘。
- 原生组件检查使用合成内存数据和模块样文本框：网格取消/Esc零写入，自由布局应用一次外观写入，隐藏坐标与其他原数据保持。原生Sync关闭；启用Sync调度仅脚本mock覆盖。另在320/1280 CSS像素iframe视口中以真实键盘验证焦点、按钮可达和保存提示在自身事件后持续；晚到读取不抢焦点使用注入延迟。不是完整新标签页、读屏发声或刷新后提示持久性保证。

## English
- The new-tab “Browse 21 layouts” gallery now temporarily previews templates with current sites, categories, background and card overrides. Explicit Apply saves; Cancel, Close, collapsing the gallery or Escape ends the preview.
- First admission hands focus from its owned template button to the status notice before disabling controls. Later choices retain focus, and late reads do not reclaim focus moved to an input or gallery summary. An Apply's exact own appearance event no longer clears confirmed local-save feedback; unrelated or changed state still invalidates pending preview.
- Preview/cancel do not write storage, change saved coordinates, switch workspaces or fetch icons. Shortcut/category editing is temporarily paused; independently authorized module saves are not globally paused. Apply checks state under the existing write lock, merges the template into latest appearance and verifies readback. Legacy appearance creation preserves effective color mode. Uncertain writes are reported without automatic rollback or blind retry; closing cannot undo an already submitted write.
- Confirmed local saves use the existing opt-in Chrome Sync scheduler, without claiming completed remote synchronization. The compact selector and Settings gallery keep immediate-save behavior; Settings diagrams remain schematic.
- Native component checks used synthetic RAM and a module-like textarea: Grid Cancel/Escape made no writes; Free Apply made one appearance write while preserving hidden coordinates and unrelated raw data. Native Sync was disabled; enabled scheduling has scripted mock coverage only. Native keyboard checks in 320/1280 CSS-pixel iframe viewports verified focus, reachable controls and save feedback surviving its own event. A scripted read delay tested late focus behavior. This does not certify the complete new-tab shell, screen-reader speech or status persistence after reload.
