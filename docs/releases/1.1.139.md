# 1.1.139 · 旧网址兼容与收藏章节导航 / Legacy URL compatibility and saved-answer sections

## 新增

- AI 收藏当前正文的阅读模式新增默认折叠的「章节」目录。至少两个非空根级 Markdown 标题时显示，支持重复标题、Setext 和各级标题；选择章节只定位当前答案正文并聚焦对应标题，不改变外页滚动或网址。
- 同一正文重绘及阅读/原文切换保留当前阅读器的临时阅读位置；忙碌、读取待定或错误状态暂停目录操作，保留安全焦点，不抢回用户已移开的焦点。无跨会话位置记忆或新增存储字段。

## 修复

- 保留受支持的历史已存网址原始拼写与身份，避免仅因缺少协议、末尾斜线等差异拒绝旧配置，或在规范化后混淆网址对应的布局。读取、明确编辑、备份和导入沿用原始身份；打开时另行计算安全目标网址。
- 保持迁移前副本、原顺序和隐藏视图坐标；升级不会自动替换网址、分配身份、重排坐标或恢复资料。非法或含凭据等不安全网址继续拒绝，不放宽新输入规则。

## 注意事项

- 受旧网址身份影响的 Sync 上传/下载会阻断并说明兼容原因；不会自动把可能改变身份的快照传给旧客户端。兼容配置的便携 JSON 使用 2.0 / urlIdentityVersion 1 标记，旧版导入器明确拒绝。不要为绕过提示而修改标记或手动规范化网址。
- 本功能不能重建已丢失的数据，也不代表已经恢复任何真实用户资料。明确导入仍需确认并保留导入前恢复副本。备份可包含私人标题、网址与文本，分享前请检查。
- 两项真实功能独立提交后合并发布。组合冻结源码通过 3926 Node / 84 Python 与静态检查；未新增扩展权限，运行文件白名单为 128 项，不含测试资料或用户备份。
- 旧网址原生验收使用五份合成回执和实际产品导出文件，覆盖启动、仅改标题、Finder、便携导出/确认导入及 Sync 阻断。章节导航使用四份中英文回执，两种语言各 38/38 脚本边界检查；原生点击、键盘、200% 缩放与忙碌前后位置保持通过。
- 原生验收为精确生产文件加合成内存适配，不是已安装扩展升级、真实用户恢复、磁盘持久性或真实 Sync/Drive 验证。导航验收没有存储、网络、剪贴板或权限写入。章节忙碌切换与边界矩阵为明确标注的脚本场景。
- 本次仅发布 GitHub。Chrome 商店已上传的 1.1.137 仍等待资料校验提示处理；不替换该上传包、不提交本批版本。
