# 1.1.34 · 搜索收藏注释 / Search saved excerpt notes

## 新增

- 首页统一 AI 搜索现在可以查找已保存收藏的注释，显示注释命中的原文片段，并打开对应收藏。
- 英文、简体中文标签和三语 README 同步说明搜索范围。

## 修复

- 补齐只有注释包含关键词时无法找到收藏的搜索缺口，保留正文、标题、标签优先顺序与单条结果去重。

## 注意事项

- 仅搜索当前未归档收藏的已保存注释；不扩大到提示词附加字段、历史、恢复副本、来源网址或草稿。
- 空查询仍显示正文预览；没有新增权限、持久索引、存储写入或联网。
- 片段以纯文本显示，支持中文、大小写展开和 Unicode 边界；跨标签更新与读取失败仍撤下旧结果。

- 最终整合源码通过 1,673 项 Node 与 53 项 Python 回归；原生 Chrome 验证注释独有词匹配、原文片段标签、精确新标签导航、关闭/重开保留搜索词、Esc 返回焦点和深色键盘操作。

## English

### Added

- Unified AI search can find saved excerpt notes, show a literal matching snippet and open the exact saved collection record.
- English/Simplified Chinese labels and all three README guides describe the expanded scope.

### Fixes

- Notes-only keywords now find the collection while preserving body/title/tag priority and one result per record.

### Notes

- Only current active collection notes are searched. Prompt extras, archived records, history, recovery copies, source URLs and drafts remain excluded.
- Empty queries still preview the body. No new permissions, persistent index, storage writes or network access.
- Snippets remain plain text with Unicode boundary handling. Cross-tab updates and read failures invalidate old results.

- Final integrated source passed 1,673 Node and 53 Python tests. Native Chrome verified notes-only matching, exact snippets/labels and new-tab destination, retained query on close/reopen, Escape focus return and dark-theme keyboard operation.
