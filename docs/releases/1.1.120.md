# 1.1.120 · 历史提示词与导航键盘恢复 / Historical prompts and navigation keyboard recovery

## 新增

- 收藏详情可显式审阅并复制已保存上下文中的完整历史提示词。按字面显示原始输入，独立于答案复制，不读取当前来源或调用模型。

## 修复

- 导航刷新前将焦点移到面板，完成后仅在用户未转移焦点时返回刷新按钮，保持键盘关闭路径。
- 外部布局失效后的只读浏览仍可退出仅已选及清除筛选；选择、检查与添加继续受保护。过期预览回调不修改新状态。

## 注意事项

- 历史提示词可能含敏感来源，请先审阅再复制。它属于保存时的请求，不证明当前来源或后续答案版本。
- 原生历史提示词复制与 537 字符合成样例严格相等，覆盖换行、引号、中西文、脚本字面量和反斜线；浅深 100%/200% 与键盘关闭焦点通过。原四收藏内容已通过正常备份恢复；恢复产生可逆历史及元数据版本变化。
- 导航原生覆盖刷新完成返回焦点、Escape、分类改名后只读锁与浏览恢复。读取挂起时 Escape、外部新增导致零选择、过期预览移除等竞态仍为模型覆盖。
- 两项普通 CI 通过 2917/84 和 2925/84 项 Node/Python；实际 120 完整回归通过 2925 Node/84 Python，最小原生身份确认 120 和已恢复基线。保留 118 个运行时文件，无新增权限。
- 已有 Claude 功能仍为默认关闭实验，未实号验证。
