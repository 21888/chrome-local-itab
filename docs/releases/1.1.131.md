# 1.1.131 · 拖动取消与收藏来源状态修复 / Drag cancellation and collection source state fixes

## 新增

- 本批集中修复两条既有交互，不新增权限、依赖或存储格式。

## 修复

- Free 和手动吸附布局拖动期间可用未修饰的 Escape 取消，恢复未提交的位置和拖动状态。取消后的延迟松开只拦截该次指针手势的误点击，保留后续普通点击、键盘激活和新拖动；次要指针及迟到重绘不能提前清除保护。
- 拖动取消尊重已处理按键、重复键、修饰键和输入法组字状态；退役会话回调不能影响新手势。
- 收藏交接面板根据当前勾选、精确版本、来源元数据和实际发送原文显示“精确选中”“已改变”或“未选中”，不把上方审阅快照误称为当前发送内容。
- 清除选择、重载或编辑后可明确再次使用同一已保存版本，重新读取核验并保留已有的替换确认。首次使用之后仍保持通知、隐藏页面和生命周期失效保护，不偷偷替换现有草稿。
- 成功再次使用时清理自己拥有的过时通用重载/本地审阅提示；失败、忙碌或较新的提示不会被旧回调清除。禁用已聚焦按钮时保留正确焦点归属。

## 注意事项

- 两个独立修复提交分别通过精确 CI；最终严格串行测试 3439 Node / 84 Python。拖动独审 32 项及受影响 52 项，收藏最终独审 28 项通过。运行包仍为 123 个白名单文件。
- 早期并发测试有进程退出/SIGKILL，没有作为通过证据，原因未确定；冻结拖动源码随后协调串行全测 3406/3406 通过。收藏原生测试发现重载后再次使用仍有旧通用提示，已修复并重新全测、独审和浏览器验收，不使用旧候选冒充通过。
- 云端 Chrome for Testing 155：拖动 Free/手动吸附各 18/18 合成事件矩阵；合成指针配合真实 Escape 验证归位、搜索保留和延迟松开零写入/零误打开。原生 Enter、点击和完整拖动另行验证，正常原生拖动各有一次合成内存保存。合法浏览器工具不提供分离的按下/移动/松开，所以全原生按住鼠标途中 Escape 未测，系统输入法也未测。
- 拖动修复开发包曾同路径安装补验，原生完整拖动保存及重载回读、菜单点击/Escape/Enter通过；搜索因重复 renderer error9 未完成，原因未确定。正常导入恢复后设置导出 data 相等，导入产生其正常恢复备份。此边界未被称作完整安装态验收。
- 收藏最终精确生产页面配合合成内存适配，中英文各 23/23 浏览器预定义矩阵及独立原生可信键鼠交互通过；旧通用提示矛盾为零。应用写入、网络、权限、provider、剪贴板及打开窗口计数为零。矩阵每种语言另有 3 次明确标记的合成 fixture 修改，用于版本/归档通知测试，不冒称全程零修改。
- 收藏候选未安装；上述浏览器证据不代表真实持久 Chrome 存储或模型服务验收。本批无截图上传、Chrome 商店提交或权限变更。
