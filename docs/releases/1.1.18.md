## 新增

- 增加任务导出的下载异常、资源清理、保存数据与未保存草稿隔离的回归测试。

## 修复

- 任务导出遇到浏览器下载准备或触发异常时，显示文件下载错误，不再把带数字错误码的浏览器异常误报为保存失败。
- 下载触发失败后移除临时链接并释放对应的 Blob URL；正常触发仍延迟释放 URL。

## 注意事项

- 导出任务仍只包含已保存任务及以前的本地副本，不包含当前未保存的新增或编辑草稿；导出不会修改或清空这些草稿。
- 不改变权限、存储格式、便笺或倒计时的导出行为。异常路径经过自动化模拟验证；不声称已验证浏览器真实下载失败。
- 触发下载不代表文件已成功保存；请在清除扩展数据或卸载前检查下载的备份文件。

## English

- Fixes Tasks export error reporting: browser download preparation or activation errors are reported as file errors, including DOMExceptions with numeric codes, rather than as failed saves.
- Removes temporary links and releases blob URLs after failed activation; successful activation retains delayed URL cleanup.
- Regression coverage checks download failures, cleanup, storage-read errors, exact saved JSON, and retained quick-entry and editor drafts. Tasks exports still contain only saved records and previous local copies.
- No permissions, storage-format, Scratchpad or Countdown behavior changes. Failure paths use deterministic model tests, not native browser failure validation. Starting a download does not verify that a file was saved; check the backup before clearing extension data or uninstalling.
