# 1.1.23 · 个人提示词库 / Personal prompt library

## 状态

本地集成候选的变更记录，不代表已推送、创建 GitHub Release 或通过商店审核。记录时公开最新版仍为 1.1.21；1.1.22 工作空间版本已在本地提交，但尚未推送。本候选包含该工作空间基础，相关变更见 [1.1.22 记录](1.1.22.md)。

## 新增

- 新标签页增加「提示词库」入口，在独立扩展标签页管理跨工作空间共用的本地资料。支持标题、正文、分类、标签、工具备注、收藏，以及本地搜索和筛选；代码和 HTML 仅作为文字显示。
- 支持 `{{变量}}` 填写、完成版预览和用户点击复制。同名变量一次填写、重复替换；未填变量阻止完成版复制，明确选择空值则允许留空。支持字面括号及整篇原文模式；变量值不自动写入正文、历史或备份。
- 正文修改追加历史，元数据修改不增加正文版本。恢复历史正文追加新版本，保留后续记录及精确版本身份；删除进入可恢复回收站并保留正文和历史。
- 完整本地备份扩展至 schema 3，全局提示词只保存一次，包含有效记录、回收站、正文历史及恢复副本。恢复需明确选择全局资料库目标并预览替换范围；仅恢复提示词不要求工作空间结构匹配。

## 保存与恢复保护

- 多标签页过时编辑会被阻止并保留草稿，可查看已保存内容、另存新提示词或明确放弃。写入读回验证失败不等于未保存，不能把连续新建或重新提交当作安全重试。
- 完整恢复前保留本地恢复副本；恢复不确定时阻止后续危险写入，要求检查候选数据后明确处理。恢复后的旧页面不能静默覆盖新资料。
- schema 1/2 旧备份，以及未选择提示词模块的 schema 3 恢复，均保持现有提示词不变。相同正文版本 ID 对应不同文字时拒绝恢复，不会悄悄改指向其他版本。

## 限制与验证

- 没有模型执行、AI 网站读取、服务商连接、API 密钥字段、新权限或自动上传。普通设置导出、Chrome Sync 和 Google Drive 不包含提示词。资料库是跨工作空间的全局内容，不提供工作空间归属筛选，也不是账户或安全隔离。
- 最多 200 条（包含回收站）、每条正文 32,000 个 Unicode 码点、20 个正文版本、8 个恢复副本，资料库总预算 2 MiB。达到上限会拒绝写入而非截断或清除历史；当前没有永久删除、清空回收站或自动清理。完整备份另受 32 MiB 上限约束。
- 草稿、变量及预览只存在当前标签页内存中；离页警告不保证出现。备份不包含未保存内容。本地存储和 JSON 备份未加密，请勿保存密码或密钥；导出本身不会释放库内容量。
- 集成候选的完整自动化回归通过 1,351 项 Node 测试与 52 项 Python 测试。云端 Linux 原生 Chrome 已检查创建/编辑、字面文字、变量与明确空值、复制、版本、回收站、搜索、过时标签页，以及真实 JSON 备份替换和恢复前副本；也检查了 外窗口宽 553 像素的深色浏览器窗口（非测量后的 CSS 视口）。
- 上述窄窗口不是实体手机测试，未完成真实输入法组字或原生故障注入验收。模型化故障测试不能证明浏览器断电、磁盘故障或多步存储的原子性。详细证据与未测范围见[原生验收记录](../prompt-library-native-validation.md)。

## English

This is the local integrated 1.1.23 candidate, not a claim of publication or store approval. At the time of this record, the public latest release remains 1.1.21; the local 1.1.22 workspace commit has not been pushed. This candidate includes that workspace foundation.

- Adds a separate Prompt library tab from the new-tab page: one global local plain-text collection across workspaces, with categories, tags, tool notes, favorites, search and filters. HTML and code remain text.
- Fill `{{variables}}`, review the completed text and click Copy. Repeated variables share one value; missing values block completed-copy, while explicitly empty values are allowed. Literal modes are available. Variable values are ephemeral and are not automatically saved in bodies, history or backups.
- Body edits append versions; metadata edits do not. Restoring a body appends a version while retaining later history and exact version identities. Recoverable Trash preserves records and history. Stale edits are rejected with the draft retained for review, saving as new or explicit discard.
- Complete backup schema 3 includes the global library once, with Trash, body history and recovery snapshots. Restore requires an explicit global-library target and replacement review. Prompt-only restore does not require matching workspace topology. Legacy schema 1/2 archives and deselected prompts leave the existing library unchanged. Conflicting reuse of a body-version ID is rejected.
- Pre-restore recovery copies and verified writes protect replacement flows; uncertain results fence subsequent writes for explicit review. These safeguards do not make multi-step browser storage crash-atomic. An unverified write may already have committed.
- No model execution, page reading, provider connection, API-key fields, new permissions or automatic uploads. Ordinary configuration exports, Chrome Sync and Drive do not include prompts. No workspace membership controls or security isolation are provided.
- Limits: 200 records including Trash, 32,000 Unicode code points per body, 20 body versions, eight recovery snapshots and a 2 MiB library budget; complete archives also have a 32 MiB limit. Limits reject rather than truncate or evict. There is no permanent deletion, Trash purge or automatic history cleanup. Exporting does not free capacity. Drafts and variable values are tab-memory-only; departure warnings are not guaranteed. Local data and JSON backups are unencrypted.
- The integrated candidate passed 1,351 Node and 52 Python tests. Native cloud Linux Chrome checks covered create/edit, literal text, variables/explicit empty values/copy, versions/Trash/search, stale tabs, actual JSON backup replacement and pre-restore recovery copies, plus a dark browser window with a 553-pixel outer width (not a measured CSS viewport). This was not a physical-phone, real-IME or native fault-injection test. See the [native evidence and untested scope](../prompt-library-native-validation.md).
