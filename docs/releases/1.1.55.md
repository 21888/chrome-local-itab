# 1.1.55 · 同一提示词模型对比 / Same-prompt model comparison

## 新增

- 选择一至两个已保存连接，审核每个完整目标地址、模型与相同的已填充提示词；明确最大请求数和可能分别收费。
- 并排显示纯文本结果，每个目标独立停止、失败或显式保存到 AI 收藏，保留原提示词版本引用。

## 修复

- 拒绝重复目标；发送前重新读取连接，来源或连接变化会使旧审核失效。
- 过期授权、迟到结果、工作区替换和关闭不会继续保存；不确定保存重用原回执。

## 注意事项

- 默认不选择目标；授权与发送分开，无自动重试。密钥分开临时保存，不写入预设或收藏。
- 一次对话框最多发起一个批次，重新运行需关闭后重开。停止不保证撤销已经产生的费用。
- 不发送其他提示词、历史或工作区内容。合成测试不代表真实服务商、收费或原生权限验证。

- 完整测试清单以等价分片通过 1,998 项：170 个非规模文件 1,994 项，加独立运行的四个规模用例；171 个文件全部覆盖，无跳过。Python 检查通过 53 项。较早因执行环境停顿而中断的运行不计为通过。
- 云端原生英文浅色发送前验证通过：默认关闭、重复目标拒绝、两目标相同提示词与完整地址/模型、最大两次请求提示、取消第二目标后重新审核最大一次、Escape/焦点/重开重置，以及原单版本历史和无关联结果保持不变。未输入密钥、授权、发送或保存响应。
- 已知界面细节：停用第二目标后标题可能仍保留旧名称，发送按钮仍显示通用“最多两次”；目标选择与审核最大次数正确。真实传输、响应/保存、失败/停止及中文/深色/窄屏不属于本次原生验证范围。
