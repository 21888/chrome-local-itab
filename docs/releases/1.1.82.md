# 1.1.82 · 导航库品牌搜索写法 / Flexible brand search spelling

## 新增

- 为 Google、Bing 分别增加「谷歌」「必应」两项有官方命名依据的搜索别名，仅用于对应条目。

## 修复

- 本地搜索统一 NFKC 和小写，兼容全角英文；品牌名/别名允许省略或插入空格、英文连字符，例如 chat-gpt、git-hub、googlefonts。
- 多词查询仍逐词全部匹配，不压缩描述或拼接跨字段，不引入模糊纠错。

## 注意事项

- 分类、用途、运营地区、组织和价格筛选仍精确匹配；108 个站点、154 个用途标签及显示名称、URL、已保存数据和权限不变。
- 实现候选通过 2335 项 Node、53 项 Python 和 54 项针对性测试；限定中文 Clarity 亮色桌面原生检查通过 chat-gpt、git-hub、googlefonts 和不匹配分类/所在地/定价排除、清除与重新打开重置。git-hub 正常返回 GitHub 与 Copilot 两项。
- 全角输入及「谷歌」「必应」别名未在原生工具中输入，仍仅为确定性合成覆盖；窄屏、暗色和写入路径未在本轮重复验收。

## English

- Adds the officially evidenced Chinese search aliases 谷歌 for Google and 必应 for Bing, scoped only to those entries.
- Local search uses NFKC and lowercase; individual brand names/aliases accept omitted or inserted spaces and ASCII hyphens, including chat-gpt, git-hub and googlefonts.
- Every query term is still required; descriptions/cross-field text are not compacted and no fuzzy typo correction is introduced. Structured filters remain exact.
- Keeps 108 sites, 154 tags, display names, URLs, saved data and permissions. The implementation candidate passed 2335 Node, 53 Python and 54 focused tests. Bounded Chinese Clarity light desktop checks passed the three ASCII spellings, incompatible exact-filter exclusions and clear/reopen resets. git-hub correctly returns both GitHub and Copilot.
- Full-width input and 谷歌/必应 aliases were not entered natively and remain synthetic-only evidence. Narrow, dark and write paths were not rerun in this pass.
