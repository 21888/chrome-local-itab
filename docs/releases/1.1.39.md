# 1.1.39 · 窄屏自由布局与备份验证 / Narrow Free layouts and backup assurance

## 新增

- 七模块完整备份合成测试与可复用校验工具，覆盖工作空间、回收站、提示词历史和精确结果关联。完整恢复与四组选择性恢复的真实浏览器下载文件已通过校验。
- 中、英、西班牙语备份与迁移说明更新到现有模块及恢复范围。

## 修复

- 缩窄自由布局时，原本分离的快捷方式不再被挤到相同位置；放宽后恢复保存的位置，调整显示不会写入坐标。
- 保留有意重叠的组合；过宽组合可横向滚动访问，拖动会考虑显示偏移和滚动位置。
- 旧备份目的工作空间等界面测试等待真实就绪状态，消除固定延时造成的误报。

## 注意事项

- 调整显示与实际拖动不同：只有完成拖动才保存所拖动快捷方式的位置。超大布局可能向下延展，以保证可访问性。
- 恢复前快照包含所有工作空间模块，但全局库只包含本次选择的模块。取消、取消选择全局库和中断后的恢复语义均有自动化验证。
- 1,756 项 Node、53 项 Python 测试通过；自由布局原生验收覆盖 400/1188px CSS 视口、拖动，以及 240px 下过宽组合的横向滚动。[实测范围](../qa/narrow-free-layout/native-acceptance.md)。
- 自动化重建存储测试不代表已完成真实旧版扩展升级或全部平台验收。

## English

### Added
- Reusable synthetic seven-module backup fixtures and a verifier for workspaces, Trash, prompt history and exact result links. Actual browser exports pass full-restore and four selective-restore comparisons.
- Current Chinese, English and Spanish backup/migration guidance.

### Fixes
- Previously separate Free-layout shortcuts no longer collapse onto the same narrow-canvas position. Widening restores saved positions without resize-time coordinate writes.
- Intentional overlap groups retain geometry; oversized groups have horizontal access and scroll-aware dragging.
- Backup view tests wait for actual readiness rather than fixed timing delays.

### Notes
- Only completed dragging saves the moved shortcut. Very large layouts may extend downward to retain accessibility.
- Pre-restore recovery contains all workspace modules but only selected global libraries. Cancellation, deselected globals and interruption recovery have automated coverage.
- 1,756 Node and 53 Python tests pass. Native Free-layout checks cover 400/1188px CSS viewports, dragging and oversized-composition scrolling at 240px. [Bounded acceptance](../qa/narrow-free-layout/native-acceptance.md).
- Reconstructed-store tests do not establish authentic old-extension upgrades or all-platform acceptance.
