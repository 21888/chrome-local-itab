# 1.1.104 · 任务与收藏保存核验 / Task and collection verification

## 新增

- AI 任务批次保存不确定时可显式只读核验：必须有回执，且读取快照中整批任务与原七字段完全一致才解除锁定；不重新添加。
- 收藏页保留原不确定命令并支持只读回执核验，避免后续冲突被误当作此前从未提交；首次明确冲突仍可正常编辑恢复。

## 修复

- 收藏未知写入后的明确拒绝转为核验模式，原操作不丢失、不自动重放。历史核验采用当前有效状态，不回滚后续修改或归档。

## 注意事项

- 任务核验只说明读取时原批次完整未改，不是历史提交证明，也不保证之后状态；收藏回执核验说明历史操作，不保证记录目前存在或未变。
- 两项普通提交精确 CI 通过 2597/81 与 2616/81 项 Node/Python 检查，实际 104 完整回归通过 2616 项 Node 与 81 项 Python；普通重新加载核实实际版本及首页基线，仅身份检查。
- 原生仅中文桌面浅色安全流程：无任务命令的任务模式本地审阅/清空，及无待定保存的收藏编辑/搜索清除/丢弃重开。两种回执与写入故障核心均仅真实 Store 合成验证；无新增任务、保存、provider 调用或权限。未测完整暗色/窄屏/竞争矩阵。
