# 1.1.84 · 导航添加时创建分类 / Create a category while adding sites

## 新增

- 网站库可输入新分类名称，审阅完整网站名单和新分类后明确确认，将新分类与所选网站一起保存；兼容单站与最多 20 站批量选择。
- 支持没有现成个人分类时从此流程创建；成功后更新分类导航，不自动切换当前分类或重新排布布局。

## 修复

- 新名称去首尾空白并按 NFC 校验，限制 1–80 个 Unicode 字符并拒绝控制字符与大小写规范化重名。
- 保留全部验证、网址去重、身份冲突规避和保存读回保护；全为已添加网站时不创建空分类。编辑草稿或目标会作废旧审阅，保存中与输入法合成时不会误确认。

## 注意事项

- 创建分类与新增链接属于一次受保护保存，不是浏览或输入名称就写入；取消不会创建分类。不改权限、默认目录或外部请求。
- 追加分配重试测试后的全部 2378 项 Node 与 53 项 Python 回归通过；限定中文原生检查通过单站/两站批量新分类、取消不建空类、重名拒绝、320px 暗色审阅、现有目标兼容及刷新持久化；保留原类别与当前视图。零类别、IME、竞争和原子故障仍为合成证据，不代表完整原生矩阵。
