# 1.1.85 · 未发送 AI 草稿关闭保护 / Protect unsent AI drafts

## 新增

- AI 上下文面板识别未发送的问题、已选素材、手改摘录与手改回复标题，关闭或离开前提示未保存内容。

## 修复

- 同一草稿判断用于面板关闭与页面离开；取消关闭保留草稿，明确丢弃后重新打开为空。恢复原值或取消/清空可解除相应草稿提示。

## 注意事项

- 草稿仍仅存在于当前会话，不新增持久化、网络调用或权限；浏览器页面离开提示由浏览器决定是否显示。
- 实现全部 2382 项 Node 与 53 项 Python 回归通过；限定中文桌面原生检查通过空白关闭、仅问题/仅标题的关闭确认、取消保留、明确丢弃重开为空与清空解除提示。选材/手改摘录/已审阅状态及页面离开提示未做原生验证；无真实 provider 调用或完整浏览器矩阵。

## English

- Recognizes unsent questions, selected sources, edited excerpts and manually edited answer titles when checking for uncommitted work on panel close or page exit.
- Canceling dismissal retains the draft; explicit discard reopens blank. Restoring original values or Cancel / clear removes the corresponding draft warning.
- Drafts remain session-only, with no added persistence, network calls or permissions. Browser navigation warnings remain subject to browser behavior.
- All 2382 Node and 53 Python implementation checks passed. Bounded Chinese desktop native checks passed blank dismissal, question-only/title-only confirmation, cancel retention, explicit discard with blank reopen and clearing the guard.
