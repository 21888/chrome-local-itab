# 1.1.66 · 取消确认后恢复编辑器焦点 / Restore editor focus after cancellation

## 新增

- 为提示词编辑器确认框的原触发控件保留稳定焦点身份。

## 修复

- 脏草稿确认期间外部刷新重建编辑器后，取消或 Escape 可返回当前有效的关闭编辑器按钮，避免焦点落到页面正文。
- 多次刷新、已变化选择/草稿、关闭生命周期与迟到旧回调不会抢走用户已建立的新有效焦点。

## 注意事项

- 保留未保存草稿，不改变保存、确认、权限或网络行为；隐藏/禁用替代控件不接收恢复焦点。

- 本地独立检查通过 2,121 项，Python 检查通过 53 项。20,000 链接用例未在本地重跑，完整本地验证仍不完整；发布须对应提交的原有完整 CI 通过。
- 真实安装扩展的双标签测试通过：A 标签脏草稿确认期间，B 标签普通收藏/取消收藏写入触发 A 编辑器重建；Escape 与键盘 Enter 取消分别返回当前关闭编辑器按钮的可见焦点，未保存标题/正文仍保留。全部 108 个生产运行文件与测试安装目录匹配，无夹具或状态注入。
- 焦点由可见焦点环和实际键盘操作确认，原生 AX 未提供元素树。仅英文浅色桌面范围；没有接受草稿保存/丢弃，也未新增原始导出/历史审计，不扩称中文/深色/窄屏覆盖。

## English

- Retains a stable identity for the prompt editor control that opens a confirmation dialog.
- After an external refresh rebuilds an editor during dirty-draft confirmation, Cancel or Escape can restore focus to the current valid Close editor button rather than the page body.
- Repeated refreshes, changed selections/drafts, disposal and late callbacks do not steal newly established valid focus. Hidden or disabled replacements are excluded.
- Unsaved drafts remain intact. Save, confirmation, permission and network behavior is unchanged.

- Local checks passed 2,121 unique cases plus 53 Python checks. The 20,000-link case was not rerun locally, leaving local validation incomplete. Publication requires the exact commit’s existing complete CI gate.
- Native testing on the actual installed extension passed two ordinary-tab races: Favorite and Remove favorite writes in tab B rebuilt tab A behind its dirty-draft confirmation. Escape and keyboard Enter-on-Cancel each restored visible focus to the current Close editor button and retained the unsaved title/body. All 108 packaged files matched the installed source; no fixture or state injection was used.
- Focus evidence is visible focus rings and actual keyboard behavior; native AX did not expose an element tree. This gate is English/light desktop only. No draft save/discard was accepted, and no additional raw-export/history audit or Chinese/dark/narrow coverage is claimed.
