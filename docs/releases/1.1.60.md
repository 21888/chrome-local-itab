# 1.1.60 · 单目标显式重试 / Explicit failed-target retry

## 新增

- 模型对比中失败或停止的目标可单独重新审核，使用新临时密钥并明确发送一次额外请求。
- 展示该目标原目的地址、模型、提示词与额外费用提示；成功的另一目标及其保存回执保持不变。

## 修复

- 旧的停止回调或迟到结果不能覆盖重试答案；来源、预设或工作区失效时拒绝重试。
- 正在请求、授权或保存时不允许新重试；授权与发送继续分离，无自动请求。

## 注意事项

- 每次重试都可能另收费，停止不保证撤销先前费用。切换目标或重跑成功结果需新建比较。
- 原模板与未接受建议的试跑不提供重试入口或处理；不会把失败重试扩大为重跑全部模型。
- 合成测试不代表真实服务商、权限与网络状态；原生合成传输验收单独说明。

- 本地独立检查通过 2,048 项，Python 检查通过 53 项。20,000 链接用例未在本地重跑，完整本地验证仍不完整；发布须对应提交的原有完整 CI 通过，未放宽断言或更改工作流。
- 独立浏览器测试页面使用 20 个与生产逐字节匹配的资产、合成权限/响应与内存存储，验证 A 成功、B 失败后单独重新审核并发送 B，保留已保存 A 的答案与回执，再明确保存 B。最终计数为 A 一次、B 两次，共三次请求、两次收藏写入；两个结果具有同一原提示词版本、不同模型与正文。所有临时密钥为空，测试控制不进入生产包。
- 中间计数被弹窗遮挡，最终计数限定没有额外自动或审核请求。Stop/迟到回调仅有单元证据；不宣称真实服务商、Chrome 授权、计费、扩展持久化或完整语言/主题/键盘矩阵已验证。

## English

- Adds an explicit re-review and separate Send for one failed/stopped comparison target, with a fresh temporary key and disclosure of one additional potentially billed request.
- Preserves the successful peer and its save receipt. Retries use the original reviewed endpoint/model/prompt; stale sources, presets or sessions fail closed.
- Pending request/grant/save activity blocks retry, and late stopped callbacks cannot replace newer answers. Permission and Send remain separate; there are no automatic calls.
- Switching targets or rerunning a success requires a new comparison. Original-versus-unsaved-proposal trials exclude retries. Stopping cannot undo costs already incurred.
- Synthetic tests do not establish real-provider/grant/network behavior; native synthetic-transport acceptance is separate.

- Local checks passed 2,048 unique cases plus 53 Python checks. The 20,000-link case was not rerun locally, leaving local validation incomplete. Publication requires the exact commit’s existing complete CI gate; no assertions or workflow were relaxed.
- Native browser interaction on an isolated test page using 20 byte-identical shipped assets, synthetic permissions/responses and in-memory storage verified A success, B failure, explicit B-only review and Send, preservation of A’s saved response/receipt, and explicit B saving. Final counters were A once, B twice, three requests and two collection writes. Both results retain the same original prompt version with distinct models/bodies. All keys were empty; test controls are excluded from the production package.
- The modal obscured intermediate counters; final exact totals bound automatic/review-only requests. Stop/late callbacks remain unit evidence. Real providers, Chrome grants, billing, durable extension storage and full locale/theme/keyboard coverage are not claimed.
