# 1.1.130 · 模板标题搜索与整理列表筛选 / Prompt title search and organizer filtering

## 新增

- 上下文问答的已保存模板选择器支持临时本地标题搜索、匹配数量和无结果提示。按 Unicode NFKC、大小写及空白归一化后的字面子串匹配，不搜索正文、标签或历史版本，不自动选择唯一结果。
- 修改或清空模板搜索会清除旧选择、变量和替换预览，保留问题原文；仍须明确选择、预览和替换。重载保留查询，关闭清空临时查询。原始 CRLF/CR 和 4,000 UTF-16 单位边界保持精确。
- 整理已保存网站支持按标题、完整 URL 或显示的来源分类名称临时筛选。保留原始顺序及重复记录身份，显示匹配、全部选中与隐藏选中数量。
- 跨筛选选择和目标分类保持不变；审阅始终包含全部选中记录，包括当前隐藏项。返回保留查询，清除搜索只改查询；更换目标仍会移除已在目标分类的选择，包括隐藏项。明确确认后才走原有原子移动流程。

## 修复

- 模板搜索或清空按钮因忙碌、答案保存或待办提交而被禁用前，先将焦点移至状态提示，避免原生浏览器焦点掉到页面 body。
- 搜索组字状态在失焦后清理；IME 处理中的 Escape 不误触外层关闭。整理列表搜索框在输入期间保持挂载，旧控件、旧会话及提交期间的事件不能改写当前选择。

- 本批两个功能各自独立提交并通过精确 CI。最终严格串行全测 3368 Node / 84 Python；模板搜索独立 19 项、整理筛选独立 25 项通过。123 个运行文件，无新增权限、依赖或存储 schema。
- 云端 Chrome for Testing 155 使用精确候选完整页面及真实生产脚本链，配合合成内存存储。模板搜索预定义浏览器矩阵 28/28，并在恢复状态不一致后重新可见复跑两次确认；英文/中文 200% 原生键盘流程通过。整理筛选矩阵 30/30，最终无人工干扰复跑仍全部通过，另完成中英文 100%/200% 原生操作。
- 搜索、清空、审阅、返回和取消不写入，筛选不增加存储读取。整理的明确移动及 pending 移动测试各有一次合成内存写入，完整状态核对仅改变被选中的重复条目及孤儿条目的分类。初始化读取、模拟外部冲突和明确确认写入不被称作全程零读写。
- 一次整理矩阵重跑被人工切窗打断导致焦点断言失败，未采用为验收依据；保留的 30/30 JSON 与最终无干扰可见终态分别记录。IME 仅浏览器事件级覆盖，未验证系统输入法候选窗。实际安装 129 未替换；本批未调用真实 provider、系统剪贴板或持久 Chrome 存储，不宣称扩展升级验收。未上传截图或提交 Chrome 商店。

- Changing or clearing the query invalidates the selection, variables and preview while preserving the question. Explicit select, preview and Replace remain required. Reload retains the query; Close resets it. Raw CRLF/CR and exact 4,000-unit limits remain intact.
- Filter organizer records by title, full URL or displayed source category. Preserve original order, duplicate occurrence identity, destination and cross-filter selections. Show all selected and hidden-selected counts; review always includes every selection. Back retains the query, Clear changes only the query, and destination changes remove same-target selections even when hidden.
- Recover focus before disabling prompt search/reset controls under busy/save/task locks. Clear interrupted composition state on blur and retain the organizer input while typing. Detached, previous-session and pending-submit controls cannot redirect current selections.
