# 1.1.138 · 只读检查留存副本与明确冲突状态 / Read-only saved-copy inspection and clear conflict state

## 新增

- 独立「检查留存副本（只读）」页面，可从新标签页、设置页及启动/冲突提示打开；普通工作区启动失败时仍可检查受支持的本机留存副本。
- 分开显示当前工作区、迁移副本、旧配置和恢复链的来源、数量及校验状态。预览和下载需要明确点击，保留可支持的原网址拼写、顺序和布局信息；识别出的凭据字段被省略并说明。

## 修复

- 工作区旧资料冲突时，结束误导性的「正在加载」状态，显示明确的暂不可用/冲突提示，同时保留写入阻断、旧页面失效保护与焦点。

## 注意事项

- 调查 JSON 不是完整备份，不能直接导入恢复；普通备份导入器明确拒绝该类型。本功能不自动恢复、不写入原资料，也不保证找回已经不存在的数据。下载文件仍可能包含私人标题、文本及普通网址参数，分享前请自行检查。
- 两项功能独立提交；storage.js、sync.js 与 shared/workspaces.js 保持 1.1.137 原样。未增加扩展权限；独立只读页采用限制网络和图片的页面 CSP。运行白名单由 123 增至 127 个文件，新增四个只读检查文件，不含测试资料或用户备份。
- 组合源码首轮全套 3709 Node / 84 Python 通过。只读页原生验收覆盖中英文、两个真实合成调查文件下载、启动失败时从真实入口另开页，以及六个脚本场景；四份最终回执验证原始合成数据未变。最初一次渲染器中断未计作通过，同源码重载后完成。
- 冲突界面原生验收四份回执通过，覆盖首次 registry/activation 晚写冲突、已有会话冲突及另一个管理器解决后旧页仍禁写。初始 harness 错误码断言失败已保留；只修正测试预期，生产代码未改。
- 验收使用精确生产文件和合成内存适配，不代表真实安装态升级、真实用户存储恢复或磁盘持久性保证。入口测试保留的是测试输入草稿，不代表所有产品草稿模块均已原生覆盖。
- 本次仅发布 GitHub。Chrome 商店已上传的 1.1.137 因资料校验阻塞，尚未送审；本批不替换该上传包、不提交 1.1.138。

- Add an independent read-only inspection page for supported retained local copies, reachable even from a real workspace-startup failure. Sources, counts and verification results remain distinct. Preview/download require explicit clicks; supported original URL spelling/order and layout details are retained, with identified credential fields omitted and explained.
- Replace misleading Loading labels after legacy-workspace conflict with explicit unavailable/conflict state while retaining write fences, invalidated-page guards and focus behavior.
- Investigation JSON is not a complete or directly importable backup; ordinary importers reject its envelope. No automatic restore or original-data writes occur. Missing data cannot be reconstructed without retained copies. Exports can still contain private text and ordinary URL parameters; review before sharing.
- Two independent functional commits. storage.js, sync.js and shared/workspaces.js remain byte-identical to 1.1.137. No added extension permissions. A restrictive standalone-page CSP blocks network/images. Four inspection assets increase the runtime allowlist from 123 to 127; test data and user backups are excluded.
- Combined first full run: 3709 Node / 84 Python. Read-only native coverage includes EN/ZH, two actual synthetic investigation downloads, the startup-failure entry and six scripted cases; four final receipts confirm unchanged synthetic originals. An initial renderer interruption is retained and excluded, followed by an unchanged-source successful reload.
- Conflict UI: four passing receipts cover registry/activation late writes, a captured-session conflict and continued old-page write refusal after separate-manager resolution. An initial harness error-code assertion failure is retained; only its expectation changed, not production code.
- Exact production assets with synthetic memory adapters are not proof of installed-upgrade behavior, recovery of real user data or disk durability. Entry-flow draft evidence used a QA input rather than every product draft module.
- GitHub-only release. Chrome Web Store 1.1.137 remains uploaded but blocked by metadata validation; this batch neither replaces that upload nor submits 1.1.138.
