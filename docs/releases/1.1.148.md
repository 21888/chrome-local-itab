# Local iTab 1.1.148

## 新增
- 本批包含两项导航库资料展示改进：四条目录费用说明更新，以及来源日期与未知状态的中英文解释。

## 修复
- 更新 Grok、Cursor、Pika 和 Luma 的费用说明、来源及查阅日期；Luma 保持资料未充分确认的“未知”费用分类。
- 来源面板将日期明确标为“来源查阅日期 / Source reviewed”。页脚说明“未知”表示相关资料尚未充分确认，日期不保证当前费用或可用性；所在地指公司或运营方，不代表可访问地区。
- 同步英文后备文案；保留既有目录标识、网站地址、公司信息、数据结构和操作控件。

## 注意事项
- 目录是离线整理的资料，不是实时价格、服务可用性或地区访问保证。方案和账号要求可能变化，请通过来源链接核对当前条件。
- 本批不改变导入、恢复、同步、权限或服务商请求行为。
- 原生检查使用真实导航组件与合成只读快照，核对中英费用卡片、Luma 未知筛选、来源日期和页脚说明；未访问外部来源或重新测试真实付费方案。未进行安装扩展或完整新标签页验收。

## English
- This batch contains two navigation-library improvements: refreshed pricing notes and sources for Grok, Cursor, Pika and Luma, plus clearer metadata-review wording. Luma uses Unknown where pricing information has not been sufficiently confirmed.
- Existing source dates are labeled “Source reviewed.” The bilingual disclosure and English fallback explain that Unknown means insufficiently confirmed information, and that a review date does not guarantee current pricing or availability. Operator location does not describe where a site is accessible.
- Catalog IDs, site URLs, company details, schema and controls remain unchanged. The catalog is an offline editorial reference; plans and account requirements can change. Consult linked sources for current terms.
- Import, recovery, synchronization, permissions and provider-request behavior are unchanged. Native checks used the real navigation component with synthetic read-only snapshots: bilingual pricing cards, Luma Unknown filtering, source dates and disclosure wording. They did not visit external sources, recheck live paid plans, install the extension or cover the complete new-tab page.
