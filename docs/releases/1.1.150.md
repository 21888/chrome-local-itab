# Local iTab 1.1.150

## 新增
- AI 上下文问答支持手动粘贴严格的任务 JSON，显式加载后逐项选择、审阅，再确认添加到现有待办；标记为未核验来源的外部任务，不冒充已连接模型的回答。
- 网站查找器增加显式“全部工作区”范围，只读搜索已登记活跃工作区的已保存网站并显示所属工作区；默认仍为当前工作区，打开网站不会切换工作区。

## 修复
- 跨工作区结果打开前重新核验工作区身份、代际、网址及相关状态。页面离开、关闭或相关条件变化取消未完成核验；仅点击产生且仍归本次操作所有的可见空白页允许在原页被其遮住时完成核验。

## 注意事项
- 手动任务输入不会自动读取剪贴板或请求服务商，也不需要模型连接。仅最终确认经现有幂等任务保存流程写入；临时输入关闭后不保留。JSON 要求唯一 tasks 字段及1–50条非空单行字符串，每条至多1000、整体至多32000个 UTF-16 单位。
- 全部工作区扫描仅由用户选择启动，不迁移、不切区、不写入或联系 Sync/服务商。任一活跃工作区缺失、不可读、格式不支持、冲突、超限或含凭据式网址时，全部范围不可用，不展示不完整结果。
- 读取固定30个控制/旧数据键及已登记的活跃 bundle；存储读取返回完整顶层值，验证期间可能暂时读入 bundle 内笔记、任务或恢复数据及控制快照中的其他字段；只保留网站/分类投影和身份核验信息，不展示、记录或发送这些附带数据。
- 支持至多100个登记项、20000个网站、10000个分类及8 MiB投影；原始读取每次验证通道预算64 MiB，并非峰值内存保证。锁和前后快照核验不是浏览器事务，不保证抵御忽略锁且隐瞒通知的任意写入者。
- 原生组件验收使用合成内存数据：手动任务替换取消零写入，子集重复确认仅一次预期任务写入且保留原任务；最终 Finder 在真实打开的自有空白页遮住原页后，经脚本注入的读取延迟完成核验并到达本机合成目标，零写入。来源页 pagehide 负例由脚本测试覆盖，未原生穷举所有中断；无真实服务商、历史数据恢复或安装扩展验收声明。

## English
- Added explicit local review of manually pasted task JSON: load, select individual tasks, review the exact batch, then confirm through the existing idempotent Tasks save path. Provenance is unverified external text, never a claimed connected-model response. No automatic clipboard reads or provider calls; temporary input is discarded on close.
- Finder now offers an explicit All workspaces scope for saved sites in registered active workspaces, with workspace labels. Current remains the default. Opening a result does not switch workspaces.
- Every All activation revalidates identity, generation, URL and related state. Departure or changed conditions cancel pending checks. A narrowly owned visible blank opened by that activation may take foreground while verification completes; it must remain verifiably the same owned blank.
- All is read-only and all-or-unavailable for missing, unreadable, unsupported, conflicting, oversized or credential-bearing saved URLs. No migration, storage writes, workspace switch or Sync/provider requests. Reads use 30 fixed control/legacy keys and registered live bundles. Full top-level storage reads can temporarily include incidental notes/tasks/recovery or control-snapshot fields; only site/category projections and identity fences are retained, and incidental data is not rendered, logged or transmitted.
- Limits: 100 registry entries, 20,000 sites, 10,000 categories, 8 MiB projected JSON and 64 MiB raw data per validation pass. The raw budget is not a peak-memory guarantee. Cooperating locks and snapshot checks are not browser transactions or protection against arbitrary uncooperative writers after the final snapshot.
- Native component checks used synthetic RAM: manual-task replacement cancellation wrote nothing; repeated subset confirmation made one expected task write and preserved the original task. Final Finder replay used a genuinely opened owned blank that hid the source, injected storage-read delays, and successful navigation to a local synthetic target with no writes. Source pagehide negatives are scripted coverage, not a native exhaustive interruption matrix. No real-provider, historical-data-recovery or installed-extension acceptance claim.
