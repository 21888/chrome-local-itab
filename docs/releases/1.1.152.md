# Local iTab 1.1.152

## 新增
- AI工作台可手动粘贴外部回答，显式加载后只读审阅原文，再明确保存到全局AI收藏；无需连接模型、填写问题或选择摘录，不自动联网或读取剪贴板。
- 保存前明确提示完整回答进入跨工作区全局收藏及未加密本地备份。手动内容标注来源、模型与引用未经核验，不虚构提供商、问题或上下文快照。

## 修复
- 任务JSON编辑超限或无效时保留完整草稿并取消旧审阅，禁用旧确认；修正后必须重新审阅再添加，避免沿用旧任务批次。

## 注意事项
- 外部回答最多32000个UTF-16单位，无静默裁剪或自动任务解析。浏览器可能在粘贴或读取输入值时规范化换行，无法恢复已被浏览器转换的原剪贴板换行。
- 保存针对已加载原文；后来尚未加载的新草稿不会替换它。只读显示中的HTML、图片及链接不执行、跳转或抓取。保存前请检查私人信息，内容中的说法不代表已核实事实。
- 保存复用现有收藏锁、容量、幂等命令与回执核验，不改变存储schema。结果不确定时保持当前会话命令，核验只读；关闭仍沿用原协议，没有持久重试草稿，已提交写入不能通过关闭撤销。放弃不确定会话后，重新保存前请先检查全局收藏。
- 本批保留既有任务与收藏记录。无新权限、真实服务商接入或历史数据恢复承诺。原生组件验收使用合成RAM：旧任务审阅由脚本预置，实际粘贴32472单位保全文本并阻断旧确认，修正后重新审阅仅一次添加；外部回答英文实际粘贴/加载/替换取消/保存仅一次收藏写入，中文仅标签和加载检查。无真实服务商、安装扩展或完整工作区并发验收声明。
