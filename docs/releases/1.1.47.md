# 1.1.47 · 可选模型请求 / Optional model requests

## 新增

- 从提示词库打开可选模型对话框，填写兼容 Chat Completions 的 HTTPS 地址与模型 ID，逐次审核完整请求后手动发送。
- 站点权限与发送分开操作；密钥仅保留在当前对话框内存中，不进入本地收藏或备份。
- 非流式响应可手动保存到 AI 收藏，并关联发起请求的提示词版本。支持取消、超时、错误提示与幂等保存重试。

## 修复

- 提供请求取消、旧响应抑制和不确定保存重试保护。

## 注意事项

- 默认不连接模型。第三方服务可能收费，发送前需自行确认服务条款和价格。
- 仅支持 HTTPS Chat Completions 兼容接口和非流式文本响应；不保证所有提供商兼容。
- 自动测试使用合成响应与模拟权限；未授权真实站点权限、未输入真实密钥、未调用真实提供商。原生权限和实际提供商端到端验证仍未执行。

- 最终完整本地测试通过 1,852 项，Python 检查通过 53 项。
- 云端原生 Chrome 英文浅色模式通过请求审核、Escape/Close 焦点返回、重新打开重置与 320 CSS 像素窄屏检查；界面显示 AI 收藏仍为 0 项。未采集全存储差异或网络轨迹，不据此声称完整无写入/无网络验证。中文、深色、真实授权、提供商与响应保存尚未原生验证。

## English

- Adds an optional model dialog to the prompt library with an explicitly reviewed destination, model and full prompt before sending.
- Origin access and sending are separate steps. Keys remain in dialog memory and are excluded from saved collections and backups.
- Supports bounded non-streaming text responses, cancellation, timeouts, safe errors and explicit idempotent saves linked to the original prompt version.
- Third-party providers may charge. Only HTTPS Chat Completions-compatible endpoints are supported; compatibility is not universal.
- Automated coverage uses synthetic responses and mock permissions. No real permission grant, credential or provider call was used; native permission and live-provider end-to-end checks remain unperformed.

- Final complete local suite: 1,852 tests passed, plus 53 Python checks.
- Bounded cloud Chrome English/light checks passed for exact review, Escape/Close focus restoration, reopen reset and 320 CSS-pixel reflow; AI collection UI remained empty. No whole-storage diff or network trace was collected. Chinese/dark UI, real permissions, providers and response saving remain native-untested.
