# 1.1.63 · 停止等待中的模型操作 / Stop pending model operations

## 新增

- 无新增提供商或权限；本版本完善已有停止操作。

## 修复

- 模型运行与优化在权限预检查尚未返回时也能立即停止并恢复界面，不再因悬挂检查永久忙碌。
- 每个操作具有独立身份；旧检查、迟到响应与清理不能发送请求、覆盖新结果或清空新请求的临时密钥。
- 关闭、页面离开和中断保留相同隔离；忽略取消的底层传输也不能把旧结果带回界面。

## 注意事项

- 停止不保证服务商停止处理或撤销费用；不自动重试，也不自动授予权限。
- 建议编辑、试跑与不确定采纳期间的既有冻结规则保持不变。

- 本地独立检查通过 2,092 项，Python 检查通过 53 项。20,000 链接用例未在本地重跑，本地完整验证仍不完整；发布须对应提交的原有完整 CI 通过。
- 独立浏览器页面以 20 个生产匹配资产和模态内显式合成控制，验证停止悬挂预检查后新请求继续，旧预检查释放不额外发送或解锁新请求；停止旧响应后，迟到旧完成不覆盖/解锁新响应。两场景都仅在明确保存后写入一次；计数和界面成功状态一致，未单独浏览收藏列表。
- 所有密钥为空，传输/权限/存储为合成依赖。真实权限延迟、服务商、持久化、中文/深色/窄屏未验证；新增测试控件影响焦点顺序，不作完整键盘声明。迟到拒绝回调及优化模式保留为自动化测试范围。

## English

- Model runs and refinements can stop immediately while a permission precheck is still pending, restoring the UI without waiting indefinitely.
- Per-operation identity fences prevent old checks, late responses and cleanup from sending requests, replacing newer results or clearing a newer request’s temporary key.
- Closing, leaving the page and interruption retain the same isolation, including transports that ignore cancellation.
- Stop cannot guarantee provider cancellation or reverse charges. It creates no automatic retry or grant, and preserves proposal-edit, trial and uncertain-acceptance locks.

- Local checks passed 2,092 unique cases plus 53 Python checks. The 20,000-link case was not rerun locally, leaving local validation incomplete. Publication requires the exact commit’s existing complete CI gate.
- Native interaction on an isolated page with 20 byte-identical assets and explicit in-modal synthetic controls verified both races: a stopped held precheck cannot dispatch or unlock a newer request when released, and a stopped old response cannot overwrite or unlock the newer response. Each scenario wrote once only after explicit Save, supported by visible success and counted store writes rather than an independent collection listing.
- All keys were empty; transport, permission and storage dependencies were synthetic. Real permission latency, providers, durability and Chinese/dark/narrow coverage remain unverified. Test controls alter tab order, so no full keyboard audit is claimed. Late rejection and refinement mode remain automated-test evidence.
