# 1.1.133 · Claude 实验页来源标签与本地化 / Claude experiment identity labels and localization

## 新增

- 本批修复现有 Claude 用量实验页的显示合同，不增加端点、权限、自动请求、持久存储或账号绑定。

## 修复

- 明确选择组织时先捕获已验证的显示标签，在接受本次快照后显示同一标签。重名、未命名及短ID碰撞沿用既有区分规则，原始组织名称保持不变；错误、关闭、导航或迟到响应不能保留旧快照标签。
- 实验页完整静态标题、按钮、安全说明、文档语言、ARIA及动态状态接入现有中英文消息目录；包括18类错误、五小时/每周窗口、未提供窗口、未知重置时间及未命名组织。目录缺失时提供可读英文回退。
- 澄清仅使用明确选择页面的当前会话认证，不代表账号身份、余额或账单；显示已用百分比，不能把未提供窗口当作零用量。关闭会清除本页结果，但不等于撤销浏览器权限或立即中止已经进入页面的读取，原有十秒上限保持。

## 注意事项

- 两项修复各自独立普通提交并通过精确CI；最终严格串行测试3497 Node / 84 Python通过，运行文件123个。传输函数readInPage、请求及权限边界未变；独审覆盖显示身份与生命周期，第二项另有13组本地化/边界验证。
- 第一项云端Chrome155浏览器合成矩阵64/64，另有8条原生鼠标/键盘路径及9份原始回执核验。该阶段UI仍硬编码中文，EN/ZH仅是合成组织名称样本，不能解释为双语界面验收。
- 第二项精确生产HTML/i18n/controller/renderer配合合成Chrome消息目录与内存API，浏览器矩阵36/36及7条独立原生路径通过；8份回执独审通过，覆盖真实呈现的英中UI、英文fallback、18类错误、null与零、组织原文、关闭及迟到结果丢弃。构建用Node DOM smoke另行记录，不充作浏览器结果。
- permissions/tab/scripting调用为合成内存函数，有按路径核对的预期调用次数，不是零API调用，也不是真实授权。适配器核对readInPage函数身份但不执行其中fetch；没有验证真实Claude端点、响应解析、登录身份、余额、账单、系统权限弹窗或安装态Chrome目录选择。
- 所有测试组织、标识符及用量均为合成数据；页面网络、实际权限、应用存储、provider及剪贴板计数为零，诊断和CSP违规为空。普通本地资源读取、QA JSON下载和文件管理器复制另计，不宣称抓包覆盖其他进程。
- 实际安装132及其业务数据未改动。README截图维护仍为独立任务，本批不包含任何截图或相关九个文档文件；未上传截图或提交Chrome商店。

- Explain selected-page session authentication and used-percent-only semantics without claiming account identity, balances or billing. Unavailable windows are not zero usage. Closing clears local results, not browser grants or necessarily an already-started page read; the existing ten-second bound remains.
