# 1.1.134 · 旧网站数据兼容与比较返回修复 / Legacy site compatibility and comparison return fixes

## 新增

- 本批修复两条既有流程，无新增权限、依赖或存储格式。

## 修复

- 导航库读取合法旧网站记录时，允许原有缺省的图标或分类字段。仅以既有默认显示投影验证，不偷偷重写原始记录；新鲜度比较仍使用精确原始数据，删除/恢复路径保持严格验证。
- 明确添加网站后，首页采用正常显示投影接收保存结果，避免自己的存储通知将合法旧字段差异误判成外部变化并锁住布局。真正外部变化和损坏数据继续受保护。
- 关闭收藏比较后立即按现有规则刷新操作状态。切换标签页再返回并关闭比较时，有效来源可继续上下文问答；归档、读取失败、编辑或其他不满足条件的来源不能因关闭比较而绕过防护。
