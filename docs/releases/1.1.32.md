# 1.1.32 · 按提示词版本查看结果 / Saved results by prompt version

## 新增

- 提示词详情增加「此版本已保存的结果」，仅显示同时精确关联提示词 ID 和不可变正文版本 ID、且未归档的 AI 收藏。卡片仅含结果标题和工具说明，在新标签页打开。
- 预览结果区跟随当前预览实际使用的版本；保存新正文后仍保留变量会话时，继续显示旧版本结果。正文历史中的结果区独立跟随所选版本，不改变预览或变量。
- 英文与简体中文界面说明；其他语言沿用现有英文回退。

## 修复

- 读取中、读取失败与确实没有结果分别展示；刷新立即撤下旧卡片，过期响应和旧卡片点击不可重新展示或打开已失效的上下文。
- 提示词读取失败后，切换记录不会解除结果读取保护，必须成功重读才能恢复；启动期间先注册离页清理，即使读取一直未返回也可清理。单个退订异常不会阻止另一数据源清理。
- 收藏刷新只重绘结果区，保留编辑草稿、变量输入焦点和所选历史版本。

## 注意事项

- 只读集成使用现有安全后端，没有新增权限、存储结构、模型调用、自动复制或网络请求。不按标题猜测关联、不自动关联最新版本、不显示已归档或仅存于恢复快照中的收藏。
- 完整自动化回归通过 1,653 项 Node 与 53 项 Python 测试，无跳过或取消。
- 本次新增合成纯函数与 UI 模型回归，覆盖精确关联、旧变量会话、历史选择、读取失败/乱序、归档/解除关联、过期导航、离页清理及异常退订。
- 恢复后的原生 Chrome 已验证精确收藏新标签导航、旧版本变量预览保留、切换版本范围、归档/恢复实时更新、深色主题和键盘 Tab/Enter。原生读取失败未注入，相关失败保护仅由自动化模型覆盖。
- 已包含不含个人资料或凭据的合成测试数据。详细范围见 docs/prompt-linked-results.md。

## English

### Added

- Prompt details show active saved AI collection results explicitly linked to both the exact prompt ID and immutable body-version ID. Cards contain only a title and tool label and open the exact result in a new tab.
- The preview section follows the version actually used by its variable session, including an older retained body after a newer save. The history section independently follows its selected version without changing the usable preview or variables.
- English and Simplified Chinese labels, with existing English fallback for other locales.

### Fixes

- Loading, read failure and confirmed empty results remain distinct. Refresh immediately invalidates old cards; superseded responses and stale card activations cannot revive an outdated context.
- A failed prompt read stays fenced across record navigation until a successful re-read. Page-departure cleanup is registered before startup reads finish, and one failed unsubscribe cannot prevent cleanup of the other source.
- Collection refresh repaints only result sections, preserving prompt drafts, variable-input focus and the selected history version.

### Notes

- Read-only integration uses the existing fenced backend. No new permissions, schemas, model calls, automatic clipboard activity or network requests. No title-based matching, latest-version fallback, archived results or recovery-only collection records.
- Full automated regression passed 1,653 Node and 53 Python tests, with none skipped or cancelled.
- Synthetic pure/UI-model regression covers exact links, retained sessions, history selection, failed and out-of-order reads, archive/unlink changes, stale navigation, page departure and throwing cleanup.
- Recovered native Chrome verified exact collection new-tab navigation, retained old-version variable previews, version-scope changes, live archive/restore updates, dark theme and Tab/Enter navigation. Native read-error injection was not performed; failure guards are covered by automated models only.
- A synthetic fixture contains no personal data or credentials. See docs/prompt-linked-results.md for scope and usage.
