# 1.1.122 · 收藏导入与渐进回答 / Collection import and progressive answers

## 新增

- 收藏页新增独立 JSON 导入/恢复入口，严格审阅本产品收藏导出文件后明确替换全局收藏，旧库保留恢复快照；取消不写入。不是合并，也不接收完整备份文件。
- 资料问答 Answer 可选择渐进显示，默认关闭，复用既有客户端解析器。更改选项使旧审阅失效，Tasks 保持非渐进；未完成片段不能作为完成答案保存或复制。

## 修复

- 导入审阅、文件读取、恢复选择及不确定结果核验沿用既有事务和会话防护；明确区分未确认结果与已验证替换。

## 注意事项

- 导入会替换本机全局收藏，包括归档内容，须先读审阅说明。原生用同内容合成四记录验证取消零写、明确替换、恢复前快照与恢复成功；内容/历史/顺序还原，记录 revision各+2、version变化，恢复快照2→3且旧两份保留。这些合法元数据变化不等于零写恢复。
- Answer原生只验证无账号本地审阅、选项切换与Tasks重置、100%/200%布局、草稿取消/丢弃。未Send、授予权限或调用模型；真实渐进响应、提供方兼容和中止竞态仍属合成测试/审阅范围。
- 导入并发、未知结果、解析拒绝、复杂归档/关联内容等未重复原生矩阵；没有永久删除或上传备份。
- 两普通CI通过2950/84与2976/84 Node/Python，118运行文件，无新增权限。实际122全套2976 Node/84 Python通过，最小原生身份确认122及原首页基线。
