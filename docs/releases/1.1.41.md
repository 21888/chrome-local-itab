# 1.1.41 · 空白布局添加入口 / Empty manual-layout Add control

## 新增

- 增加空白首页、空分类、不同模板和窗口变化的布局回归验证。

## 修复

- 自由及手动吸附布局中，「添加快捷方式」现在位于完整空白状态说明与操作按钮下方，避免两者重叠。
- 隐藏的旧空白提示不会继续占位；筛选切换后按照当前可见内容重新放置。

## 注意事项

- 只修正显示位置，不改写已有快捷方式坐标或保存数据。
- 1,757 项 Node、53 项 Python 测试通过；原生验收覆盖空首页/分类、两种手动模式、添加入口、明暗模板与 320px 重排。[验收范围](../qa/empty-manual-layout/REPORT.md)。
