# Local iTab 1.1.156

## 新增
- 工作台与导航：澄明模板改用局部作用域的组件样式；分类可用方向键导航，纯语录视图提供可见返回入口。工作区可按名称搜索、相邻排序，并在新标签页打开选定空间；网站整理可选择当前筛选结果。
- 待办：从已有文本建立独立新任务、移到列表首尾、复制单条或当前可见列表；批量完成、重新打开及恢复已移除任务均先审阅目标，再通过原有事务与冲突校验提交。支持查看本地恢复副本的原文。
- 便笺：在当前草稿中查找、显示当前/总匹配数、从选区发起查找、显示逻辑行数，并明确复制全文、选区或保存冲突版本而不替换草稿。
- 本地计算器：明确复制当前结果、用结果继续、查看最多五条本页计算、编辑原表达式、复制计算记录及移除单条记录；支持常见排版乘除和减号。继续或编辑只更新草稿，仍需明确提交才能计算。
- 日历、倒计时与时钟：跳到指定年月、计算/交换/清空日期区间及复制结果；倒计时可预览草稿日期、按距今天的前后天数填入日期、复制已保存标题和日期；世界时钟支持完整日期、本地时刻对照、前后 24 小时步进及复制对照。专注卡显示区间进度和确认后的本地预计结束时间。
- 备份与导入：书签导入前可筛选审阅、导出前可选择分类；完整备份可批量选择模块、审阅导出摘要和工作区影响，并显示准确 JSON 字节的 SHA-256，复制校验值仍需明确点击。
- AI 本地资料：可选择搜索已载入的摘录、快捷聚焦或清空来源筛选；从已保存摘录/提示词版本建立独立草稿、比较两个保存版本、导出审阅后的筛选结果、定位首个未填变量。打开模型连接或发送请求仍是独立的明确操作。

## 修复
- 兼容布局写入增加权威回读，未知格式、非规范已保存数值及无法确认的写入不会被当作已保存成功；不自动回滚或重复可能已提交的操作，保留原数据与恢复副本。
- 中断恢复候选必须匹配该事务记录的校验值，不能把无关但自身有效的副本标成操作前数据。部分结构错误下提供仅下载保留副本的受限入口；普通设置保持锁定，不自动恢复或写入。
- 明确区分中断恢复诊断包与可导入完整备份，展示恢复说明、可取消状态和启动失败提示；修复恢复早退时静态设置界面的本地化。下载请求不再被描述为已完成保存。
- Tasks、Scratchpad 及相关界面在异步读取、保存、重试、换工作区、重挂载和页面离开时保留原来源/目标所有权，避免过期回调替换较新的草稿或反馈。强化批量目标、收据、版本和完整状态回读校验。
- 修复待保存布局数字、快捷方式与设置编辑的草稿/离开保护、工作区目的地捕获、图片解码后保存、备份跨工作区图片计数，以及多个键盘焦点、标签关联和中英文本问题。模板图库尊重已处理的 Escape 和输入法合成事件。

- 数据保留是发布门禁，但不能承诺所有设备、磁盘故障或未验证环境下绝不丢失。历史升级事故的实际原因及用户资料恢复未获证明；本版不宣称修复或恢复那次事故，也不解除商店更新的独立待核验条件。
- 自动验证覆盖真实生产方法中的合成故障、迁移中断/重复启动、旧写入冲突、回读失败、恢复副本和事务来源保护。原生检查使用合成内存适配器，覆盖已记录的工作台、恢复界面、模板及计算器路径，不等于安装扩展升级、Chrome 磁盘持久化、崩溃/配额或全部输入法/辅助技术验收。
- 21 模板 × 两个视口的 42 个预览状态保留快捷方式与本地卡片，取消未增加存储写入；37 次明确记录的取消焦点均返回图库，其余五次只有正常取消观察。仅英文浅色及视口抽样，不宣称全部背景、深色或完整页面逐像素覆盖。计算器原生检查覆盖英文宽视口和中文 390px 框内的继续、编辑及移除；浮点结果保留 JavaScript 数值行为，不是十进制精确运算保证。
- SHA-256 仅用于比较文件字节，不是签名、下载成功证明或恢复保证。诊断包的 current 可能含部分写入后的混合状态，下载不会自动合并或修复。升级前请保存未提交草稿并导出所需备份；手动安装保留原加载目录，不要通过卸载、清空存储或新目录替换来排障。
