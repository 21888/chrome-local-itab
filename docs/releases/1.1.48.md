# 1.1.48 · 更多首页布局 / More dashboard compositions

## 新增

- 模板总数增至 21：新增速览、今日、书签、停靠、拼贴与便笺六种不同结构。
- 首页与设置提供可展开的布局示意图库，保留原生下拉选择。Escape 收起图库并恢复焦点。

## 修复

- 新增组合针对窄屏收敛列数；停靠导航保持正常文档流，避免遮盖内容。
- 布局继续使用真实分类，保留站点、待办、组件开关与自由布局坐标。

## 注意事项

- 图库是结构示意，不是用户截图。选择模板仍会立即保存外观设置。
- 此版本不添加权限、网络请求或示例用户数据。原生浏览器绘制与完整发布验收单独执行。

- 完整本地测试通过 1,855 项，Python 检查通过 53 项。云端原生 Chrome 英文浅色模式验证图库取消/焦点、停靠/书签/便笺三种结构与 320 CSS 像素窄屏。取消后的实际设置导出与基线一致；重载后导出仅模板字段变化，五个合成链接、标识与自由布局坐标保持一致。
- 未覆盖原生中文/深色、全部 21 种模板矩阵、已启用工具卡片、链接打开或并发保存失败；仅实际操作首页图库。
