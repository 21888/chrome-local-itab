# 1.1.33 · 将已保存摘录填入提示词变量 / Saved excerpts into prompt variables

## 新增

- 在提示词变量旁选择已保存的 AI 摘录，审阅正文和目标变量后，仅填入选定的一个变量。
- 保留当前预览使用的精确正文版本，正文中的 HTML 和模板符号保持字面文本。
- 提供英文与简体中文界面和使用说明。

## 修复

- 应用期间锁定选择；收藏变化、归档、读取失败、变量编辑、切换提示词或关闭对话框会使旧选择失效。
- 异步失效或应用期间，将位于即将禁用控件上的焦点安全移到取消按钮，保留键盘取消能力。

## 注意事项

- 仅使用所选收藏正文，不复制注释、来源网址、版本关联或历史；不写入存储、不联网、不调用模型、不自动复制。
- 最终整合源码通过 1,669 项 Node 与 53 项 Python 回归。原生 Chrome 验证选择审阅、单变量填入、Esc 取消及返回焦点、跨标签归档使旧选择失效、恢复与深色主题；范围见 docs/qa/prompt-excerpt-variables/native-acceptance.md。
- 取消或 Esc 不覆盖原变量；变量内容不会加入导出和备份。

## English

### Added

- Review a saved AI excerpt and insert its body into one explicitly selected prompt variable.
- Preserve the exact body version used by the current preview and treat embedded HTML and template syntax literally.
- English and Simplified Chinese interface and usage guidance.

### Fixes

- Lock choices during apply and invalidate outdated selections on edits, archive, read failure, navigation or dismissal.
- Keep keyboard cancellation available by moving focus from a control being disabled to Cancel.

### Notes

- Body-only, in-memory insertion. No notes, source URLs, links or history are copied; no persistent writes, networking, model calls or automatic clipboard activity.
- Final integrated source passed 1,669 Node and 53 Python tests. Native Chrome verified selection/review, one-variable apply, Escape/focus return, cross-tab archive invalidation, restoration and dark theme. See docs/qa/prompt-excerpt-variables/native-acceptance.md for scope.
- Cancel/Escape preserve existing variable values. Temporary values remain outside exports and backups.
