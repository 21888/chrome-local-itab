# 1.1.57 · 可选问答来源快照 / Optional Q&A source snapshots

## 新增

- 保存问答回答时，可选择同时保存精确问题、已审核摘录、完整请求、接口与模型；默认关闭，并显示完整待保存内容。
- 收藏详情以纯文本显示历史快照及其对应的初始回答版本，不自动解析来源或重发请求。

## 修复

- 快照固定关联初始回答版本；修改回答或来源不会重写历史，恢复不能替换或重新绑定已有快照。
- 严格验证字段、精确请求对应关系与容量，超限拒绝整个写入；不确定保存保留原操作与范围。

## 注意事项

- 快照可能包含用户输入的私密内容，显式保存前必须检查。密钥字段和认证头不复制，文本内自行填写的秘密无法自动识别。
- 快照进入未加密收藏与完整备份；省略来源网址并不删除快照内的文字或接口地址。独立 Markdown 导出不包含快照。
- 无快照旧记录保持原格式。旧版本会拒绝带新字段的记录，恢复这类备份前须更新扩展。
- 导入的快照不构成模型生成证明，回答引用仍未验证。合成测试不代表真实提供商或完整原生保存验收。

- 本地独立检查通过 2,021 项，Python 检查通过 53 项；未重复执行前序版本资源超时的 20,000 链接用例，不能称完整本地通过。十个规模依赖文件与已验证 1.1.55 一致，发布仍须对应提交的原有完整 CI 通过。
- 独立原生浏览器测试页面使用与生产一致的视图/控制器及合成传输、模拟权限、内存存储，验证默认不留快照、显式保存精确快照、回答修订后初始版本绑定不变、导出隐私提示/取消；另验证两项任务经审核确认后加入，未执行任务。19 个运行资产逐字节匹配，测试页面不进入生产 ZIP。
- 这不验证真实提供商、权限、扩展持久化或完整备份往返。已知问题：发送前填写的回答标题可能在响应到达时被问题替换；响应后修改标题可用，快照内容与版本关联不受影响。

## English

- Adds an OFF-by-default option to save the exact question, reviewed excerpts, complete prompt, endpoint and model with an answer, after showing the complete retained payload.
- Displays the immutable historical snapshot with its original answer body version, without resolving sources or making another request.
- Strict shape, request-binding and capacity checks reject unsafe or oversized whole writes. Existing snapshots cannot be replaced/rebound on restore; uncertain saves preserve operation identity and scope.
- Snapshots may contain private input and join unencrypted collection/complete backups. Omitting source URLs does not redact snapshot text/endpoints. API-key fields/authentication headers are excluded; secrets manually entered into source text cannot be inferred away. Standalone Markdown excludes snapshots.
- Legacy snapshot-free records keep their shape. Older releases reject the optional field, so update before restoring these backups. Imported snapshots are not proof of model output; citations remain unverified. Native/live-provider acceptance is separate.

- Local checks passed 2,021 unique cases plus 53 Python checks. The predecessor’s resource-timed-out 20,000-link case was not retried, so local validation is incomplete; ten scale dependencies match verified 1.1.55. Publication still requires the exact commit’s unchanged complete CI gate.
- Native interaction on an isolated test page with byte-identical shipped views/controllers and synthetic transport/permissions/in-memory stores verified default-off answer-only saving, exact opt-in snapshots, immutable first-version binding after answer revision, and export warning/Cancel. Separately, two reviewed tasks were explicitly added, not executed. All 19 copied assets matched; fixture assets are excluded from production.
- This does not establish live-provider/grant behavior, durable extension storage or complete backup roundtrip. Known nonblocking issue: a title entered before Send can be replaced by the question when the reply arrives; editing the title afterward works, and snapshot content/version binding remain correct.
