# 1.1.129 · 收藏来源交接与草稿保护 / Collection source handoff and draft protection

## 新增

- 当前收藏详情可在同页继续上下文问答，只交接条目ID、记录版本和正文版本。独立读取当前已保存正文并展示精确来源供审阅，不自动选择。明确“使用”才选入；最终再次读取验证来源身份，变更、归档或读取失败则拒绝。
- 保留原文CRLF/CR、编辑摘录与恢复原文边界，显示归一化不替换发送原文。隐藏历史快照/注释不自动充当当前来源。复制完整请求、发送模型和保存答案/待办仍各自需要原有明确操作。
- 收藏页采用只读工作区接入：缺少初始化状态、恢复挂起或旧数据冲突时给出正常新标签页处理指引，不偷偷初始化、迁移或写冲突标记。普通工作区初始化和持久冲突检测保持原有行为。

## 修复

- 首次工作区接入尚未完成时，隐藏页面或pagehide立即使整个host预检失效；返回前台后迟到结果不能新建弹窗或交接票据，需重新明确进入。
- 每次重复接入重新核验只读工作区状态及固定身份，避免缓存ready吞掉现有草稿后才发现恢复、漂移或会话失效。等待期间再次核验恢复/注册表/legacy状态，失效generation不可因存储恢复而复活。
- 替换草稿确认快照加入待办勾选集合和待办审阅身份，防止等待期间的新选择或新审阅被旧确认丢弃。问题、来源编辑和其他新工作仍受原有快照保护。
