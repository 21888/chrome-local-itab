# 1.1.53 · 精确背景颜色输入 / Precise background color entry

## 新增

- 两个背景颜色选择器旁增加带标签的 #RRGGBB 文本框，可键入或粘贴精确颜色。
- 选择器与文本输入双向同步，提供中英文格式错误说明。

## 修复

- 不完整或非法颜色不会预览或保存；修改其他字段也不会悄悄覆盖错误输入。
- 保存中、取消与重置保持现有预览和写入保护。

## 注意事项

- 只接受六位十六进制颜色，不执行 CSS 字符串。没有新增权限或数据字段。
- 原生输入与粘贴验收单独执行；此改动不声称修复所有系统颜色选择器。

- 最终完整本地测试通过 1,971 项，Python 检查通过 53 项。云端原生英文浅色模式通过精确颜色键入/粘贴、非法文本不改变预览且持续禁用保存、渐变保存后重载值一致、取消/重置/Escape 焦点，以及非法第二颜色切换纯色后解除非活动错误。
- 未验证原生系统选择器反向同步、中文、深色模式、窄屏、存储字节差异或并发竞态。

## English

- Adds labeled #RRGGBB text entry beside both native color pickers, with bidirectional synchronization and English/Chinese validation feedback.
- Incomplete or invalid text neither previews nor saves, and survives unrelated edits until corrected. Pending-save, Cancel and Reset safeguards remain intact.
- Accepts only six-digit hex colors, without arbitrary CSS, new permissions or storage fields. Native typing/paste acceptance is separate; this does not claim to repair every OS color picker.

- Final full local suite: 1,971 tests passed, plus 53 Python checks. Native English/light core passed for typed/pasted hex, invalid text preserving preview and blocking Save, exact gradient values after Save/reload, Cancel/Reset/Escape focus, and invalid second-color recovery on switching to solid.
- Native OS-picker reverse synchronization, Chinese, dark mode, narrow screens, byte-level storage differences and races remain untested.
