# 1.1.73 · 本地话题窄屏布局 / Narrow local-topic layout

## 新增

- 无新增产品功能；增加本地话题布局的静态回归覆盖。

## 修复

- 设置 → 内容中的本地话题网格可随窄容器收缩，宽容器仍保留 220px 的首选列宽下限。
- 长话题标题保留完整文本并换行，编辑/删除操作组及按钮标签可换行，减少窄屏横向溢出的固有约束。

## 注意事项

- 仅调整本地话题局部 CSS；事件处理、数据保存、迁移与权限不变。静态测试不等同于实际渲染或交互验收。
- 已完成限定原生验收：英文 Clarity 下 Baidu 长连续 ASCII/URL 形标题的亮色 320/375/640/768/960px 与桌面、暗色 320px/桌面；另验证三类分组切换、320px 下 Weibo/Zhihu 短合成标题的键盘新增、编辑与删除确认/取消，以及保存后重载持久化。未覆盖中文界面、CJK 标题及暗色其余宽度，不代表完整交叉矩阵通过。
- 已知遗留限制：Clarity 亮色的 Delete 控件对比度偏低；本版只改换行和尺寸，未改颜色，该问题另行修复。

## English

- No new product feature; adds static regressions for the local-topic layout.
- Lets the local-topic grid shrink with narrow containers while retaining its preferred 220px floor when space permits. Full literal titles, action groups and button labels can wrap.
- Scoped CSS only: event handling, saved data, migration and permissions are unchanged. Static contracts do not establish rendered-layout or interaction acceptance.
- Bounded native acceptance covered English Clarity Baidu long ASCII/URL-like titles in light appearance at 320/375/640/768/960px and desktop, and dark at 320px/desktop. Separate 320px checks covered group switching, short synthetic Weibo/Zhihu keyboard additions, edit/delete confirmation and cancellation, and save/reload persistence. Chinese UI, CJK titles and other dark widths were not covered; this is not a full cross-product matrix.
- Known pre-existing limitation: Delete has low contrast in Clarity light appearance. This release changes wrapping and sizing, not colors; a separate fix is still needed.
