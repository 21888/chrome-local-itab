# 1.1.137 · 紧急阻止未确认的同步覆盖 / Emergency protection against unreviewed Sync replacement

## 新增

- 无。本次是单项紧急数据保护修复，不等待常规功能批次。

## 修复

- 暂停本机与 Chrome Sync 之间未经明确确认的整份不同配置覆盖，防止启动、后台同步或后续保存用空白、旧版或不同副本替换已有网站、壁纸和设置。内容相同时仅记录同步确认，不重写整份配置。
- 本机未开启同步时，不再因云端标记为开启而自动加入同步。
- 用户明确确认替换时，先单独写入并读回核验恢复副本，再提交替换并读回检查；本机副本保留原始配置与缺省字段语义，并保留此前恢复记录。清理相关路径增加并发保护。

## 注意事项

- 已复现一条 1.1.6 → 1.1.71 升级路径上的未确认云同步覆盖风险；本修复优先阻止进一步覆盖，不保证所有反馈具有相同原因。
- 已丢失的最新内容能否恢复取决于设备上仍留存的副本；本版不自动回退恢复，也不保证恢复已不存在的数据。请勿卸载扩展、清空存储或导入覆盖资料来尝试修复。
- 自动整份同步暂时受限。请先检查设置中的云端预览及本机资料，确认要保留的内容后再明确选择带恢复副本的替换；不要把「同步开启」等同于允许任意副本覆盖。
- 最终功能源码串行全测 3636 Node / 84 Python 通过，321 个 JS 与 111 个 JSON 检查通过；另有独立审查与并发、失败注入覆盖。原生验收覆盖 3 个实际页面、4 份回执，最终 14/14 脚本场景通过，实际下载的合成恢复 JSON 另行独立核验。本机关闭同步不读取云副本；差异副本阻断、预览取消、明确确认前先备份读回，以及空设备上传阻断均有覆盖。首轮英文同值控制因分类语种差异为 13/14；中文原样匹配为 14/14，运行代码未改。最后的页面重载被工具拦截，未验证重载效果。
- 没有新增权限、外部服务或 CSP 修改。本次保护不能保证硬盘故障、浏览器存储损坏或未覆盖环境中的绝对持久性，也不能用合成验证代替用户实际资料核验。
- 本说明记录 GitHub 发布；Chrome 商店上传、送审和正式上线将分别核实，不把上传成功当成商店已更新。

## English

- Emergency single-fix release: pause automatic replacement of differing complete configurations in both directions between this device and Chrome Sync. Equal data is acknowledged without rewriting the configuration. A cloud-enabled flag no longer opts in a locally disabled device.
- Explicit replacement first writes and verifies a recovery copy, then writes and checks the replacement. Device-only recovery retains original configuration/absence semantics and prior recovery history; related clearing paths gain concurrent-change protection.
- An unreviewed cloud-copy overwrite risk was reproduced along the 1.1.6 → 1.1.71 upgrade path. This release prioritizes preventing further overwrite; it does not establish one cause for every report.
- Recovery of already missing recent content depends on copies that still exist. There is no automatic rollback and no promise to recover nonexistent data. Do not uninstall, reset storage or import over existing data as a repair step.
- Automatic full-copy synchronization is temporarily restricted. Inspect local data and the cloud preview before explicitly choosing a backed-up replacement.
- Final functional source passed 3636 Node / 84 Python tests, 321 JS and 111 JSON checks, with separate independent review and fault/concurrency coverage. Native acceptance covers three actual pages and four receipts; the final scripted matrix passed 14/14 and a downloaded synthetic recovery JSON was independently verified. Cases cover locally disabled Sync without cloud reads, blocked differences, preview cancellation, verified backup before explicit replacement, and blocked empty-device upload preserving exact remote bytes. An initial EN equality control was 13/14 due to different category-language values; the unchanged ZH fixture matched at 14/14 without runtime changes. The final page reload was blocked by the tool and its effect remains unverified.
- No added permissions, external services or CSP changes. Synthetic checks do not establish the safety of a user's actual data or absolute disk/browser durability. GitHub publication, Chrome Web Store upload, review submission and public availability are distinct outcomes.
