# 1.1.44 · 倒计时文本导入草稿 / Reviewed Countdown text import

## 新增

- 倒计时可读取完整的 UTF-8 TXT 导出，在预览后明确将标题和日期载入草稿。
- 导入保留中文、表情及多行恢复标题，支持 BOM 和 CRLF 文本。

## 修复

- 文件大小、编码、真实日期与格式在应用前验证；取消、读取失败及过期预览不改写草稿。
- 较新的编辑、输入法组合、并发状态更新及离开页面会阻止旧文件覆盖当前状态。

## 注意事项

- 应用只修改草稿中的标题和日期，不改变显示开关，也不自动保存。
- 保存仍需原有的单行、最多 80 字符标题；多行或过长的恢复标题需先编辑，不完整的恢复导出不能导入。
- 原生浏览器验收与自动化覆盖分别记录。

## English

- Import complete UTF-8 Countdown TXT exports through a literal preview, then explicitly apply the title and date to the draft.
- Encoding, bounds, calendar dates and stale-state checks protect existing work. Cancel does not write.
- Applying never saves or changes visibility. Existing single-line, 80-character saved-title rules still apply; multiline recovery titles require editing before Save.
- Native acceptance is recorded separately from deterministic tests.
