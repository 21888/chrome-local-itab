# 1.1.86 · 审阅名单逐项移除 / Remove sites from a reviewed selection

## 新增

- 网站库批量审阅名单支持逐项移出所选，包括被当前筛选隐藏的网站；每次移除后展示更新后的完整名单与确认。

## 修复

- 移除保留搜索筛选、目标分类和新分类草稿，旧确认控件失效；焦点移至相邻移除按钮，移除最后一项后回到搜索。
- 保存中禁用移除，移除按钮抑制重复 Enter/空格按键；移除释放选择名额，不改变最多 20 项上限。

## 注意事项

- 移除本身不保存，只有明确确认新的剩余名单后才保存；不改变单站添加、存储协议、权限或网络行为。
- 全部 2389 项 Node 与 53 项 Python 测试通过，包含真实 view→storage 合成集成；限定中文原生检查通过隐藏选择审阅、Enter/空格单次移除及相邻/末项焦点、目标和草稿保留、320px 亮暗名单换行与取消零写。最终保存、长按重复、20 项恢复、挂起写入及屏幕阅读器未原生验证。

- Removal alone writes nothing; only explicit confirmation saves the remaining selection. Single-site behavior, storage protocol, permissions and network behavior are unchanged.
