# 本地月历

点击时钟日期下方的「日历」，查看设备当前月份。「上个月」「下个月」每次切换一个月；「今天」返回设备当前日期所在月份。当天日期以加粗和轮廓标示。月历格子仅供查看，不提供事件、提醒或格子日期选择。

- 查看指定月份时，输入「年份」、选择「月份」，再点击「查看」或在年份框按 Enter。仅编辑字段不会自动翻页。年份须为 1–4 位 ASCII 数字（0–9），范围 1–9999；允许 `0001`、`0099` 这样的前导零。空值、零、负数、小数、指数和混合文字会被拒绝，并显示本地化错误提示，不会截断或删除草稿。
- 初始状态为收起。关闭后再次打开，会回到当前月份并重新填入年份和月份。关闭月历或隐藏时钟／整个面板，会清除临时草稿和错误。
- 保持打开时，跨越午夜、修改时钟设置、切换语言或回到标签页，都不会改变正在浏览的月份和年份／月份草稿。当天标记会随设备本地日期更新。「上个月」「下个月」「今天」会将草稿同步到新浏览月份，并清除错误。
- 用 Tab 移到「日历」，通过浏览器原生的 Enter / 空格操作展开；继续用 Tab 访问导航按钮、年份框、月份下拉框和「查看」。跳转成功后保留操作控件的焦点，并播报所查看的月份。在年份框或按钮上按 Escape 会收起，并将焦点返回仍可见的「日历」；月份下拉框保留包括 Escape 在内的原生键盘操作。输入法组字期间按 Enter 不会提交；一次新的 Enter 按下可提交，按住后的续发不会重复提交。隐藏时钟或整个面板也会收起月历，但不会将焦点移到隐藏元素。
- 日期名称跟随时钟的界面日期语言。始终采用公历，支持 1–9999 年；每周起始日优先使用浏览器提供的语言地区信息。旧浏览器没有此信息时，英语回退为周日，简体中文及其他或未知语言回退为周一。
- 月历属于现有时钟，共用计时器，不保存数据，不增加权限，不联网，也没有独立设置或卡片。关闭时钟也会隐藏月历。

## 日期间隔

展开月历底部的「日期间隔」，以完整的 `YYYY-MM-DD` 文本输入「开始日期」和「结束日期」，再点击「计算」或在任一日期框按一次新的 Enter。使用 ASCII 数字，年份为 `0001`–`9999`，须保留前导零。空值、不完整或不存在的日期、前后空白都会原样保留并显示本地错误，不会被自动修正。

「开始日期用今天」和「结束日期用今天」只把对应日期框填为设备当下的本地公历日期，格式为 `YYYY-MM-DD`。每次点击都会重新读取日期，跨午夜后也一样；不会使用 UTC 日期或正在浏览的月份。另一份原始日期草稿与年月草稿保持不变。填入日期会清除日期间隔的错误、结果与复制提示，但不会自动计算或移动焦点；即使填入的日期相同，也须重新计算。设备时钟无效或本地年份不在 `0001`–`9999` 时，两份草稿均保持不变。

「交换日期」会原样交换开始与结束日期的文本，包括空值、无效日期和空白。它会清除日期间隔的错误、结果与复制提示，不会自动计算、改变当前浏览月份或年月草稿，也不会移动焦点。请再次点击「计算」取得反向结果。双击只交换一次，之后单独点击可再次交换。

「清空日期」会清空两份原始日期草稿及其错误、结果与复制提示，即使两字段已为空也可清理旧提示。当前浏览月份、年月草稿、两级展开状态与焦点保持不变。它不会读取设备日期、计算或复制；重新输入日期后须显式计算才能复制。新的 Enter／空格保留原生按钮激活，长按、输入法合成与双击后续激活会被忽略。

结果显示原始起止日期和「结束减开始」的有方向整数公历自然日差。同日为 0，相邻次日为 +1，前一天为 −1；支持闰年、低年份和反向范围。按日期计算，不受时区、夏令时或当地跳过某日的影响；不是经过小时、工作日或同时包含首尾的计数。

编辑任一日期会立即清除旧结果，计算不会改变所浏览的月份。翻月、年月跳转、「今天」、跨午夜、时钟设置与语言更新都会保留这两份独立草稿和结果。仅收起「日期间隔」会在本次月历会话内保留它们；关闭并重开主月历，或隐藏时钟／整个面板，会清空日期、错误与结果，并再次收起此工具。扩展不会保存或同步这些日期草稿和结果。

计算成功后，点击「复制结果」可复制完整的可见结果，包括两个 ISO 日期、正负方向和当前语言的自然日单位。未计算或已编辑的草稿不能通过此按钮复制；复制不会重新计算或移动焦点。独立提示显示正在复制、成功或失败。剪贴板不可用或被拒绝时，原结果仍可选择并用 Ctrl/Cmd+C 手动复制，不会自动重试。

编辑、使用任一日期框的今天按钮、交换、清空或重新计算、切换结果语言、收起日期间隔、隐藏或离开页面、关闭主月历或替换视图都会清除复制提示。已发给系统的写入无法取消，须等待该请求实际结束后才能再次复制。普通翻月、「今天」、年月跳转和时钟 tick 会保留仍有效的提示。复制不会读取剪贴板、增加权限或保存月历状态；系统剪贴板可能按操作系统设置保留或同步文本，输入的日期也可能属于个人信息。

两个日期框各自维护输入法完成状态。组字 Enter 和按住 Enter 的续发不会计算，稍后一次新的 Enter 才会计算。Escape 沿用月历约定：收起主月历并将焦点返回仍可见的「日历」。隐藏、收起、脱离页面或失效的旧控件不能计算或移动焦点。日期框为普通文本输入，没有原生日期选择弹窗。

窄屏展开时，时钟会在页头独占一行；收起时原有布局不变。月历没有需要备份或同步的状态。
